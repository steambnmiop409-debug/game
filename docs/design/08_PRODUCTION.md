## T1. 엔진과 기술 스택 (확정)

### T1.1 웹: TypeScript + Three.js + Web Audio API + Vite

| 이유 | 설명 |
|------|------|
| 발디 문법에 맞다 | 박스형 공간, 최근접 필터 텍스처, 빌보드 스프라이트는 Three.js로 간단하고 가볍게 만들 수 있다 |
| **심장 박동이 시계다** | Web Audio API의 오디오 시계(`AudioContext.currentTime`)로 소리를 샘플 단위로 정확하게 예약할 수 있다. 건물의 박동, 발소리 차폐, 시퀀서를 하나의 시계에 묶는 데 유리하다 |
| 입체음향 | `PannerNode`의 HRTF 모드로 헤드폰 입체음향을 낼 수 있다 (벽 너머의 박동, 피카부의 '여러 곳') |
| 마이크 (선택) | `getUserMedia`로 최종장에서 플레이어가 자장가를 함께 흥얼거리는 기능을 구현할 수 있다 |
| 배포 | 링크 하나로 브라우저에서 바로 플레이할 수 있다 (GitHub Pages, itch.io) |
| 개발 환경 | 이 저장소의 클라우드 환경에서 헤드리스 크로미움으로 **직접 실행하고 화면을 확인하며** 개발할 수 있다 |

> 나중에 Electron이나 Tauri로 감싸 데스크톱판을 만들 수 있다.

## T2. 아키텍처: "시계는 건물의 심장이다"

```
                    ┌────────────────────────────────┐
                    │   Heart Clock (건물의 심장)       │  ← AudioContext.currentTime 기반
                    │   BPM, 박동 번호, 다음 '쿵' 시각, 심정지 │     미리보기(lookahead) 예약
                    └────────────────┬───────────────┘
      ┌──────────┬──────────┬────────┼─────────┬─────────────┬──────────────┐
      ▼          ▼          ▼        ▼         ▼             ▼              ▼
 [Sequencer] [Beat AI]  [Noise]  [Rewire]  [Light Pulse] [ECG HUD]   [Tissue Pulse]
  자장가 변주  박동마다     박동 은신  보지 않는   박동마다       심전도 띠      조직 정점
  레이어      걷는 존재    판정       방 재연결   3% 어두움                    부풀기
```

| 모듈 | 책임 |
|------|------|
| `core/heart` | 건물의 심장. BPM 상태(안정~발작), 심정지, 박동 이벤트 발행 |
| `audio/sampler` | 실제 악기 샘플을 음높이별로 재생 |
| `audio/sequencer` | 자장가와 변주를 박동에 맞춰 예약 재생 (S7) |
| `audio/fx` | 레트로 신호 체인, 공간 잔향, 청진기 필터(벽 너머 먹먹함), 무전기 대역 |
| `audio/pitch` | (선택) 마이크 음높이 감지 |
| `world/level` | **텍스트(ASCII) 격자 지도**를 3D 박스 공간으로 변환 |
| `world/rewire` | 방 그래프에서 **아무도 보지 않는 방**의 연결을 박동마다 바꾼다. 시야(주인공, 우나)와 앵커(무균실, 자외선)는 제외 (G7) |
| `render/billboard` | 스프라이트, 외곽선, 프레임 애니메이션, 형태 완화 대체 스프라이트 |
| `ai/` | 크리처 상태 기계 (G3.3), 박동 묶임과 연속 이동, 회진 경로와 시간표 |
| `companion/una` | 따라오기, 손잡기, 시선 고정, 대화 트리거, 분리 사건, 도구/사람 수치 |
| `systems/` | 소음, 체온, 산소, 침식, 구급 장비, 가방 |
| `ui/` | 구급 활동 기록지(일시정지·실패), 병상 저장, 심전도 HUD |

**레벨 파일 예시 (설계 형식)**
```

#201....#202....#203....#     T = TV (호피의 건강 시간)

#.......D.......D.......#     D = 문,  C = 무균실(저장, 앵커)
####D#######D#######D####     P = 공중전화,  X = 조직 문(맥 짚기)

##########################
```

## T3. 에셋 파이프라인

| 에셋 | 방법 |
|------|------|
| 텍스처 | **팔레트 인덱스 텍스트 → PNG 변환 스크립트.** 타일, 리놀륨, 조직 같은 반복 재질은 절차적 생성(Python/PIL). 포스터, 감사 편지, 아이 그림은 픽셀 단위로 직접 그린다. 영어 원문 텍스처와 한국어 번역 자막 문자열을 쌍으로 관리한다 (A3.4) |
| 스프라이트 | 같은 형식. 프레임마다 별도 파일, 외곽선은 스크립트가 자동으로 넣는다. 후기 실험체는 형태 완화용 실루엣 버전을 함께 만든다 |
| 로고 | `tools/brand/make_logo.py` → `assets/brand/second_nature_logo.svg` (시안 있음) |
| 음악 | 악보 데이터(JSON) → 실시간 시퀀서. 구조 스케치는 MIDI (`tools/audio/make_theme_sketch.py`) |
| 샘플 | 직접 녹음 + CC0 라이브러리 (S10.1). `assets/audio/samples/<악기>/<음>.ogg`. 라이선스는 `assets/audio/LICENSES.md`에 출처와 함께 기록 |
| 텍스트 | 한국어 문자열 테이블 (대사, 기록물, UI, 자막). 고유명사는 영어 원어 + 한국어 표기 |

## T4. 마일스톤

| 단계 | 목표 | 산출물 | 성공 기준 |
|------|------|--------|----------|
| **M0 핵심 감각 프로토타입** | "건물의 심장에 맞춰 걷고, 우나의 손을 잡고 숨는 것이 무섭고 재미있는가?" | 병동 복도 하나와 방 네 개, 건물의 심장과 박동 은신, 박동마다 걷는 회진 셋, **우나(따라오기·손잡기·시선 고정)**, 청진기, **보지 않을 때 바뀌는 복도 하나**, 무균실 하나, 메인 테마 시퀀서 v0 | 처음 하는 사람이 설명 없이 5분 안에 '박동 걷기'를 알아채고, 회진이 지나갈 때 **스스로 우나의 손을 잡는다** |
| **M1 Ch1 버티컬 슬라이스** | 챕터 1을 처음부터 끝까지 | P0 + P1 전체, 타이틀, 메뉴, 저장, 설정, 접근성, 로고, 메인 테마 완성본, 호피의 건강 시간 | 처음부터 끝까지 50~60분, 크래시 없음. 마지막 청진기 장면에서 테스터가 말을 잃는다 |
| M2 Ch2 | 임상연구동 | 자외선 등, 비상구 순열, 냉동실, 나이트라이트 | |
| M3 Ch3 | 설계동 | 산소, CCTV 지도, 기억의 창, 심정지 창, 태그·크레이들·오리가미·탱글 | |
| M4 Ch4 | 별관 B | 공간 왜곡 최대치, 피카부·노크노크·레디오어낫, 탈출 시도, 사진 장면 | |
| M5 Ch5 | 지하 C-0 | 꿈의 방, 수석 회진, 엔딩 3종, 선택 마이크 | |
| M6 다듬기 | 전체 | 성능, 플레이테스트 반영, 영어 자막(선택) | |

**오디오는 병행 트랙으로 진행한다:** M0에서 심장 시계와 샘플러 → M1에서 메인 테마와 Ch1 크레딧 송 → 이후 챕터마다 변주 하나와 크리처 박동 시그니처.

## T5. 리스크와 남은 결정 사항

### T5.1 리스크

| 리스크 | 대응 |
|--------|------|
| 민감한 소재 (아동 대상 실험, 성별 정정, 신체 변형) | [B6](01_CONCEPT.md#b6-톤--윤리-원칙)의 원칙과 보여 주는 선을 모든 대사·기록물·스프라이트의 검수 기준으로 쓴다. 특히 우나의 과거 성별을 충격 요소로 쓰지 않는지, 정상 시절의 성별정정 의료를 정당한 의료로 그리는지 마일스톤마다 확인한다 |
| 동반자 AI가 짜증을 유발할 위험 | 우나가 길을 막거나 뒤처지지 않게 한다. 손잡기 중에는 주인공의 움직임을 그대로 따른다. 분리 사건은 의도된 장면에서만 일어나게 한다 |
| '보지 않을 때 바뀌는' 공간의 혼란 | 무균실과 우나의 기억, CCTV 지도로 기준점을 충분히 준다. 한 챕터 안에서 바뀌는 연결의 수를 제한한다 |
| 샘플 라이선스 | CC0와 직접 녹음을 우선한다. 출처와 라이선스를 파일 단위로 기록한다 |
| 브라우저 오디오 자동재생 정책 | 첫 클릭이 있어야 오디오가 시작된다 → **"무전기를 눌러 응답하세요"** 화면이 이 제약을 출동 응답으로 바꾼다 (B3.4) |
| 상표 | 'Second Nature'는 흔한 영어 표현이라 같은 이름의 회사나 상품이 있을 수 있다. 출시 전 상표를 검색한다 |
| 범위 폭증 | 챕터 단위로 출시할 수 있게 만든다. Ch1만으로도 완결된 경험이 되게 한다 |

### T5.2 결정이 필요한 사항 (사용자 확인)

1. ~~**엔진:** 웹 / Unity / Godot~~ → **TypeScript + Three.js 확정**
2. **첫 범위:** M0 프로토타입부터(제안) / 바로 Ch1 버티컬 슬라이스
3. **마이크 기능:** 최종장에서 함께 흥얼거리기를 넣기(제안) / 넣지 않기
4. **실물 녹음:** 오르골, 장난감 피아노, 엄마의 허밍(사람 목소리)을 직접 녹음할 수 있는지, 아니면 CC0 샘플과 합성만으로 갈지
5. **영어 자막:** 게임 언어는 한국어로 확정. 영어 자막을 나중에 추가할지
