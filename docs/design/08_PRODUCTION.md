## T1. 엔진과 기술 스택 (확정)

### T1.1 웹: TypeScript + Three.js + Web Audio API + Vite

| 항목 | 버전·내용 |
|------|----------|
| 언어 | TypeScript (strict, `noUnusedLocals`) |
| 렌더링 | three.js r186 (`WebGLRenderer`, PBR, 그림자) |
| 소리 | Web Audio API (HRTF `PannerNode`, `ConvolverNode` 잔향, 오디오 시계 예약 재생) |
| 빌드 | Vite. `base: './'`라서 빌드 결과를 어느 경로에 올려도 동작한다 |
| 글꼴 | 갈무리 11 (`galmuri`, SIL OFL 1.1) |

| 이유 | 설명 |
|------|------|
| 입체감과 가벼움 | R.E.P.O. 수준의 입체감(그림자, PBR)을 내면서도, 저해상도 렌더로 브라우저에서 가볍게 돈다 |
| 소리를 샘플 단위로 예약 | `AudioContext.currentTime`으로 음악·걸음 박자·효과음을 정확한 시각에 예약한다 |
| 입체음향 | HRTF로 헤드폰에서 회진의 위치, 벽 너머의 소리를 들려준다 |
| 배포 | 링크 하나로 브라우저에서 바로 플레이할 수 있다 (GitHub Pages, itch.io) |
| 개발 환경 | 클라우드 환경의 헤드리스 크로미움으로 **직접 실행하고 화면을 확인하며** 개발한다 |

> 마이크 입력(`getUserMedia`)은 쓰지 않는다 (사용자 결정, T5.2).
> 나중에 Electron이나 Tauri로 감싸 데스크톱판을 만들 수 있다.

## T2. 아키텍처

```
 main.ts ──▶ Game (game.ts) ── 상태: boot → title → play ⇄ pause → fail / credits
              │
              ├─ core/      engine(렌더 타깃·후처리·1인칭 손 오버레이), input, pace(걸음 박자), post(셰이더)
              ├─ audio/     audio(버스·잔향·입체음향), synth(악기·목소리 합성), sfx(효과음 등록), music(테마·적응형)
              ├─ world/     level(방·개구부·충돌·길 찾기), chapter1(배치), props, textures, materials, lights, batch
              ├─ entities/  player(+1인칭 손), una, rounds, hoppy, models(리그)
              ├─ gameplay/  story(챕터 스크립트), interact, tapes(VHS 화면), prologue(구급차)
              ├─ data/      text.ts (모든 한국어 문자열: 대사, 차트, 판독, 테이프, 퀴즈, 크레딧)
              └─ ui/        HUD, 자막, 문서, 퀴즈, 메뉴, 구급 활동 기록지
```

| 모듈 | 책임 |
|------|------|
| `core/engine` | 낮은 해상도 렌더 타깃(HalfFloat) → 후처리 셰이더 → 최근접 확대. 1인칭 손은 깊이를 지우고 위에 그린다 |
| `core/pace` | **걸음 박자** (게임 시간 기준: 느린 컴퓨터에서 게임이 느려지면 크리처의 걸음도 같이 느려진다). 회진과 호피 스와피가 이 박자에 맞춰 한 걸음씩 걷는다. 퀴즈 오답(+15 BPM, 챕터 끝까지)과 발견(+20, 10초마다 −5)으로 빨라진다. 추격 음악이 이 박자를 따른다 |
| `core/input` | 포인터 잠금, 키 래치(`take`: 비동기 스크립트가 키 입력을 놓치지 않게) |
| `audio/audio` | 버스(음악·월드·UI·목소리·환경), HRTF, 방 잔향 프리셋 두 개를 교차 페이드, 벽 차폐(저역 통과), 소프트 클립과 리미터 |
| `audio/synth` | 모달 합성(오르골, 첼레스타, 장난감 피아노, 비브라폰, 크로탈레스), 유리 하모니카, 카플러스-스트롱 우쿨렐레, 포먼트 목소리(허밍, 합창, 한글 옹알이 말소리) |
| `audio/music` | 메인 테마 44마디 시퀀서(미리보기 예약), 적응형 레이어(긴장·추격·자장가 조각·스팅어), 크레딧 송 |
| `world/level` | 0.5m 격자의 방, 벽(두께와 걸레받이), 개구부(문·이중문·아치·창·엘리베이터·통풍구·해치), 변형 그룹, 충돌, A* 길 찾기, 벽 사이 판정, 광선 거리 |
| `world/lights` | 손전등(쿠키, 그림자, 가까우면 약해짐), 가장 가까운 형광등 7개에 점광원 풀, 하나에 그림자, 형광등 깜빡임과 웅웅거림 |
| `entities/rounds` | 순찰·의심·추격·정지 상태 기계, 체온(열) 감지, 시야는 벽 판정 |
| `entities/hoppy` | 앉음·일어남·추격·정지·걸림, 통풍구에서 접혀 들어오기 |
| `entities/una` | 따라오기, 손잡기, 스크립트 이동(Promise), 앉기·눕기, 표정 |
| `gameplay/story` | 체크포인트마다 `async` 스크립트. 취소 토큰으로 실패·재시도·메뉴 전환 때 안전하게 끊는다 |
| `gameplay/tapes` | 128×96 캔버스에 장면을 그리고 VHS 잡음, 날짜 도장 |

## T5. 리스크와 남은 결정 사항

### T5.1 리스크

| 리스크 | 대응 |
|--------|------|
| 민감한 소재 (아동 대상 실험, 성별 정정, 신체 변형) | [B6](01_CONCEPT.md#b6-톤--윤리-원칙)의 원칙을 모든 대사·기록물·모델의 검수 기준으로 쓴다. **바뀐 몸(성별, 외모)은 공포가 아니다. 공포는 본인의 뜻과 상관없이 몸을 다시 설계할 수 있게 된 회사에 있다.** 우나의 과거(테이프 #3)를 충격 요소로 쓰지 않는지 마일스톤마다 확인한다 |
| 동반자 AI가 짜증을 유발할 위험 | 우나가 길을 막거나 뒤처지지 않게 한다. 멀어지면 보이지 않는 곳에서 따라잡는다. 손잡기 중에는 주인공의 움직임을 그대로 따른다 |
| 헤드리스 점검의 한계 | 소프트웨어 렌더라 실제 프레임과 소리를 확인할 수 없다. 실제 기기 플레이테스트가 필요하다 |
| 샘플 라이선스 | CC0만 쓴다. 출처와 라이선스를 `public/audio/vsco/LICENSE.txt`에 기록한다 |
| 브라우저 오디오 자동재생 정책 | 첫 클릭이 있어야 오디오가 시작된다 → 첫 화면(헤드폰 권장, "클릭하면 시작합니다")에서 첫 클릭을 받는다 |
| 상표 | 'Second Nature'는 흔한 영어 표현이라 같은 이름의 회사나 상품이 있을 수 있다. 출시 전 상표를 검색한다 |
| 범위 폭증 | 챕터 단위로 출시할 수 있게 만든다. Ch1만으로도 완결된 경험이 되게 한다 |
