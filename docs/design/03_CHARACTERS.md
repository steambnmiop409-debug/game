## C1. 플레이어: 조율사 (No.49)

| 항목 | 내용 |
|------|------|
| 시점 | 1인칭. 말하지 않는 주인공. 이름은 모든 학교 문서에서 **검게 지워져 있다** |
| 2006년 | 19세 견습 피아노 조율사. 작은 조율 공방에서 일한다 |
| 과거 | 1987년생. 1995년 '티코의 리틀 마에스트로 콘테스트'에서 선발(8세). **건반 49(A4)** 배정. 졸업 예정일 1996-12-14. **하루 전인 12-13에 퇴교**(9세) |
| 기억 | 학교 시절을 거의 기억하지 못한다. 펠 선생님이 밤에 차로 데려다준 뒤로 부모는 "나쁜 꿈이었다"고만 했다. 아이는 스스로 그 기억을 닫았다 |
| 버릇 | 피아노 A를 맞출 때마다 **조금 낮게** 맞추는 버릇이 있다. 스승은 "넌 늘 조금 낮아"라고 핀잔을 준다 |
| 조율사라는 직업의 의미 | 악기의 몸을 아는 사람이다. **향판이 따뜻하다, 현이 맥박처럼 떨린다, 이건 가문비나무가 아니다** 같은 공포는 조율사의 손과 귀로 먼저 온다 |
| 아이들에게 49번은 | 반 친구. 아이들은 49번을 기억한다. 어떤 아이는 반가워하고, 어떤 아이는 **"너만 빠졌어"**라고 원망한다 |
| 1인칭 손 스프라이트 | 손가락 끝을 자른 조율사 장갑. 오른손에 공명기, 왼손은 상호작용과 귀 막기 |

| 항목 | 내용 |

| 진실 | 아이들이 자라기 전에 그 소리를 몸째 '보존'했다. 1980년 청력을 잃은 뒤로는 손바닥을 악기에 대고 **진동으로** 아이들을 들었다 |
| 현재 | 1996년 밤, 아이들이 그를 발표회장 **파이프 오르간**으로 만들었다. 그의 폐가 풀무다 (C4.11) |

## C3. 룰라 (Lulla) — 견본품, 그리고 친구

| 항목 | 내용 |
|------|------|
| 겉모습 | 도시락만 한 오르골. 뚜껑 위에서 발레리나 인형이 돈다. 인형의 머리카락은 **진짜 머리카락**이다. 태엽을 감았을 때만 인형의 눈이 뜨이고, **눈동자가 나를 따라온다.** 상자 옆면 꼬리표에는 `견본품 — SAMPLE`이라고 찍혀 있고, 그 아래 삐뚤빼뚤한 크레용 글씨로 `49에게`라고 적혀 있다 |
| 정체 | 1995년 학교에서 가장 어렸던 여섯 살 여자아이. 마스터피스 카탈로그 시연용 '견본품'이 되었다 (W5.4). 49번을 졸졸 따라다니던 친구였다 |
| 원통 | 핀은 여러 아이의 젖니다. **그중 두 개는 주인공의 것이다** (Ch1 마지막에 원통이 보이고, Ch3 양호실 장부로 확인된다) |
| 말하는 방식 | **말을 못 한다.** 오르골 선율로만 '말한다.' 장조는 안심, 단조는 경고, 짧게 끊긴 음은 '서둘러', 「똑딱 노래」 첫 소절은 '나 여기 있어', 점점 느려지며 늘어지는 음은 '감아 줘' |
| 게임 기능 | **오르골 나침반 (G7).** 학교 구석구석을 아는 그녀가 가야 할 쪽을 바라보면 소리가 커진다. 대신 그 소리가 다른 것들을 부른다 |
| 원하는 것 | 49번이 **피아노가 되지 않는 것**, 그리고 모두가 이제 그만 쉬는 것. 그녀는 아이들의 비밀 노래 「집에 가는 노래」를 알고 있다 |
| 갈등 | 프리마는 룰라를 '말 안 듣는 견본품'이라 부르며 되찾으려 한다. 보스버그는 Ch5에서 룰라를 '증거'로 가져가려 한다 |
| 신뢰 (숨은 수치) | 오르골이 "감아 줘"라고 할 때 감아 주면 오르고, 그녀를 크리처 유인용 미끼로 쓰면 내려간다 (G7, P6) |
| 오르골 사실성 | 금속 빗살을 원통의 핀이 튕기는 구조. 태엽이 풀리면 **템포는 느려지지만 음높이는 변하지 않는다** |

### C4.1 **마에스트로 티코** (Maestro Tikko) / 시어도어 펠 / 음 없음(틱) / Ch1~4

| 필드 | 내용 |
|------|------|
| 외형 | 키 1.9m. 나무 피라미드형 메트로놈 몸통. 앞판에 크게 그린 만화 눈과 웃는 입. 진자 막대가 얼굴 앞을 좌우로 가로지르며 흔들린다. 흰 장갑, 나비넥타이, 지휘봉. 몸통 옆면에 `Largo · Andante · Allegro · Presto` 눈금 |
| 사람의 흔적 | **그려진 눈동자 한가운데 작은 구멍 두 개.** 가까이 가면 그 너머에서 진짜 눈이 깜빡인다 (Ch1에서는 거리상 거의 안 보이고, Ch4에서 정면으로 마주한다). 그리고 그의 '틱' 소리는 우드블록이 아니라 **이가 딱딱 부딪치는 소리**다 (Ch4에서 가까이 들을 때 알게 된다) |
| 행동 규칙 | **박자마다 한 걸음.** 걸음 하나에 1.2m. 72BPM이면 초속 1.44m로, 처음에는 플레이어의 걷기 속도(2.0m/s)보다 느리다. 청음 수업에서 틀릴 때마다 전체 BPM이 +8씩 오른다 (발디 오마주) |
| 디테일 | BPM이 오를수록 진자 추가 아래로 내려온다 (실제 메트로놈은 추가 내려갈수록 빨라진다) |
| 감지 | 박자 밖에서 난 발소리, 청음 수업의 틀린 답 |
| 약점과 신호 | **소리굽쇠 A**(학교의 '멈추고 들어라' 신호)에 4박 동안 얼어붙는다. 고무 뮤트로 가슴 속 작은 메트로놈을 막으면 4박 정지 |
| 진정 | Ch4: 손글씨로 '49'라고 적힌 1995년 콘테스트 테이프 속 **펠 자신의 웃음소리** |
| 제압 | Ch4: 펜듈럼의 탈진기를 부순다 |
| 잡히면 | 화면이 검게 변하고 지휘봉 소리 '탁' 한 번. 이어서 **교문 밖에서 바라본 학교** 화면과 문구 **"수업 끝. 집에 가렴."** (Ch1에서는 조롱처럼 읽히지만 Ch4에서 의미가 뒤집힌다. 그는 늘 49번을 학교 밖으로 내보내려 했다) |

### C4.2 **벨로 꽉-안아줘 곰** (Bello) / 버티 로우 / 건반 21 1대 · F2 (87.31Hz) / Ch1

| 필드 | 내용 |
|------|------|
| 외형 | 키 3m 퍼레이드용 곰 인형. 가슴이 빨강·흰 줄무늬 아코디언 풀무다. 털은 엉켜 있고, 한쪽 눈은 단추, 다른 쪽은 빠져 솜이 비어져 나왔다 |
| 사람의 흔적 | 찢어진 털 사이로 보이는 **풀무 안쪽의 나무틀이 갈비뼈 모양**이다. 들숨 때마다 그 틀이 벌어진다. 그리고 그 안에서 **누군가가 같이 숨을 쉰다** |
| 정체 | 무서우면 숨을 참던 덩치 큰 소년. '호흡 불량'으로 건반 명단에서 지워지고 TV 퍼레이드 곰이 되었다. 이제 그는 영원히 숨을 쉬어야 소리가 난다 |
| 행동 규칙 | **들숨 4박, 날숨 4박.** 들숨 때는 주변 공기를 빨아들여 플레이어를 끌어당긴다(난간이나 손잡이를 잡고 버텨야 한다). 날숨 때는 돌진하며 돌풍을 일으켜 물건을 쓰러뜨린다 |
| 디테일 | 버튼식 다이어토닉 아코디언처럼 **들숨과 날숨에 다른 화음**이 난다(실제로 존재하는 양방향 이음 방식). 들숨은 F장조, 날숨은 F단조. 단조 화음 끝에 아주 작게 **아이가 흐느끼는 숨**이 섞인다 |
| 감지 | 숨소리. 플레이어의 숨이 25% 아래로 떨어져 헐떡이면 위치가 들킨다 |
| 약점과 신호 | 고무 뮤트로 풀무의 공기 밸브를 막는다. 소리굽쇠 A에 4박 정지 |
| 진정 | 버티의 사물함에서 찾은 **엄마의 녹음 편지** "버티, 무서우면 천천히 숨 쉬어. 엄마가 셀게. 하나, 둘…" → F2에 맞춰 재생하면 그가 천천히 숨을 고르며 주저앉아 콧노래를 부른다 |
| 제압 | '풀무 프레스'로 유인해 밸브를 뚫는다 → 마지막 화음을 길게 내뱉으며 쪼그라든다. 마지막 숨은 아이의 숨이다 |
| 잡히면 | 꽉 끌어안긴다. 음성 상자의 녹음 "꽉 안아줘!"가 늘어지며 재생되고, 아코디언 화음이 압축되어 끊긴다. 암전 |

### C4.3 **포키즈** (Forkies) / (사람이 아님) / A4 근처 / Ch1~2

| 필드 | 내용 |
|------|------|
| 외형 | 손가락만 한 소리굽쇠에 고무공 발이 달린 태엽 장난감 |
