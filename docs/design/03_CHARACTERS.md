## C1. 플레이어: 조율사 (No.49)

| 항목 | 내용 |
|------|------|
| 시점 | 1인칭. 말하지 않는 주인공. 이름은 모든 문서에서 **검게 지워져 있다** (플레이어가 자신을 투영할 자리이자, 학교가 지운 이름이라는 서사 장치) |
| 2006년 | 19세 견습 피아노 조율사. 작은 조율 공방에서 일한다 |
| 과거 | 1987년생. 1995년 '티코의 리틀 마에스트로 콘테스트'에서 선발(8세). **건반 49(A4)** 배정. 1996-12-14 퇴교(9세) |
| 기억 | 학교 시절 기억이 거의 없다. 키프세이크 채취의 부작용으로 목소리와 함께 기억 일부가 떨어져 나갔다 (W5.4) |
| 왜 조율사가 됐나 | 설명할 수 없는 끌림. 피아노 A를 맞출 때마다 **'조금 낮은 A'가 이상하게 더 편하게 들린다.** 스승은 "넌 귀가 너무 정직해서 탈이야"라고 말한다 (프롤로그 대사) |
| 능력의 근거 | 공구를 다룰 줄 아는 기술자라서 공명기를 직접 조립할 수 있다. 튜닝 해머와 뮤트를 능숙하게 쓴다 |
| 반쯤 면역 | 귀가 평균율에 완전히 굳지 않았기 때문에 **정음의 끌어당김을 버틴다.** 다른 사람이라면 즉시 '조율'됐을 허밍 속에서도 이명 게이지만으로 버틴다 (G4) |
| 1인칭 손 스프라이트 | 손가락 끝을 자른 조율사 장갑. 오른손에 공명기, 왼손은 상호작용과 귀 막기 |

## C2. 인간 인물

### C2.1 코넬리우스 해로우 (Cornelius Harrow, 1931~) — 창립자, '지휘자'

| 항목 | 내용 |
|------|------|
| 겉모습 | 인자한 창립자. 오르가니스트 출신. 로비 초상화 속에서 늘 오래된 **귀나팔**(보청 나팔)을 쥐고 있다 |
| 진실 | 1954년 어머니 장례식에서 들은 '그 화음'을 평생 좇았다. 1980년 완전히 청력을 잃은 뒤로는 **측정기만 믿었다.** "기계가 맞다고 하면 맞는 것이다." |
| 동기 | 화음이 되어 그것을 **소리로서 '듣는 것'.** 그에게 아이들은 '자신의 잃어버린 귀'였다. 악의보다 집착과 슬픔이 크다 |
| 현재 | 1996-12-21, 발표회장 오르간과 하나가 되었다 → **지휘자 (C4.13)** |
| 등장 | Ch2 서류, Ch4 편지, Ch5 본인 |
| 대표 대사 | "내 귀는 오래전에 죽었다. 아이들이 내 귀다." / "한 음만. 단 한 음만 더 있으면 들을 수 있어." |

### C2.2 잉그리드 보스버그 박사 (Dr. Ingrid Vossberg, 1934~) — 음향학자

| 항목 | 내용 |
|------|------|
| 겉모습 | 음악원의 '청력 보건 고문'. 학부모 안내서에 실린 미소 띤 사진 |
| 진실 | 냉전기 정부 음향 연구 프로그램 **LYRE**(Long-Yield Resonance Experiment, 가상) 출신. '공명 정체성 이전(RIT)' 이론의 창시자. 프로젝트 88의 실무 책임자 |
| 동기 | 이론의 완성. 그리고 LYRE 후원자들에게 '사람을 소리로 만드는 화음'을 넘기는 것 |
| 현재 | **살아 있다(72세).** 1996년 그날 밤 중계차에서 멀티트랙을 녹음하고 있었다. **2006년 소포를 보낸 사람이다** |
| 등장 | Ch3 연구 녹음, Ch4 LYRE 서류, Ch5 무전 목소리, 비밀 엔딩 |
| 플레이 중 정체 | 끝까지 '목소리'로만 나온다. 얼굴은 비밀 엔딩의 마지막 컷에서만 보인다 |
| 대표 대사 | "공명은 거짓말을 하지 않아요. 사람은 하지만." / (카세트 끝, 아주 작게) "마흔아홉. 집에 와야지." |

### C2.3 시어도어 펠 (Theodore Pell, 1950~) — 청음 교사, 티코의 목소리

| 항목 | 내용 |
|------|------|
| 겉모습 | 「티코의 템포 타임」 진행자. 아이들이 가장 좋아한 선생님 |
| 진실 | 프로젝트 88의 실체를 알고 **한 명이라도 빼내려 했다.** 1996-12-14, 주인공의 정체성 공명 측정치(440.00, '완벽')를 숨기고 "교정 불가, 퇴교 권고"라고 거짓 평가서를 써서 주인공을 내보냈다 |
| 대가 | 1996-12-20 발각되어 **펜듈럼(대 메트로놈)에 정음**됐다. 그 뒤 10년 동안 박자를 지키며 허밍을 '박자 안에' 가둬 왔다 |
| 현재 | **마에스트로 티코 (C4.1)** |
| 등장 | Ch1 TV(티코로서), Ch2 연습실 49의 테이프, Ch4 진실 |
| 대표 대사 | (Ch2 테이프) "마흔아홉, 이걸 듣고 있다면 돌아왔다는 거구나. 돌아오지 마." / (Ch4 마지막) "난 네가 낮다고 했지. 넌 한 번도 낮았던 적이 없어." |

### C2.4 오딜 그랑데 (Odile Grandé, 1938~) — 피아노과장

| 항목 | 내용 |

### C2.5 헤스터 애비 (Hester Abbey, 1945~) — 양호교사 겸 청력사

| 항목 | 내용 |
|------|------|

## C3. 룰라 (Lulla) — 동반자이자 거울

| 항목 | 내용 |
|------|------|
| 겉모습 | 손바닥만 한 오르골 위에서 도는 발레리나. 도자기 얼굴에 가는 금이 하나 있다. 악보 종이로 만든 튀튀. **태엽을 감았을 때만 눈을 뜬다** |
| 발견 | Ch1 로비 분실물 보관함. 꼬리표에 `No.49`가 적혀 있다. 펠이 학교 측 회수를 막으려고 숨겨 두었다 |
| 말하는 방식 | **말을 못 한다.** 오르골 선율로만 '말한다'. 장조는 안심, 단조는 경고, 짧게 끊긴 음은 '서둘러', 「똑딱 노래」 첫 소절은 '나 여기 있어' |
| 게임 기능 | **오르골 나침반 (G7).** 태엽을 감으면 목표 방향을 바라볼수록 소리가 커지고 밝아진다. 대신 그 소리가 적을 부른다 |
| 정체 | **평균율로 '보정된' 주인공 자신의 목소리** (W5.4). 학교가 원했던 '완벽한 49번' |
| 동기 | 그녀도 아홉 살 아이의 목소리다. 그녀는 진심으로 믿는다. "완벽한 A가 들어가면 화음이 닫히고, 86명이 쉴 수 있어." |
| 갈등 | 최종장에서 그녀는 자기 A(440.00Hz)를 내밀고, 주인공은 자기 A(436.5Hz)를 쥐고 있다. 둘이 함께 울리면 **초당 3.5회의 맥놀이**가 생긴다 |
| 해소 (진엔딩) | 주인공의 낮은 A로 화음이 맑아지는 것을 들은 룰라가 **스스로 빗살 하나를 휘어** 음을 내린다(W2 예외: 의지). 맥놀이가 멈춘다 |
| 신뢰 (숨은 수치) | 오르골을 감아 달라고 할 때 감아 주면 오르고, 그녀를 적 유인용 미끼로 쓰면 내려간다 (G7, P6) |
| 오르골 사실성 | 금속 빗살을 원통의 핀이 튕기는 구조. 낮은 음 빗살 밑에는 납 추가 붙어 있다. 태엽이 풀리면 **템포는 느려지지만 음높이는 변하지 않는다** |

### C4.1 **마에스트로 티코** (Maestro Tikko) / 시어도어 펠 / 음 없음(틱) / Ch1~4

| 필드 | 내용 |
|------|------|
| 외형 | 키 1.9m. 나무 피라미드형 메트로놈 몸통. 앞판에 크게 그린 만화 눈과 웃는 입. **진자 막대가 얼굴 앞을 좌우로 가로지르며 흔들린다.** 흰 장갑, 나비넥타이, 지휘봉. 몸통 옆면에 실제 메트로놈처럼 `Largo · Adagio · Andante · Allegro · Presto` 눈금이 있다 |
| 행동 규칙 | **박자마다 한 걸음.** 걸음 하나에 1.2m. 72BPM이면 초속 1.44m로, 처음에는 플레이어의 걷기 속도(2.0m/s)보다 느리다. 청음 수업에서 틀릴 때마다 전체 BPM이 +8씩 오른다 (발디 오마주) |
| 디테일 | BPM이 오를수록 **진자 추가 아래로 내려온다** (실제 메트로놈은 추가 내려갈수록 빨라진다). 추가 입 앞까지 내려오면 Presto다 |
| 감지 | 박자 밖에서 난 발소리, 틀린 답, TV 카메라 |
| 약점 | 박자에 맞춰 걸으면 듣지 못한다. 고무 뮤트로 그의 '심장'(가슴 속 작은 메트로놈)을 막으면 4박 동안 멈춘다 |
| 진정 | Ch4: 손글씨로 '49'라고 적힌 1995년 콘테스트 테이프에 담긴 **펠의 웃음소리** |
| 제압 | Ch4: 펜듈럼의 탈진기를 부순다 |
| 잡히면 | 화면이 검게 변하고 지휘봉 소리 '탁' 한 번. 이어서 **교문 밖에서 바라본 학교** 화면과 문구 **"수업 끝. 집에 가렴."** (Ch1에서는 조롱처럼 읽히지만 Ch4에서 의미가 뒤집힌다) |
| 사운드 | 우드블록 틱, 보면대를 두드리는 지휘봉, 진자 축의 삐걱임. 목소리는 싸구려 TV 스피커를 거친 80년대 진행자 톤 |

### C4.2 **벨로 꽉-안아줘 곰** (Bello) / 버티 로우 / 건반 21 · F2 (87.31Hz) / Ch1

| 필드 | 내용 |
|------|------|
| 외형 | 키 3m 퍼레이드 진열용 곰 인형. **가슴이 빨강·흰 줄무늬 아코디언 풀무**다. 털은 엉켜 있다. 한쪽 눈은 단추, 다른 쪽은 빠지고 솜이 비어져 나왔다. 들숨 때 가슴이 부풀며 풀무 주름이 갈비뼈처럼 드러난다 |
| 정체 | 긴장하면 숨을 참던 덩치 큰 소년. '숨 대신 노래하라'며 풀무에 정음됐다 |
| 행동 규칙 | **들숨 4박, 날숨 4박.** 들숨 때는 주변 공기를 빨아들여 플레이어를 끌어당긴다(난간이나 손잡이를 잡고 버텨야 한다). 날숨 때는 돌진하며 돌풍을 일으켜 물건을 쓰러뜨리고 소음을 만든다 |
| 디테일 | 버튼식 다이어토닉 아코디언처럼 **들숨과 날숨에 다른 화음**이 난다(실제로 존재하는 양방향 이음 방식). 들숨은 F장조, 날숨은 F단조 |
| 감지 | 숨소리. 플레이어의 숨이 25% 아래로 떨어져 헐떡이면 위치가 들킨다 |
| 약점 | 고무 뮤트로 풀무의 공기 밸브를 막는다 |
| 진정 | 창고에서 찾은 버티의 녹음, 곧 숨을 참았다가 터뜨리며 웃는 소리를 **F2에 맞춰** 재생한다 → 주저앉아 콧노래를 부른다 |
| 제압 | '풀무 프레스'로 유인해 밸브를 뚫는다 → 마지막 화음을 길게 내뱉으며 쪼그라든다 |
| 잡히면 | 꽉 끌어안긴다. 아코디언 화음이 압축되어 끊기고 암전 |

### C4.3 **포키즈** (Forkies) / (아이가 아님) / A4 근처 / Ch1~2

| 필드 | 내용 |
|------|------|
| 외형 | 손가락만 한 소리굽쇠에 고무공 발이 달린 장난감. 무리를 지어 다닌다 |
| 정체 | 아이가 아니다. 아이들 웃음소리가 오래 녹음된 상자 안에 있다가 그 소리가 깃들었다 (W2 규칙 1). **"모든 괴물이 아이였던 것은 아니다"**를 보여 주는 장치 |
| 행동 | 무해하다. 하지만 플레이어를 보면 뛰어오르며 '띵' 하고 울린다. 경보 역할을 해서 근처 크리처를 부르고 BPM을 일시적으로 +4 올린다 |
| 대처 | 펠트 덧신으로 조용히 지나가거나, 손으로 잡아 울림을 멈춘다(쥐면 조용해진다) |

### C4.4 **마담 그랑데** (Madame Grandé) / 오딜 그랑데 / A0 (27.5Hz, 피아노 최저음) / Ch2

| 필드 | 내용 |
|------|------|
| 외형 | 세 다리로 걷는 9피트 콘서트 그랜드. **뚜껑이 턱**이고 그 안에 해머들이 이빨처럼 늘어서 있다. 보면대가 눈썹 모양이다. 지시봉을 쥔 가는 팔이 하나 있다 |
| 행동 규칙 | 연습동을 순찰하며 **틀린 음을 사냥한다.** 바닥 건반 복도에서 음계 순서를 어기고 밟으면 그 위치를 정확히 안다. 프랑스어로 박을 센다. "앵, 되, 트루아, 카트르." |
| 감지 | 틀린 음(음계 밖의 음), 연습실 피아노의 불협화음 |
| 약점 | 튜닝 해머로 그녀의 핀블록(관절)을 풀면 현이 늘어져 잠시 주저앉는다 |
| 진정 | 그랑 살롱 축음기에서 찾은 **어린 오딜이 틀린 음을 내자 그녀의 스승이 다정하게 웃는 녹음**. 이것을 A0 기준으로 맞춰 재생하면 그녀가 기억해 낸다. "틀려도… 괜찮았었지." |
| 제압 | 핀블록을 하나씩 풀어 현을 모두 늘어뜨린다 → 무너지며 최저음 A0가 길게 울린다 |
| 잡히면 | 뚜껑이 닫히는 포르티시모. 저음 클러스터와 서스테인 페달 소리, 그리고 암전 |

### C4.5 **페이지 터너** (Page Turners) / 반주 교사들 / 음 없음 / Ch2, Ch5

| 필드 | 내용 |
|------|------|
| 외형 | 손가락이 아주 긴 마른 인형 같은 존재. 얼굴 대신 펼쳐진 악보 한 장이 있다 |
| 정체 | 수년간 아이들 연주 옆에서 악보를 넘기던 반주 교사들 |
| 행동 | **죽이지 않는다.** 플레이어를 보면 '페이지를 넘긴다.' 지금 서 있는 복도 구역이 책장처럼 회전해 이전 구역으로 되돌아간다(진행이 후퇴하는 장애물) |
| 대처 | 종이 넘기는 소리를 녹음해 다른 곳에서 재생하면 그쪽으로 넘기러 간다 |

### C4.6 **싱어롱즈** (The Singalongs) / '크로매틱 열둘' / 건반 53~64 (C♯5~C6) / Ch2

| 필드 | 내용 |
|------|------|
| 외형 | 펠트 손인형 12개. 단추 눈은 **실로 꿰매져 감겨 있고**, 입은 'O' 모양이다. 서로 손을 잡고 둥근 원을 이룬다. **음 하나마다 색 하나** (반음 12개를 색상환 12색에 대응. 스크랴빈의 색-음 대응에서 착안) |
| 정체 | 1993년 한꺼번에 정음된 고음 아이 12명 |
| 행동 | 앞을 못 본다. **노래로 반향 위치를 파악**한다. 원 전체가 하나의 화음을 유지하다가 **화음이 바뀌는 순간에만** 움직인다 |
| 위험 | 12명이 동시에 서로 다른 음을 내면 **반음 12개의 클러스터**가 된다. 이명 +25 |
| 대처 | 그들 중 한 명의 음을 녹음해 그대로 재생하며 걸으면 **동료로 착각한다** (위장) |
| 진정 | 합창실 피아노에 남은 **12명이 처음 함께 화음을 맞추고 웃는 녹음** |

### C4.7 **너스 허시** (Nurse Hush) / 헤스터 애비 / 1kHz 순음 / Ch3

| 필드 | 내용 |
|------|------|
| 외형 | 키 2.4m의 마른 체구에 하얀 간호복. 머리는 **진공관식 청력검사기** 상자이고 다이얼이 달려 있다. 귀 자리에 헤드폰 두 짝. 늘 손가락을 '입술'(스피커 그릴)에 대고 있다. 소리를 들으면 얼굴의 바늘 계기판이 튄다 |
| 행동 | 박자가 없는 지하를 **매끄럽게 미끄러지듯** 움직인다. 소리 나는 존재를 '조용히' 시킨다 |
| 감지 | 모든 소리. 무향실에서는 **심박 90 이상**을 6m 안에서 듣는다 |
| 약점 | 펠트로 헤드폰을 덮으면 몇 초 동안 귀가 먼다 |
| 진정 | 양호실 서랍 카세트에 담긴 **아이들이 숨죽여 킥킥대는 소리**를 1kHz 기준으로 재생한다 → 그녀가 속삭인다. "…이제 쉬어도 돼." |
| 제압 | 검사기 전원부의 진공관을 뽑는다 |
| 잡히면 | 귓가에서 "쉬이이—". 1kHz 순음이 차오른 뒤 뚝 끊긴다 |

### C4.8 **레레** (Re-Re) / 레미 / 건반 42 · D4 (293.66Hz, 계이름 '레') / Ch3

| 필드 | 내용 |
|------|------|
| 외형 | 아이 실루엣이 조금씩 어긋나게 겹쳐 그려진 잔상 덩어리. **잔향실 안에서만 보인다** |
| 정체 | 남의 말과 노래를 따라 하기 좋아하던 아이. 잔향실에서 정음되다가 정체성이 반사음 속으로 흩어졌다 |
| 행동 | 플레이어가 낸 소리를 **3초 뒤 다른 위치에서 똑같이** 낸다. 그 소리에 다른 크리처가 몰려든다 |
| 활용 | 역으로 이용할 수 있다. 일부러 소리를 내고 레레가 엉뚱한 곳에서 따라 하게 해서 너스 허시를 유인한다 |
| 진정 | 레미가 처음 '자기 노래'를 지어 부른 녹음을 **역재생으로 복원**해 D4로 들려준다 → 따라 하기를 멈추고 처음으로 자기 소리를 낸다 |

### C4.9 **래프 트랙** (Laugh Track) / (아이가 아님) / 음 없음 / Ch4

| 필드 | 내용 |
|------|------|
| 외형 | 80년대 옷을 입은 스튜디오 방청객 마네킹. **인쇄된 웃는 얼굴**의 판지 가면, 용수철 달린 박수 손 |

### C4.11 **어셔** (The Ushers) / 발표회 안내 직원들 / 음 없음 / Ch5

- 손전등을 든 정장 마네킹. 시야는 손전등 원뿔이다. **지휘자의 루바토 박자**에 맞춰 통로를 걷는다.

### C4.12 **여든여섯** (The Eighty-Six) / 발표회의 아이들 / 건반 1~87 중 49를 뺀 86명 / Ch5

- 합창 계단석에 선 반투명 실루엣 86명. **10년 동안 F–C 빈 5도를 웅웅대고 있다.**
- 적이 아니다. 하지만 화음이 '빠진 음'을 찾을 때마다 계단석 전체가 **플레이어를 향해 고개를 돌린다.**
- 공명기의 화음 쌓기로 그들에게 음을 '빌려주면' 한 명씩 길을 비켜 준다.

### C4.13 **지휘자** (The Conductor) / 코넬리우스 해로우 / C0 (32피트 파이프, 약 16.35Hz) / Ch5 (Ch1부터 허밍으로 존재)

| 필드 | 내용 |
|------|------|
| 외형 | 발표회장 오르간 전체가 몸이다. 정면 파이프 88개가 **갈비뼈이자 얼굴**처럼 배열되어 있고, 콘솔은 손이다. 의자에는 해로우의 낡은 연미복이 걸쳐져 있고, 콘솔 위에 귀나팔이 놓여 있다 |
| 스톱 | 오르간의 음색 손잡이(스톱)마다 **아이 이름**이 붙어 있다. 그리고 실제로 존재하는 사람 목소리 흉내 리드 스톱 **'복스 후마나(Vox Humana, 인간의 목소리)'**가 하나 있다 |
| 행동 | 움직이지 않는다. 홀 전체가 그의 몸이다. 파이프가 숨을 쉬듯 바람을 뿜고, 셔터(스웰 박스)가 열리고 닫히며 공격한다. **루바토 박자**(사람 지휘자처럼 늘어졌다 서둘렀다 하는 박자)로 어셔와 홀을 지휘한다 |
| 32피트 파이프 | 가장 낮은 C는 약 16Hz다. 들린다기보다 **몸으로 느껴진다.** 게임에서는 저역 진동과 맥놀이 변조로 표현한다 |
| 동기 | "한 음만. 49번만 오면 들을 수 있어." |
| 결말 | 엔딩에 따라 다르다 (P6) |

| 건반 | 음 | 진동수 | 보유자 → 현재 |
