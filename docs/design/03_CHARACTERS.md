## C1. 플레이어: 구급대원

| 항목 | 내용 |
|------|------|
| 정체 | 앨더 카운티 응급의료대(Alder County EMS) 구급대원. 23세. 이름은 명찰에서 번져 보이지 않는다 |
| 시점과 말 | 1인칭. 거의 말하지 않는다. 중요한 순간에만 **글로 된 선택지**로 짧게 말한다 (예: "너 여기 들어온 지 얼마나 됐어?") |

| 왜 구급대원인가 | 그날 불길 속에서 자기를 안고 나온 구급대원 때문에 |

## C2. 우나 (Una) — 대상 1-01

### C2.1 기본

| 항목 | 내용 |
|------|------|
| 겉모습 | 열한두 살쯤으로 보이는 여자아이. 놀랄 만큼 예쁘다. 맨발. 낡은 환자복 위에 간호사가 준 카디건. 흉터 하나 없다 |
| 실제 | 1977년생. 1987년 열 살에 실험 1의 대상이 되었다. **22년째 이 모습이다** |
| 이름 | '우나'는 간호사 루스 캘러웨이가 지어 준 이름이다. 회사가 부른 '1-01'을 대신해서. *una*는 '하나'라는 뜻이다. **"너는 하나뿐이니까."** |
| 옛 이름 | 회사 기록에는 Daniel Pierce라고 적혀 있다. 우나 자신은 그 이름이 점점 희미하다 |
| 몸 | 먹지 않는다. 마시지 않는다. 자지 않는다. 숨 쉬지 않아도 된다(말할 때만 공기를 쓴다). 체온은 늘 방 온도다. 심장 소리가 거의 없다. 늙지 않는다. 다치지만 죽지 않는다 |
| 원하는 것 | **집에 가는 것.** 20년 넘게 시도했지만 한 번도 성공하지 못했다 |

### C2.2 성격과 말투

- 처음 만났을 때 우나는 **너무 정상적으로 보여야 한다.** 이 시설에서 살아남은 평범한 아이처럼.
- 말이 많고, 겁이 많고, 농담을 한다. 오래된 것들을 이상하게 잘 안다.

| 상황 | 대사 예시 |
|------|----------|
| 첫 만남 (침대 밑) | "…구급대원이에요? 진짜 왔네. 장난 전화 아니었어요, 진짜로." |
| 회진이 지나갈 때 | "제 손 잡아요. 빨리. 그럼 쟤네가 못 봐요." / "왜냐고요? 몰라요. 원래 그래요." |
| 물을 건넸을 때 | "괜찮아요. 목 안 말라요." (Ch1) → "…고마워요. 이거 갖고 있을게요." (주머니에 넣는다, Ch3) |
| 복도가 바뀌었을 때 | "아 또 바뀌었네. 여기 원래 화장실이었는데." |
| 농담 | "저 여기서 숨바꼭질 챔피언이에요. 상대가 좀… 반칙이긴 하지만." |
| 엄마 이야기 | "우리 엄마 노래 진짜 못해요. 근데 자장가는 맨날 불러 줬어요. 첫 줄밖에 기억 안 나지만." |
| 주인공이 잠들 때 | "자요. 제가 보고 있을게요. 저 원래 잠 잘 안 와요." |

### C2.3 이상 징후의 공개 순서

> 진행할수록 이상한 것이 보인다. 한 번에 하나씩, 플레이어가 **스스로 알아채게** 둔다.

| 챕터 | 징후 | 연출 |
|------|------|------|
| Ch1 | 물을 마시지 않는다. 차가운 타일 위를 맨발로 걷는다 | 대사 한 줄, 화면 구석 |
| Ch1 끝 | **청진기를 대도 아무 소리가 나지 않는다** | 챕터 마지막 장면 (P1) |
| Ch2 | 밥을 줘도 먹지 않는다. **잠을 자지 않는다** (저장할 때 주인공이 깨어나면 우나는 밤새 같은 자세로 앉아 있다) | 저장 장면 |
| Ch2 | 펜라이트를 비춰도 **동공이 줄어들지 않는다** | 장난처럼 시작한 장면 |
| Ch2 | 냉동실에서 멀쩡하다. **주인공의 입김만 하얗게 보이고 우나의 입에서는 아무것도 나오지 않는다** | 대사 없음. 화면으로만 |
| Ch2 | 1988년 직원 단체 사진을 보고 **얼굴을 알아본다** "이 선생님 손 차가웠어요." | |
| Ch3 | 크게 다쳤는데 신경 쓰지 않는다. 팔이 이상한 각도로 꺾였다가, 우나가 아무렇지 않게 다시 맞춘다 "괜찮아요. 원래 이래요." | 피 없음. 소리와 각도로만 |
| Ch3 | "너 여기 들어온 지 얼마나 됐어?" 우나가 대답을 피한다 | 선택지 대사 |
| Ch3 | 시설 기록에서 **실험 날짜 1987**을 발견한다. 20여 년 전. 외모는 전혀 늙지 않았다 | |
| Ch4 | 우나의 방, 그리고 **사진** (C2.6) | |
| Ch5 | 우나가 죽지 않는 진짜 이유 (W2 규칙 7) | |

### C2.4 능력 (게임플레이, G6)

| 능력 | 근거 | 쓰임 |
|------|------|------|
| **손잡기** | 잔여체에게 우나는 자기 몸이다. 그리고 우나의 손은 늘 차갑다 | 우나의 손을 잡고 있는 동안 회진이 주인공을 알아보지 못한다 |
| **시선 고정** | 잔여체는 누가 보고 있는 공간을 바꾸지 않는다. 우나는 **눈을 깜빡일 필요가 없다** | 우나에게 한 방향을 '지켜보게' 하면 그쪽 길이 바뀌지 않는다 |
| 숨이 필요 없다 | 실험 1-E | 가스가 찬 방, 물에 잠긴 수조에 들어간다 |
| 추위를 타지 않는다 | 실험 1-E | 냉동실 안쪽의 밸브를 연다 |
| 죽지 않는다 | 실험 1-E | 전기가 흐르는 곳에도 들어갈 수 있다. **다만 아프다.** 그녀를 그렇게 쓸지는 플레이어가 고른다 (G10) |
| 한계 | 잔여체가 놓아주지 않는다 | 철조망과 정문 근처에 가면 쓰러지고, 다음 순간 **자기 방 침대에서 눈을 뜬다** |

### C2.5 우나가 주인공과 붙어 다니는 이유

1. **우나가 전화를 걸었다.** 22년 만에 처음으로 누군가가 왔다.
2. 우나는 바깥 사람이 필요하다. 바깥 사람만이 잔여체를 '이물질'로서 흔들 수 있다.
3. 주인공은 우나가 필요하다. 우나의 손 없이는 회진을 피할 수 없다.
4. 그리고 우나는 주인공의 왼팔을 처음부터 알아본다. 처음 손을 잡았을 때 우나가 멈칫한다. "…구급대원님 손, 따뜻한데 이상해요. 여기 같아요." (주인공의 성별을 정하지 않기 위해 우나는 끝까지 '구급대원님'이라고 부른다) (Ch3에서 의미가 드러난다)

### C2.6 사진 장면 (Ch4, 원안)

> 장소: 별관 B 장기 요양 병실, 우나의 방. 벽에는 날짜 표시가 빽빽하다. 서랍 맨 아래에 사진 한 장.

1. 오래된 가족사진. 엄마, 아빠, 그리고 **남자아이 한 명.** 처음에는 우나를 찾을 수 없다.
2. 플레이어는 다른 가족의 사진이라고 생각한다. 사진을 집어 든다.
3. 우나가 사진을 **빼앗는다.** 그리고 처음으로 크게 화낸다. "그거 내 거예요! 만지지 마요!"
4. 긴 침묵. 우나가 사진을 들여다본다.
5. 그 아이가 우나 자신이었다. 여기서 중요한 것은 우나가 **원래 남자아이였다는 사실 때문에 충격받는 것이 아니라는 것.** 우나는 그 사실을 이미 알고 있다.
6. 진짜 공포는 따로 있다. 우나는 **자기가 원래 어떻게 생겼는지 기억하지 못한다.** 사진을 봐도 자기라고 느껴지지 않는다. 목소리도 기억나지 않는다. 본명도 점점 희미하다. 그런데 부모에게 돌아가고 싶다는 감정만 남아 있다.

```
우나:   "엄마가 날 알아볼까?"
        [선택지]  ① "아니."   ② (아무 말도 하지 않는다)
        ① → 우나가 고개를 끄덕인다.      ② → 우나가 혼자 대답한다. "…아니겠지."
우나:   "내가 엄마를 알아볼 수 있을까?"
```

- 이 장면에는 음악이 없다. 건물의 심장 소리도 이 한 장면 동안만 멎는다.

### C2.7 가장 큰 반전 (원안)

- 후기의 괴물들은 보기에는 끔찍하지만 **심장이 뛰고, 먹고, 자고, 늙고, 죽는다.**
- 우나는 아름답고 완벽하게 사람처럼 생겼다. 그런데 **심박도 거의 없고, 먹을 필요도 없고, 호흡도 필요 없고, 노화도 없고, 죽지도 않는다.**
- **회사의 첫 번째 진짜 성공작은 괴물이 아니었다. 너무 완벽하게 인간처럼 생긴 무언가였다.**
- 그리고 회사는 그 성공을 보고 잘못된 결론을 내렸다. **"인간의 형태는 유지할 수 있다. 그렇다면 인간의 기능은 얼마나 제거할 수 있는가?"**

### C2.8 우나를 그리는 원칙

- 우나는 언제나 '우나', '그녀'다. 옛 이름은 회사 기록과 사진 뒷면에만 있다.
- 우나는 공포의 대상이 아니다. 이상 징후는 **슬픔과 불안**으로 연출하고, 깜짝 놀래키는 연출로 쓰지 않는다.
- 우나가 잃은 것은 성별이 아니라 **선택과 기억**이다.

### C4.12 **수석 회진** (Chief of Rounds) / 데즈먼드 헤일 / Ch5

- 다른 회진보다 머리 하나가 더 크다. 명찰 `D. HALE, M.D., PH.D. — DIRECTOR`.
- 생각은 남지 않았지만 녹음된 습관처럼 문장 조각을 되풀이한다. "어디까지… 바꿀 수 있지?"
- Ch5에서 회진 전체를 지휘해 주인공을 쫓는다.

### C4.13 **루스의 회진** (Ruth's Round) / 루스 캘러웨이 / Ch3, Ch5

- 다른 회진과 똑같은 매끈한 얼굴, 명찰 `R. CALLOWAY, R.N.`
- **이 형체 하나만 우나의 자장가를 흥얼거린다.** 그리고 고개를 기울이는 버릇이 있다.
- Ch3: 우나가 알아본다. "…루스 선생님?" 형체는 우나는 지나치고 주인공 쪽으로 고개를 돌린다.
- Ch5: 수석 회진의 행렬을 몸으로 막아 우나와 주인공을 지나가게 한다.
