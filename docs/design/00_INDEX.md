# OFF-KEY : 틀린 음의 아이 — 게임 설계 문서 (색인)

![OFF-KEY 로고 시안](../../assets/brand/offkey_logo.svg)

> **박자 안에 숨고, 소리로 맞서는 레트로 음악학교 호러.**
> 1996년 생방송 발표회 도중 440명이 '소리'가 되어 사라진 어린이 음악원에, 10년 전 "음이 낮다"며 쫓겨났던 아이가 피아노 조율사가 되어 돌아온다.

- 상태: **기획 단계 (v0.1)**
- 레퍼런스: 파피 플레이타임(챕터 구조, 깊은 미스터리), 발디의 수학교실(2018년 시절의 그래픽 문법). **내용과 퍼즐은 가져오지 않는다** ([B4](01_CONCEPT.md#b4-레퍼런스-활용-원칙), [B5](01_CONCEPT.md#b5-차별화-대조표))

---

## 읽는 법: 대설계 → 중설계 → 소설계

| 단계 | 표기 | 예 |
|------|------|----|
| **대설계** | 문자 하나 (`B`, `W`, `C`, `G`, `P`, `A`, `S`, `T`) | `W` 세계관 |
| **중설계** | 문자 + 숫자 | `W5` 프로젝트 88 |
| **소설계** | 문자 + 숫자.숫자 (그 아래는 표와 목록) | `W5.4` 룰라 키프세이크 → 보관 카드 문구 |

모든 하위 설계는 상위 설계의 규칙을 따른다. 특히 **[B1.3 핵심 기둥 5개](01_CONCEPT.md#b13-핵심-기둥-5개-모든-설계-결정의-판정-기준)**와 **[W2 세계의 규칙](02_WORLD.md#w2-세계의-규칙-초자연-법칙-5개--예외-1개)**은 모든 문서의 판정 기준이다.

## 핵심 결정 한눈에 보기

| 질문 | 답 |
|------|----|
| 제목 | **OFF-KEY : 틀린 음의 아이** |
| 배경 | 1996년 '침묵의 발표회'로 봉쇄된 *알레그레토 꼬마 음악원* (카덴스 폴스), 2006-12-20~21 |
| 주인공 | 19세 견습 피아노 조율사. 10년 전 쫓겨난 건반 49번(A4) |
| 핵심 메커닉 | **박자 은신**(박자에 맞춰 디딘 발소리는 틱에 묻힌다) + **공명기**(녹음·음높이·역재생·화음) |
| 위협 게이지 | **이명.** 귀를 막으면 내려가지만 아무것도 들리지 않는다 |
| 길잡이 | 룰라, 오르골 나침반. 정체는 평균율로 '보정된' 주인공의 목소리 |
| 주제 | 평균율(평균에 맞추는 학교) 대 순정률(순정한 아이의 귀). **"완벽한 음은 사람을 지우고, 틀린 음은 사람을 남긴다."** |
| 반전 | 주인공의 '틀린 음'(−13.7센트)은 F 위의 **순정 장3도**였다 |
| 진엔딩 | 시리즈에서 단 한 번도 울리지 않았던 IV→I, **아멘 종지** |
| 그래픽 | 발디 시절의 문법 + 수치 규격과 '한 방에 한 이야기' 규칙 |
| 소리 | 실제 악기(오르골, 장난감 피아노, 파이프 오르간, 아코디언, 유리 하모니카…) + 실시간 시퀀서 |

## 숫자 사전 (아무 데나 쓰지 않는다)

| 숫자 | 의미 |
|------|------|
| **49** | 주인공의 건반 번호. 피아노 49번 건반 = A4. 메인 테마의 마디 수. 20:49 |
| **440** | 표준 기준음 A=440Hz. 실종자 수 (아이 86 + 직원 34 + 관객 320) |
| **436.5** | 주인공의 A (F4 × 5/4) |
| **13.7** | 주인공이 '틀렸다'고 판정받은 센트 수 = 평균율과 순정 장3도의 차이 |
| **72** | 펜듈럼의 기본 BPM (안정 시 심박 정도) |
| **88** | 건반 수 (아이 87명 + 건반 88은 해로우의 '예약'), 연습실 수 |
| **1996-12-21 20:49** | 침묵의 발표회 |
