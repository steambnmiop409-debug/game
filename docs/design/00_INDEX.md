# SECOND NATURE (세컨드 네이처) — 게임 설계 문서 (색인)

![SECOND NATURE 로고 시안](../../assets/brand/second_nature_logo.svg)

> **사람의 몸을 마음대로 다시 쓸 수 있게 된 회사. 그리고 그 회사의 첫 번째 진짜 성공작과 함께, 살아 있는 건물에서 빠져나오는 1인칭 호러.**
> 회사의 첫 번째 진짜 성공작은 괴물이 아니었다. 너무 완벽하게 인간처럼 생긴 무언가였다.

- 상태: **v0.4 — 챕터 1 플레이 가능 빌드** (`src/`, 실행 방법은 [README](../../README.md)) · 엔진: **TypeScript + Three.js (확정)** · 배경: **미국** · 게임 언어: **한국어**
- 원안: 사용자 기획 (회사의 시작, 실험체, 생존 항상성, 실험 71~90, 잔여체, 사진 장면). 원안과 확장의 경계는 [B7](01_CONCEPT.md#b7-원안과-확장)에 정리했다.
- 레퍼런스: 파피 플레이타임(기업이 아이의 몸을 다시 만든 직접적인 공포, 챕터 구조, 손 장비), 발디의 수학교실(틀릴수록 빨라지는 위협), R.E.P.O.(레트로 렌더 위의 입체감). **내용과 퍼즐은 가져오지 않는다** ([B4](01_CONCEPT.md#b4-레퍼런스-활용-원칙))

## 읽는 법: 대설계 → 중설계 → 소설계

| 단계 | 표기 | 예 |
|------|------|----|
| **대설계** | 문자 하나 (`B`, `W`, `C`, `G`, `P`, `A`, `S`, `T`) | `W` 세계관 |
| **중설계** | 문자 + 숫자 | `W5` 실험 연대기 |
| **소설계** | 문자 + 숫자.숫자 (그 아래는 표와 목록) | `W5.2` 실험 번호표 → 실험 82 외부기관화 → 레디오어낫 |

모든 하위 설계는 상위 설계의 규칙을 따른다. 특히 **[B1.3 핵심 기둥](01_CONCEPT.md#b13-핵심-기둥-5개-모든-설계-결정의-판정-기준)**, **[B6 톤·윤리 원칙](01_CONCEPT.md#b6-톤--윤리-원칙)**, **[W2 이 세계가 작동하는 방식](02_WORLD.md#w2-이-세계가-작동하는-방식-규칙-7--한계)**은 모든 문서의 판정 기준이다.

## 핵심 결정 한눈에 보기

| 질문 | 답 |
|------|----|
| 공포의 근원 | **본인의 뜻과 상관없이 사람의 몸을 다시 설계할 수 있게 된 회사.** 몸의 모양, 성별, 외모 자체는 공포가 아니다 |
| 괴물은 어디에 | **건물이 괴물이다.** 아이들에게서 떼어 낸 '원래 모습'들이 모인 잔여체 |
| 왜 못 나가나 | 잔여체에게 아이들은 자기 몸이다. 죽이지 않는다. 절대로 놓아주지 않는다 |
| 우나 | 가장 인간적인 존재이자 생물학적으로 가장 먼 존재. 먹지도, 자지도, 숨 쉬지도, 죽지도 않는다 |
| 우나가 죽지 않는 이유 | 그녀의 항상성 기준점이 C-0에 묶여 있다. **그녀의 죽음 214건은 다른 곳에서 일어났다** |
| 주인공 | 1994년 이 회사의 기술로 화상을 치료받은 구급대원. **왼팔이 C-0의 원료다** (판독: 로트 0332) |
| 핵심 메커닉 | **재지시기로 몸에 남은 지시를 읽는다** (판독, 진정 카드) + **우나의 손잡기** + **차트·테이프·판독으로 사람에게 한 일을 풀어 간다** |
| 도덕적 선택 | 우나를 도구로 쓸 것인가, 사람으로 대할 것인가 |
| 엔딩 | 실험 90 "인간에게 몸이 필요한가?"에 대한 세 가지 대답. 진엔딩은 **우나가 죽을 수 있는 몸, 곧 살아갈 수 있는 몸을 돌려받는다** |
| 메인 테마 | 엄마의 자장가가 회사의 네 계단을 따라 변주된다. 마지막엔 잔향만 남는다 |
