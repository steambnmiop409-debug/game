# OFF-KEY : 틀린 음의 아이 — 게임 설계 문서 (색인)

![OFF-KEY 로고 시안](../../assets/brand/offkey_logo.svg)

> **아이를 악기로 만든 학교에서, 박자 안에 숨어 살아남는 레트로 호러.**
> 알레그레토 꼬마 음악원의 악기들은 아이들의 몸으로 만들어졌다. 그리고 아이들은 아직 그 안에 살아 있다.
> 10년 전 "음이 낮다"는 이유로 졸업 하루 전에 쫓겨났던 49번이 피아노 조율사가 되어 돌아온다.

- 상태: **기획 단계 (v0.2)** · 엔진: **TypeScript + Three.js (확정)**
- 레퍼런스: 파피 플레이타임(아이의 몸이 물건이 되는 공포, 챕터 구조), 발디의 수학교실(2018년 시절의 그래픽 문법). **내용과 퍼즐은 가져오지 않는다** ([B4](01_CONCEPT.md#b4-레퍼런스-활용-원칙), [B5](01_CONCEPT.md#b5-차별화-대조표))

## 변경 기록

| 버전 | 내용 |
|------|------|
| v0.1 | 첫 기획. 공포의 핵심이 '목소리가 소리로 옮겨진다', '440명이 소리가 되었다', 평균율·순정률 이론처럼 **추상적**이었다 |
| **v0.2** | 피드백 반영: "아이를 인형으로 만드는 것 같은 진짜 기괴함이 없다, 억지스럽다." → 공포의 핵심을 **'아이들의 몸으로 만든 악기'**로 다시 세웠다. 초자연 규칙을 없애고 현실의 뿌리(뼈 피리, 거트 현, 상아 건반, 고양이 피아노 기록, 카스트라토)에 붙였다. 창립자의 동기(변성기의 상처), 1996년 밤(아이들이 어른을 악기로 만들었다), 숨은 주모자(첫 졸업생 프리마), 길잡이(견본품 룰라와 주인공의 젖니), 공명기(길들이기 신호의 재사용), 엔딩(아이들의 비밀 노래)을 모두 새로 설계했다. 평균율·순정률은 숨은 이스터에그로만 남겼다 |

## 읽는 법: 대설계 → 중설계 → 소설계

| 단계 | 표기 | 예 |
|------|------|----|
| **대설계** | 문자 하나 (`B`, `W`, `C`, `G`, `P`, `A`, `S`, `T`) | `W` 세계관 |
| **중설계** | 문자 + 숫자 | `W5` 킨더클라비어 계획 |
| **소설계** | 문자 + 숫자.숫자 (그 아래는 표와 목록) | `W5.4` 견본품 룰라 → 이빨 요정 깡통 장부 문구 |

모든 하위 설계는 상위 설계의 규칙을 따른다. 특히 **[B1.3 핵심 기둥 5개](01_CONCEPT.md#b13-핵심-기둥-5개-모든-설계-결정의-판정-기준)**, **[B6 톤과 등급](01_CONCEPT.md#b6-톤과-등급)**, **[W2 이 세계가 작동하는 방식](02_WORLD.md#w2-이-세계가-작동하는-방식-규칙-5--한계)**은 모든 문서의 판정 기준이다.

## 핵심 결정 한눈에 보기

| 질문 | 답 |
|------|----|
| 제목 | **OFF-KEY : 틀린 음의 아이** |
| 핵심 공포 | **아이들의 몸으로 만든 악기.** 아이들은 아직 그 안에 살아 있고, 이 학교의 모든 음악은 그들이 내는 소리다 |
| 왜 억지가 아닌가 | 악기는 원래 몸(뼈, 창자, 가죽, 상아)으로 만들었고, 어른들은 실제로 음악을 위해 아이의 몸에 손을 댔다(카스트라토). 이 세계는 거기서 한 걸음만 더 나갔다 |
| 동기 | 창립자는 열네 살에 변성기로 성가대에서 쫓겨났다. 그는 아이들이 영원히 자라지 않게 '보존'했다 |
| 그날 밤 | 1996-12-21. 아이들은 배운 대로 어른 353명을 악기로 만들었다. 후원자들은 지금도 객석에서 박수를 친다 |
| 주인공 | 19세 견습 조율사. 졸업(=악기가 되는 날) 하루 전에 쫓겨난 49번 |
| 핵심 메커닉 | **박자 은신** + **공명기**(학교가 아이들을 길들인 신호음을 녹음해 되돌려 쓴다) |
| 도덕적 선택 | 체벌 신호로 다룰 것인가(선생님), 기억의 소리로 달랠 것인가(친구) |
| 길잡이 | 룰라, 견본품 오르골. 원통의 핀 중 둘은 **주인공의 젖니** |
| 숨은 주모자 | 프리마, 첫 졸업생. 이제 그녀가 선생님이다 |
| 진엔딩 | 아이들이 몰래 만든 「집에 가는 노래」(교가의 역행)를 49번의 '틀린' 음으로 시작한다. 그리고 시리즈에서 단 한 번도 울리지 않았던 **아멘 종지** |
| 그래픽 | 발디 시절의 문법 + 바디 호러 시각 규칙(흔적은 하나나 둘, 피는 없다) |
| 소리 | 실제 악기 + **사람 소리 층**(챕터마다 커진다) + 실시간 시퀀서 |
| 엔진 | **TypeScript + Three.js** (확정) |

## 숫자 사전 (아무 데나 쓰지 않는다)

| 숫자 | 의미 |
|------|------|
| **49** | 주인공의 건반 번호. 피아노 49번 건반 = A4. 킨더클라비어의 빈 요람. 메인 테마의 마디 수 |
| **87** | 킨더클라비어 안의 아이들 |
| **353** | 1996년 밤 악기가 된 어른들 (후원자 320 + 직원 33) |
| **440** | 공식 실종자 수 (87 + 33 + 320). 표준 기준음 A=440Hz와 같다 |
| **72** | 펜듈럼의 기본 BPM (안정 시 심박 정도) |
| **88** | 건반 수, 연습실 수 |
| **18** | 졸업 기념 오르골의 음 수 (젖니는 20개) |
| **1996-12-13** | 주인공이 쫓겨난 날. 졸업 예정일 하루 전 |
| **1996-12-21** | 침묵의 발표회 |
