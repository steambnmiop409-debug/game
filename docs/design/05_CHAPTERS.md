## P0. 프롤로그: 조율 의뢰 (2006-12-14, 주인공의 공방)

| 순서 | 장면 | 플레이와 연출 |
|------|------|--------------|
| 0-1 | 낡은 업라이트 피아노 앞. 스승의 메모 "A부터 맞춰라." | **조율 튜토리얼.** 소리굽쇠를 치고 튜닝 해머로 A 현을 돌린다. 소리굽쇠와 현의 맥놀이(와와와 하는 떨림)가 느려지다가 멈추면 440Hz에 맞은 것이다. 핀 잠금(G9-1)의 연습이다 |
| 0-2 | 장3도 확인 | 스승의 두 번째 메모 "F와 같이 쳐 봐. 3도는 원래 떨려야 정상이다." F–A를 함께 치면 평균율 장3도 특유의 빠른 떨림(초당 약 14회)이 들린다. 실제 조율사도 3도의 떨림 속도로 평균율을 확인한다. 그런데 A를 아주 조금 내리면 떨림이 **완전히 사라지고**(순정 장3도) 이상하게 마음이 놓인다. 다시 440으로 올려야 다음으로 넘어간다. 스승의 음성 "넌 귀가 너무 정직해서 탈이야." |
| 0-3 | 초인종. 소포 | 안에는 ① `No.49 — A`가 새겨진 소리굽쇠 ② 카세트 ③ 조율 의뢰서 "알레그레토 꼬마 음악원 연습실 B-49 피아노 조율 요망. 출장비 선불." (발신: 알레그레토 유산 신탁) |
| 0-4 | 카세트 재생 | 아이의 목소리로 「똑딱 노래」. 마지막 '아이'가 살짝 낮다. 테이프가 끝난 뒤 아주 작게 여자 목소리 **"마흔아홉. 집에 와야지."** (Q1 떡밥) |
| 0-5 | 작업실 벽 | 신문 스크랩 「침묵의 발표회 10년, 카덴스 폴스는 아직도 웅웅거린다」. 지도에 동그라미 |
| 0-6 | 암전 | 자동차 라디오에서 「티코의 템포 타임」 주제곡이 잡음 속에 흘러나온다. 타이틀 |

## P1. Chapter 1 — 조율 (Tuning Up)

| 칸 | 내용 |
|----|------|
| 장소 | ① 정문·그랜드 로비(옆방 AV실 포함), ② 레슨동, ③ 악기 창고 |
| 새 메커닉 | 박자 은신, 숨, 이명과 귀 막기, 공명기 조립(녹음·재생·송출), 핀 잠금, 청음 수업 |
| 위협 | 티코(첫 오답 이후), 포키즈, **벨로**(챕터 보스) |
| 진실 | L1. "누군가 나를 불렀다." 룰라 발견 |
| 색 | 바랜 원색(빨강·노랑·파랑), 로비는 청록과 크림 |

**비트 시트**

| # | 장면 | 내용 |
|---|------|------|
| 1-1 | 도착 (12-20 23:12, 눈) | 정문 인터폰에서 티코 징글이 흘러나온다. 쪽문의 맹꽁이자물쇠는 **소리 열쇠**: 인터폰 차임을 녹음할 수 없으니 소리굽쇠 A를 울려 연다 (기계가 A440에 반응) |
| 1-2 | 그랜드 로비 | 멈춰 있는 지름 6m 스트로보 원판, 티코 동상, 역대 리틀 마에스트로 액자. 1995년 액자만 사진이 오려져 있다. **틱 라인이 들린다.** 박자 은신 튜토리얼 (스피커 아래에 '박자에 맞춰 걸어요!' 아이용 포스터) |
| 1-3 | 분실물 보관함 | **룰라 발견.** 꼬리표 `No.49`. 태엽을 감자 「똑딱 노래」 첫 소절. 오르골 나침반 튜토리얼 |
| 1-4 | 로비 옆 AV실 | 나팔, 릴 녹음기, 소리굽쇠로 **공명기 1차 조립.** 녹음과 재생 튜토리얼: 문 차임을 녹음해 '차임 잠금' 문을 연다. 스트로보 원판 자리는 비어 있다 |
| 1-5 | 레슨동 입장 | 교실 7개(도~시). 축음기에 레슨 음반을 올리면 TV가 켜진다. **"안녕, 꼬마 마에스트로! 티코의 템포 타임이에요!"** |
| 1-6 | 청음 수업 (도~라 교실 6개) | 일반 문제. 맞히면 금별을 받는다. 틀리면 BPM이 오르고 **티코가 깨어난다.** '라' 교실 교탁 서랍에서 **스트로보 원판**을 찾아 공명기에 끼운다 (2차 조립) |
| 1-7 | **'시' 교실** (7번째) | **불가능한 문제**(사분음). 반드시 오답이 되고, 티코가 복도에 나타난다. 이때부터 레슨동 전체가 추격 구간이 된다 |
| 1-8 | 송출 유인 | 교무실 방송실에서 녹음한 수업 종소리를 반대편 스피커로 송출해 티코를 떼어 낸다 |
| 1-9 | 레슨동 출구 주크박스 | 음반 7장을 넣으면 「똑딱 노래」가 나오는데, 마지막 '아이'의 A가 **낮다.** 주크박스 핀블록을 소리굽쇠 A440에 맞춰 **'고쳐야'** 문이 열린다. *(복선: 플레이어는 지금 자기 자신의 음을 '고치고' 있다)* |
| 1-10 | 악기 창고 | 천장까지 쌓인 악기 상자. 3m짜리 **벨로**가 진열 받침대 위에 앉아 있다. 거대한 숨소리 |
| 1-11 | 벨로 추격 | **들숨 4박**에는 난간을 잡고 버티고, **날숨 4박**에는 뛴다. 숨이 25% 아래로 떨어지면 들킨다 |
| 1-12 | 공명 기억 (선택) | 창고 B의 버티 사물함에서 '숨 참고 웃는' 녹음을 찾는다 |
| 1-13 | 풀무 프레스 | **진정:** 공명 기억을 F2에 맞춰 재생하면 벨로가 주저앉아 콧노래를 부르며 길을 비켜 준다. **제압:** 프레스로 밸브를 뚫는다 |
| 1-14 | 로비 귀환 | **스트로보 원판이 돌기 시작한다.** 모든 스피커의 틱이 한 박 끊겼다가 다시 이어진다. 로비 TV에 티코가 나온다. **"1교시 끝! 다시 온 걸 환영해, 마흔아홉."** 암전 |
| 1-15 | 엔딩 송 | 「꽉 안아줘 (Squeeze Me)」 벨로의 왈츠 |

**비트 시트**

| # | 장면 | 내용 |
|---|------|------|
| 2-1 | 연습동 입구 | 88개의 연습실 문이 끝없이 이어진다. 문마다 출석부가 붙어 있다. 방마다 메트로놈이 66BPM으로 엇갈리게 똑딱인다 (**메트로놈 수십 개가 조금씩 어긋난 소리** = 이 챕터의 앰비언스). 연습동에서는 펜듈럼 대신 **가장 가까운 메트로놈의 박**이 차폐 기준이 된다. 방을 옮길 때마다 박을 다시 잡아야 한다 |
| 2-2 | 학적부실 | **프로젝트 88 명단**, 교체 보유자 기록. 건반 88 `예약 — C.H.` |
| 2-3 | 바닥 건반 복도 | 음계 길 퍼즐. 틀린 음을 밟으면 멀리서 "앵, 되, 트루아…" |
| 2-4 | 합창실 | **싱어롱즈.** 한 명의 음을 녹음해 그대로 재생하며 원 사이를 지나간다 (위장) |
| 2-5 | 페이지 터너 회랑 | 들키면 복도가 '넘어간다.' 종이 넘기는 소리를 녹음해 미끼로 쓴다 |
| 2-6 | 공명 유리 | 활로 심벌즈를 그어 유리 진열장의 고유음을 찾는다. 안에는 **음높이 다이얼 부품** |
| 2-7 | **연습실 B-49** | 가장 조용한 방. 크레용 그림: 티코와 손잡은 아이. **평가서**("−14센트, 교정 불가"). 피아노 안의 축음기에서 **펠의 테이프** "마흔아홉, 이걸 듣고 있다면 돌아왔다는 거구나. 돌아오지 마." 그리고 의뢰서에 적힌 그 피아노. A 현 하나만 조금 낮게 맞춰져 있다 |
| 2-8 | 선택의 순간 (작은) | B-49 피아노의 A를 440으로 '고칠지' 그대로 둘지 고른다. 아무 설명도 없다. (음률 ±1. 진엔딩 에필로그에 반영된다) |
| 2-9 | 그랑 살롱 | **마담 그랑데** 등장. 공명 기억: 축음기 속 어린 오딜과 그녀의 스승 |
| 2-10 | 그랑데 추격 | 88개 연습실을 지나는 추격. 문을 닫으면 메트로놈 소리가 발소리를 덮어 준다 |
| 2-11 | 보스 | **진정:** 공명 기억을 A0 기준으로 재생 → "틀려도… 괜찮았었지." **제압:** 핀블록을 차례로 풀어 무너뜨린다 |

| 2-13 | 엔딩 송 | 「에튀드 No.49」 그랑데의 연습곡 |

## P3. Chapter 3 — 온쉼표 (Whole Rest)

| 칸 | 내용 |
|----|------|
| 장소 | ⑤ 음향연구동 지하 1~2층 (청력검사 부스, 조율 의자실, 잔향실, 무향실, 정음실) |
| 새 메커닉 | **무박자 환경**(차폐 없음), 역재생, 심박(무향실), 잔향 설계 |
| 위협 | **너스 허시**, 레레 |
| 진실 | L3 (전반). 정음의 원리, 룰라의 정체, 소포를 보낸 사람(보스버그) |
| 색 | 병원 민트, 흡음재 회색, 빨간 'ON' 램프. 무향실은 거의 검정 |

**비트 시트**

| # | 장면 | 내용 |
|---|------|------|
| 3-1 | 계단을 내려간다 | 틱 소리가 한 층마다 작아지다가 **사라진다.** HUD 메트로놈이 멈춘다. 정적이 가장 큰 공포가 된다 |
| 3-2 | 청력검사 부스 (세트피스) | 문이 잠긴다. 헤드폰. "삐 소리가 들리면 버튼을 누르세요." 유리 너머에 **너스 허시**. 정확히 누르면 그녀는 다른 부스로 간다. 놓치거나 잘못 누르면 그녀가 다이얼을 돌린다. **이명 소리와 검사음이 비슷해져서** '이게 검사음인가 내 귀인가'를 가려야 한다 |
| 3-3 | 조율 의자실 | 아이용 의자 32석, 헤드폰, 가죽끈. 의자 등받이마다 건반 번호. **"하루 6시간"** 일과표 |
| 3-4 | 연구 녹음 (악보 기록) | 보스버그의 목소리 "공명은 거짓말을 하지 않아요." → **카세트 끝의 여자 목소리와 같은 목소리다** (Q1 단서) |
| 3-5 | 잔향실 | 소리가 8초 남는다. **레레**가 내 소리를 3초 뒤 엉뚱한 곳에서 따라 한다. 이를 역이용해 허시를 유인한다 |
| 3-6 | 역재생 획득 | 레레의 공명 기억(거꾸로 녹음된 노래)을 뒤집어 복원한다 |
| 3-7 | **무향실** (세트피스) | 아무 소리도 없다. **내 심장 소리와 숨소리만** 들린다. 너스 허시가 심박을 듣는다. 멈춰 서서 안내 링에 맞춰 천천히 숨 쉬면 심박이 내려간다 |
| 3-8 | 양호실 | 아이들이 숨어 지내던 흔적. 침대 밑 이름 낙서. 허시의 공명 기억(숨죽인 킥킥 소리) |
| 3-9 | 보스 | **진정:** 1kHz 기준으로 재생 → "…이제 쉬어도 돼." **제압:** 진공관을 뽑는다 |
| 3-10 | **정음실** | 가운데 의자 하나. 벽면에 **키프세이크 선반 87칸.** 86개가 아주 작게 동시에 노래하고, 49번 칸만 비어 있다. 보관 카드: **"No.49 — 원본 436.5Hz → 보정 +13.7센트 → 440.00Hz. 원본 폐기."** 들고 있던 룰라가 처음으로 **스스로 태엽이 풀리며** 멈춘다 |
| 3-11 | 거꾸로 부른 징글 | 티코 징글 테이프를 역재생하면 펠의 숨은 메시지가 나온다. **"탑. 탑을 멈춰. 나를 멈춰."** |
| 3-12 | 엔딩 송 | 「들리지 않는 아이들의 자장가」 |

## P4. Chapter 4 — 불협화음 (Dissonance)

## P6. 엔딩 3종 — 이름은 실제 종지(終止)에서 따왔다

| 엔딩 | 음악적 의미 | 조건 | 결말 |
|------|------------|------|------|
| **변격종지 「아멘」** (진엔딩) | IV→I. 찬송가 끝의 '아-멘'에 쓰여 *아멘 종지*라 불린다 | 내 목소리로 A + (주요 크리처 5종 중 **4종 이상 진정** + 룰라 신뢰가 높음) | 아래 P6.1 |
| (변형) 「흐린 아멘」 | 같은 진행, 다른 편곡 | 내 목소리로 A + 조건 미달 | 화음은 해결되지만 룰라가 스스로 깨진다. 일부 목소리가 남는다. 씁쓸한 결말 |
| **반종지 「완벽한 아이」** (배드) | V에서 끝나는, 열린 채 끝나지 않는 마침 | 룰라의 A를 받는다 | 아래 P6.2 |
| **위종지 「방송」** (비밀) | V→vi. 해결될 것 같다가 엉뚱한 곳으로 빠지는 거짓 마침 | LYRE 소리굽쇠를 가지고 트라이톤을 친다 | 아래 P6.3 |

### P6.1 「아멘」

1. 내 A(436.5Hz)가 들어간다. 룰라의 A(440)와 부딪쳐 **초당 3.5회 맥놀이**가 난다.
2. 86명이 그 맑은 3도에 기대어 **스스로 음을 고쳐 잡기 시작한다** (W2 예외: 의지). F와 C도 순정으로 내려앉고, 화음이 4:5:6이 된다. **맥놀이가 사라진다.**
3. 룰라가 빗살 하나를 휘어 내 A로 내려온다. 오르골과 나의 맥놀이도 멈춘다.
4. 시리즈 전체에서 **한 번도 나오지 않았던 진행**, F → C(IV→I)가 처음 울린다. "아—멘."
5. 지휘자의 마지막 말. "…들린다." 오르간 파이프에서 바람이 빠진다.
6. 객석의 외투들이 하나씩 의자에서 흘러내린다. 홀 천장으로 눈이 내린다.
7. **에필로그:** 카덴스 폴스, 10년 만에 조용한 밤. 연습실 B-49에서 피아노를 조율하는 주인공. A 현은 'P2-8의 선택'대로 남아 있다. 고친 쪽이라면 플레이어가 다시 내릴 수 있다. 크레딧 송 「아멘」.
8. 타이틀 화면의 하이픈 음판이 제자리에 걸린다. 메뉴의 **'라'가 열린다.**

### P6.2 「완벽한 아이」

1. 룰라의 440이 들어간다. 화음이 **평균율로 완성된다.** 하지만 F–A의 초당 13.9회, F–C의 초당 1.18회 맥놀이가 남는다. **끝날 수 없는 화음.**
2. 지휘자의 환희. "완벽해!" 화음은 열린 채 **영원히 유지된다.**
3. 주인공이 49번 자리에 앉는다. 화면이 하얗게 차오른다.
4. **마지막 컷:** 2007-12-21 20:49, WCDF-7 무음 송출. 수사 메모 한 줄. *"실종자 441명."*

### P6.3 「방송」

1. 트라이톤(증4도, '음악 속의 악마'라는 별명이 붙은 음정)이 화음을 찢는다.
2. 오르간이 터진다. 목소리들이 흩어져 홀 밖으로 빠져나간다. 아이들은 풀려나지만 **쉬지는 못한다.**
3. 무너지는 홀을 빠져나오면, 정문 밖에 시동이 걸린 방송 중계차가 서 있다. 안에서 릴 테이프가 돈다.
4. 처음으로 얼굴이 보이는 보스버그. "녹음 완료." 중계차 옆면 로고는 **LYRE.**
5. 멀리 WCDF-7 송신탑에 불이 들어온다. 후속작 떡밥: *OFF-KEY: Broadcast*.

### P6.4 엔딩 공통 규칙

- 모든 엔딩은 '침묵'에서 시작한다. 선택 직후 **2박 침묵**이 온다 (S9 침묵 예고 규칙의 마지막 사용).
- 엔딩 음악은 **실제로 그 종지를 연주한다.** 음악 지식이 없어도 '끝났다', '안 끝났다', '속았다'를 몸으로 느끼게 한다.
