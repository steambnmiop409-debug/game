# [대설계 A] 아트 바이블

> 상위 문서: [00_INDEX](00_INDEX.md) · 이 문서의 트리: **A1 ~ A7**
> 원칙: **"투박하되 엄격하게."** 저해상도 레트로 렌더를 쓰지만, 입체감은 R.E.P.O. 수준까지 끌어올리고, 모든 수치와 소품에는 규칙이 있다.
> **v0.4:** 2D 빌보드 캐릭터와 평면 조명을 버렸다. 3D 리그 캐릭터, 실시간 그림자, PBR 재질로 바꿨다. 심전도 HUD와 '박동에 맞춘 조명'도 뺐다.

## A1. 스타일 정의

### A1.1 기준점

**레트로 픽셀 렌더 위에 R.E.P.O. 수준의 입체감.** 발디의 수학교실처럼 '성의 없어 보이는' 그래픽은 목표가 아니다.
- 단순한 격자 위의 방과 복도. 그러나 벽 두께, 문틀, 걸레받이, 천장 타일까지 **입체로** 세운다
- 저해상도로 렌더한 뒤 **보간 없이 확대**한다. 픽셀과 디더링이 보인다
- **3D 리그 캐릭터** (엉덩이·몸통·머리·팔·다리 관절, 절차적 걷기 애니메이션)
- **실시간 그림자**: 손전등과 가장 가까운 형광등 하나. 캐릭터가 공간에 '서 있다'
- PBR 재질 (거칠기·금속성), 정점 색으로 구운 모서리 그늘(AO), 방마다 다른 색의 안개
- 90년대 에듀테인먼트와 병원 안내 비디오 같은 UI

### A1.2 '대충'과 '의도된 투박함'을 가르는 기준

| 대충 (금지) | 의도된 투박함 (목표) |
|------------|---------------------|
| 텍스처 해상도가 제각각 | 모든 텍스처가 **정해진 크기 단계**만 쓴다 (A2.2) |
| 색이 무작위 | **마스터 팔레트 64색** 안에서만 고른다 |
| 빈 방 | **한 방에 한 이야기** (A3.2) |
| 캐릭터가 배경에 묻힘 | **실루엣과 색이 정해져 있다**: 분홍 인형탈, 흰 가운, 노란 카디건과 맨발. 손전등 그림자가 캐릭터를 바닥에 붙인다 |
| 조명이 의미 없음 | 조명이 **이야기를 따른다**: 구역별 형광등 상태(켜짐·깜빡임·꺼짐), 풀 수 없는 문제 뒤의 정전에서 **304호만** 켜져 있다 |
| 낡음이 균일 | 2001년의 '정지', 2009년의 '부식', 그리고 **조직의 번짐**이 세 층으로 나뉜다 (A3.3) |

### A1.3 흉터 없는 몸 — 이 게임 공포의 시각 규칙

> 발달 재지시(DRI)로 바뀐 몸은 모두 **"태어날 때부터 그랬던 것처럼"** 보인다. 이것이 이 게임의 시각적 정체성이다.
> 피 한 방울 없이도, 괴물을 **정면으로** 보여 주면서 무섭게 만들 수 있다.

| # | 규칙 | 내용 |
|---|------|------|
| 1 | **이음매가 없다** | 여분의 팔, 눈꺼풀이 없는 눈, 이어진 목. 모든 형태는 **매끈한 피부로 자연스럽게 이어진다.** 봉합선, 흉터, 붕대, 수술 자국은 그리지 않는다 |
| 2 | **피는 없다** | 피, 상처, 절단면, 시신은 그리지 않는다 (B6). 붉은색은 벽화와 표지판 같은 **사물의 색**으로만 쓴다 |
| 3 | **형태는 정면으로** | 후기 실험체는 숨기지 않는다. 밝은 형광등 아래, 화면 한가운데에 **몸 전체**를 보여 준다. 공포는 그 몸이 '평범하게' 서 있다는 데서 나온다 |
| 4 | **얼굴은 아이로 남긴다** | 몸이 아무리 달라도 얼굴은 그 나이의 평범한 아이다. 웃고, 겁먹고, 지루해한다. 이 대비가 핵심이다 |
| 5 | **회진의 얼굴만은 없다** | 회진(어른들)은 반대로 **얼굴이 없다.** 아이들은 얼굴이 남았고, 어른들은 얼굴을 잃었다 |
| 6 | **추함으로 겁주지 않는다** | 형태를 일그러뜨리거나 썩게 그리지 않는다. 피부는 건강하고 깨끗하다. 무서운 것은 '사람의 조건이 지워졌다'는 사실이다 (B6.1) |
| 7 | **우나는 예외 없이 사람처럼** | 우나의 모델에는 이상한 점이 하나도 없다. 이상한 것은 **주변**이다. 입김이 없고, 그림자 속 가슴이 움직이지 않는다 |

### A1.4 조직(잔여체의 살)의 표현 규칙

| 단계 | 표현 | 챕터 |
|------|------|------|
| 0 | 없음 | Ch1 |
| 1 | 배관 이음매와 콘센트 주변에 **연한 살빛 얼룩** | Ch2 |
| 2 | 벽과 천장을 따라 **뿌리처럼 뻗은 줄기** | Ch3 |
| 3 | 문틀, 창틀, 가구가 살에 반쯤 덮인다. 표면에 **작은 손바닥 자국**이 떠올랐다 가라앉는다 | Ch4 |
| 4 | 공간 전체가 살. 배관이 혈관처럼 부풀었다 가라앉는다 | Ch5 |

- 조직은 **촉촉하지 않다.** 건강한 아이의 피부처럼 매끈하고 보송하다. 그래서 더 이상하다.

## A2. 기술 규격

### A2.1 렌더링 (구현)

| 항목 | 규격 |
|------|------|
| 내부 해상도 | 화면의 **0.42배**로 렌더한 뒤 최근접 확대 (설정에서 조절. 저사양 0.22) |
| 시야각 | 수직 70° (달릴 때 76°) |
| 텍스처 필터 | 확대 최근접(픽셀이 보인다), 축소 밉맵 |
| 재질 | PBR (`MeshStandardMaterial`), 정점 색 AO (벽 아래·모서리가 어둡다) |
| 조명 | 손전등 스포트라이트(쿠키 텍스처, 그림자), 가장 가까운 형광등 7개에 점광원 풀, 가장 가까운 하나에 그림자, 방마다 반구광. 손전등은 가까운 벽에서 자동으로 약해진다 (과노출 방지) |
| 안개 | 방마다 색과 밀도 (`FogExp2`) |
| 후처리 (셰이더 하나) | ACES 톤매핑, 색수차, 비네팅, 필름 그레인, **4×4 바이어 디더링**, 페이드·하얀 번짐·붉은 기운 |
| 금지 | 블룸, 모션블러, 피사계심도 |
| 게임 속 TV 화면 | 128×96 캔버스에 VHS 잡음, 날짜 도장, 자막 |
| 1인칭 손 | 별도 장면으로 깊이를 지우고 위에 그린다 (벽에 묻히지 않는다) |
| 입김 | 냉동실에서 **주인공의 입김만** 파티클로 나온다 (우나는 없다) — Ch2 |

### A2.2 텍스처 크기 단계

| 단계 | 크기 | 용도 |
|------|------|------|
| S | 32×32 | 작은 소품, 아이콘 |
| M | **64×64** | 벽, 바닥, 천장 타일 (기본) |
| L | 128×128 | 포스터, 표지판, 문, 그림, 차트 |
| XL | 256×256 | 감사 편지 벽, 석고 얼굴 벽, 실험 번호표 같은 '간판' 오브젝트 |
| 얼굴 | 64~128px 캔버스 | 캐릭터 얼굴 (표정은 텍스처 교체) |

- **모든 텍스처는 코드로 그린다** (`src/world/textures.ts`, 캔버스 + 시드 고정 난수). 텍스처 하나당 **최대 32색**, 게임 전체는 **마스터 팔레트 64색**('할로 파인스 64'). 구역마다 그중 16~24색을 주로 쓴다.

### A2.3 지오메트리

| 항목 | 값 |
|------|----|
| 격자 단위 | 0.5m (벽·문·길 찾기 공통) |
| 천장 높이 | 병동 3m · 임상연구동 2.7m · 설계동 2.4m · 별관 B는 **방마다 다르다** · C-0 배관 동굴 4~12m · 로비 9m |
| 폴리곤 | 박스, 원기둥, 구, 회전체로 조립한다. 곡면은 8~16각 |
| 디테일 표현 | 큰 형태는 지오메트리(문틀, 침대, 카트, 손가락 마디), 작은 글씨와 얼룩은 텍스처 |

## A3. 디테일 규칙

### A3.1 디테일 3층 법칙

| 층 | 내용 | 예: 화상 치료실 304호 |
|----|------|----------------------|
| **1. 실루엣** | 공간의 정체를 한눈에 알려 주는 형태 | 병상 하나, 수액 거치대, 창가의 작은 의자 |
| **2. 텍스처 서사** | 읽으면 이야기가 되는 표면 | 문틀의 키재기 자국과 날짜(1994), 침대 머리맡의 호피 스티커, 벽의 '오늘의 기분' 표정 차트 |
| **3. 상호작용** | 만지면 반응하는 것 | 서랍 속 1994년 환자 팔찌 (주인공의 것), 창(주차장이 보인다) |

### A3.2 '한 방에 한 이야기' 규칙

- 모든 방에는 **글 없이도 읽히는 작은 이야기가 하나 이상** 있어야 한다.
- 예시
  - 공중전화 부스: 안쪽 벽에 아이 글씨로 'HOME'이 수십 번 긁혀 있다
  - 직원 휴게실: 컵걸이마다 이름이 적힌 머그컵. 2001년 3월 달력에서 그 뒤가 넘겨지지 않았다
  - 급식실: 식판 수십 개, 숟가락이 한 번도 들리지 않은 채 먼지가 쌓였다
  - 수면연구실: 침대가 없다. 벽에 아이가 그린 눈 그림이 빽빽하다
  - 공동 병실: 침대 세 개가 붙어 있고, 베개는 하나다
  - 우나의 방: 벽의 날짜 표시, 부치지 못한 편지 더미, 루스의 카디건
  - 주차장의 세단: 시동이 걸린 채 연료가 다 떨어졌다. 조수석에 편지

### A3.3 시간의 세 층

| 층 | 의미 | 표현 |
|----|------|------|
| **2001 (정지)** | 실험 90의 날 멈춘 순간 | 켜진 채 멈춘 TV, 펼쳐진 차트, 식은 커피 자국 |
| **2009 (부식)** | 그 뒤 8년 | 먼지 데칼, 벗겨진 포스터(알파 컷아웃), 깨진 창으로 들어온 낙엽 |
| **조직 (번짐)** | 잔여체의 몸 | A1.4의 단계별 표현 |

### A3.4 글자 규칙 (배경은 미국, 게임 언어는 한국어)

| 대상 | 표기 |
|------|------|
| 벽의 표지판, 포스터, 간판 텍스처 | **영어** (현지 그대로). 플레이어가 '살피기' 하면 한국어 번역 자막이 뜬다 |
| 서류, 편지, 차트, 녹음 | 읽거나 들을 때 **한국어**로 보여 준다. 원본 영어 이미지는 배경 텍스처로 남긴다 |
| UI, 대사, 자막 | 한국어 |

## A5. 캐릭터 모델 규격

### A5.1 공통 (구현)

| 항목 | 규격 |
|------|------|
| 형식 | 기본 도형(박스·원기둥·구·회전체)으로 조립한 **3D 리그**. 관절: 엉덩이, 몸통, 머리, 위팔·아래팔, 허벅지·정강이 |
| 애니메이션 | 절차적 걷기 (보폭·팔 흔들기), 앉기, 웅크리기, 눕기 (스크립트가 몸 전체 자세를 정할 수 있다) |
| 얼굴 | 캔버스 텍스처. **아이의 평범한 표정에서 다른 표정으로 중간 단계 없이 즉시** 바뀐다 (발디식 불쾌감) |
| 걸음 박자 | 회진과 호피 스와피는 **일정한 박자로 한 걸음씩** 끊어 걷는다. 발소리(마림바)와 같은 박자 |
| 형태 완화 옵션 | 후기 실험체의 몸을 실루엣으로 바꾸는 대체 모델을 함께 만든다 (G13) |

### A5.2 캐릭터별 사양

| 캐릭터 | 키 | 시각 규칙 |
|--------|----|----------|
| **우나** | 1.36m (눈높이) | **이상한 점이 없다** (A1.3 규칙 7). 맨발, 환자복, 노란 카디건, 앞머리. 숨 쉬는 움직임이 없다. 눈을 깜빡이지 않는다 |
| **회진** | 성인 | 매끈한 얼굴(이목구비 없음), 흰 가운, 실제 명찰 텍스처, 클립보드 |
| **호피 스와피** | 2m 안팎 | 분홍 인형탈, 주둥이, 손가락이 머리에 달린 팔, **어깨에 붙은 토끼 발 다리**, 등 지퍼. 관절이 아닌 곳에서 꺾인다. 좁은 곳에서는 납작하게 접힌다 |

| **크레이들** | 아이 | 팔 여덟 개, 천장 버전과 바닥 버전 |
| **탱글** | 아이 셋 | 목 뒤를 잇는 매끈한 살의 줄 |

## A6. UI와 HUD

### A6.1 UI 스타일

- **80~90년대 병원 서식과 의료 장비의 화면.** 초록 단색 모니터, 먹지 복사 서식, 클립보드.
- 글꼴은 한글 픽셀 폰트를 쓴다 (후보: *갈무리*, *Neo둥근모*. 둘 다 SIL OFL 라이선스로 알려져 있으며 적용 전에 원문을 다시 확인한다). 손글씨가 필요한 곳(우나의 편지, 아이 그림)은 별도의 크레용 비트맵.

### A6.2 HUD 배치 (구현)

```
┌──────────────────────────────────────────────────────────┐
│ 목표                                            장소 이름 │
│ 신고자를 찾는다                                  ▣▣▣▢▢▢   │ ← 호피 부품
│                                                          │
│                          ·                               │ ← 조준점 (대상 위에서 커진다)
│                     [E] 진료 차트 읽기                     │ ← 상호작용 안내
│                                                          │
│  (아래: 1인칭 왼팔 — 침식 무늬)        ┌ SN-RI 재지시기 ──┐ │
│                                      │ 판독 결과 (초록)  │ │ ← 판독 패널
│           마커스  자막 ...             └─────────────────┘ │
│  [F 손전등] [재지시기 · 진정 ×3] [직원 카드]                 │ ← 소지품
└──────────────────────────────────────────────────────────┘
```

| 요소 | 형태 |
|------|------|
| 목표 | 왼쪽 위, 작은 글씨 |
| 장소 | 오른쪽 위, 방에 들어갈 때 잠깐 |
| 판독 | 초록 단색 패널. 한 줄씩 찍힌다. 기기 화면(3D)에도 영어로 같은 결과 |
| 진정 카드 | 소지품 칸의 남은 수, 기기 화면 `RELAX x3` |
| 숨 | 달릴 때만 나오는 가는 막대 |
| 침식 | **숫자 없음.** 1인칭 왼팔의 피부 무늬 |
| 자막 | 화자 이름 색 구분, 크기 3단계 |

### A6.3 메뉴 화면

- **일시정지 = 구급 활동 기록지.** 시각, 장소, '환자' 칸에는 우나의 이름과 '활력 징후' 칸 (모두 비어 있다).
- **저장 = 병상**에 눕는다. 깨어나면 우나가 같은 자세로 앉아 있다.
- **실패 = 구급 활동 기록지의 주증상 칸**에 원인이 적힌다.
