# [대설계 A] 아트 바이블

> 상위 문서: [00_INDEX](00_INDEX.md) · 이 문서의 트리: **A1 ~ A7**
> 원칙: **"투박하되 엄격하게."** 발디 시대의 조잡한 3D를 쓰지만, 모든 수치와 소품에는 규칙이 있다.

---

## A1. 스타일 정의

### A1.1 기준점

**2018년 인디 호러 『발디의 수학교실』 시절의 그래픽 문법**을 따른다.
- 단순한 박스형 공간 (격자 위의 방과 복도)
- 저해상도에 **보간 없이 픽셀이 그대로 보이는**(포인트 필터링) 텍스처
- **늘 카메라를 바라보는 2D 빌보드 캐릭터**
- 그림자 없는 평면 조명
- 90년대 에듀테인먼트 CD-ROM 같은 UI

### A1.2 '대충'과 '의도된 투박함'을 가르는 기준

| 대충 (금지) | 의도된 투박함 (목표) |
|------------|---------------------|
| 텍스처 해상도가 제각각 | 모든 텍스처가 **정해진 크기 단계**만 쓴다 (A2.2) |
| 색이 무작위 | **마스터 팔레트 64색** 안에서만 고른다 |
| 빈 방 | **한 방에 한 이야기** (A3.2) |
| 캐릭터가 배경에 묻힘 | 스프라이트 **1px 어두운 외곽선** 규칙 |
| 조명이 의미 없음 | 조명이 **박자와 동기화** (틱마다 3% 밝아짐) |
| 낡음이 균일 | 1996년의 '정지'와 2006년의 '부식'이 **두 층으로 나뉨** (A3.3) |

## A2. 기술 규격

### A2.1 렌더링

| 항목 | 규격 |
|------|------|
| 내부 해상도 | **640×360** 렌더 후 화면에 정수배 최근접 확대 (옵션: '원본 해상도') |
| 시야각 | 수직 60° |
| 텍스처 필터 | 최근접(포인트), 밉맵 없음 |
| 조명 | 실시간 그림자 없음. 방마다 **'방 색조'**(정점 색) + 거리 안개(구역별 색) |
| 캐릭터 그림자 | 발밑의 단순한 원형 그림자 하나 |
| 색 깊이 효과 | 안개 그라데이션에 **4×4 바이어 디더링**을 써서 16비트 시절의 색 띠 재현 |
| 금지 | 블룸, 모션블러, 피사계심도, 노멀맵 |
| 게임 속 TV 화면 | 그 화면에만 CRT 스캔라인과 색 번짐 셰이더 |
| 허밍 왜곡 | 허밍 근원 근처에서 정점이 화면 기준 1~2px **박자에 맞춰 떨린다.** 텍스처 UV도 미세하게 일렁인다 |

### A2.2 텍스처 크기 단계 (이 단계 밖의 크기는 쓰지 않는다)

| 단계 | 크기 | 용도 |
|------|------|------|
| S | 32×32 | 작은 소품, 아이콘 |
| M | **64×64** | 벽, 바닥, 천장 타일 (기본) |
| L | 128×128 | 포스터, 표지판, 문, 그림 |
| XL | 256×256 | 스트로보 원판, 오르간 정면 같은 '간판' 오브젝트 |
| 스프라이트 | 높이 최대 512px | 캐릭터 |

- 텍스처 하나당 **최대 32색**, 게임 전체는 **마스터 팔레트 64색**('알레그레토 64'). 구역마다 그중 16~24색을 주로 쓴다.

### A2.3 지오메트리

| 항목 | 값 |
|------|----|
| 격자 단위 | 2.5m |
| 천장 높이 | 일반 3m · 연습실 **2.4m** (답답함) · 로비 9m · 발표회장 18m |
| 폴리곤 | 박스와 쐐기 위주. 곡면은 8각 이하로 근사 |
| 디테일 표현 | 지오메트리가 아니라 **텍스처로** 그린다 (몰딩, 걸레받이, 흡음 패널) |

## A3. 디테일 규칙

### A3.1 디테일 3층 법칙 (모든 공간에 적용)

| 층 | 내용 | 예: 연습실 B-12 |
|----|------|----------------|
| **1. 실루엣** | 공간의 정체를 한눈에 알려 주는 형태 | 좁은 방, 업라이트 피아노, 보면대, 흡음 패널 |
| **2. 텍스처 서사** | 읽으면 이야기가 되는 표면 | 문의 연습 출석부(시간이 늘어남), 건반 위 손톱 자국, 메트로놈이 **208**에 맞춰져 있음 |
| **3. 상호작용** | 만지면 반응하는 것 | 피아노(악보 기록), 메트로놈(멈출 수 있다. 멈추면 그 방 차폐도 사라진다) |

### A3.2 '한 방에 한 이야기' 규칙

- 모든 방에는 **글 없이도 읽히는 작은 이야기가 하나 이상** 있어야 한다.
- 예시
  - 교무실: 걸이마다 직원 이름이 적힌 머그컵이 걸려 있고, 걸이 하나만 비어 있다. 이름표는 'T. 펠' (그는 사라진 사람 명단에도 없다)
  - 레슨동 '라' 교실: 키재기 문틀에 키 대신 **음이름**이 적혀 있다. 아이가 '자라는' 기준이 키가 아니라 음이었다
  - 분실물 보관함: 장갑 한 짝, 아이 운동화 한 짝, 그리고 귀마개가 **유난히 많다**
  - 그랑 살롱: 피아노 의자의 쿠션이 한쪽만 꺼져 있다. 학생이 앉는 자리가 아니라 **선생님 자리**
  - 무향실 문 안쪽: 아이 손높이에 긁힌 자국

### A3.3 시간의 두 층

| 층 | 의미 | 표현 |
|----|------|------|
| **1996 (정지)** | 20:49에 멈춘 순간 | 펼쳐진 악보, 의자에 걸린 외투, 먹다 남은 간식, 켜진 채 멈춘 TV |
| **2006 (부식)** | 그 뒤 10년 | 먼지 데칼, 벗겨진 포스터(알파 컷아웃), 물 얼룩, 깨진 창으로 들어와 쌓인 눈 |

## A5. 캐릭터 스프라이트 규격

### A5.1 공통

| 항목 | 규격 |
|------|------|
| 방향 | **단일 시점 빌보드** (Y축 고정. 항상 플레이어를 정면으로 본다) |
| 외곽선 | 1px, 팔레트의 가장 어두운 색 |
| 프레임 | 대기 2 · 걷기 2~4 · 특수 1~3 · **'얼굴 전환' 1** |
| 얼굴 전환 | 웃는 얼굴에서 공포 얼굴로 **중간 프레임 없이 즉시** 바뀐다 (발디식 불쾌감) |
| 박자 동기 | 박자 묶임 크리처는 **틱마다 프레임이 넘어간다** |

### A5.2 캐릭터별 사양

| 캐릭터 | 크기(px) | 프레임 | 시각 규칙 |
|--------|---------|--------|----------|
| **티코** | 256×512 | 대기 2, 걷기(좌우 진자) 2, 화남 1, 지휘봉 1 | 진자 추의 높이로 BPM을 표현한다 (Largo는 위, Presto는 입 앞). 얼굴은 앞판에 그린 그림이라 **입이 움직이지 않는다** |
| **벨로** | 384×512 | 들숨 3, 날숨 3, 돌진 2 | 들숨 프레임마다 풀무 주름 4→8칸. 단추 눈 하나에는 하이라이트, 빈 눈에는 없음 |
| **포키즈** | 32×48 | 점프 2 | 틱마다 점프 |
| **마담 그랑데** | 512×384 | 걷기 3, 뚜껑 열기 2, 지시봉 1 | 해머 이빨은 텍스처 반복이 아니라 **하나하나 그린다** (88개) |
| **페이지 터너** | 128×448 | 2 | 얼굴 악보에 그려진 음표가 프레임마다 바뀐다 |
| **싱어롱즈** | 96×128 ×12 | 노래 2 | 12명이 색상환 12색. 화음이 바뀔 때만 프레임이 넘어간다 |
| **너스 허시** | 192×512 | 미끄러짐 2, 바늘 튐 1 | 계기판 바늘은 별도 레이어로 실제 소리 크기에 반응한다 |
| **레레** | 128×256 | 1 + 잔상 | 같은 스프라이트를 시간 차를 두고 3번 겹쳐 그린다 (투명도 100/50/25%) |
| **래프 트랙** | 128×256 | 박수 2, 고개 돌림 1 | 판지 가면의 인쇄 망점(하프톤) 텍스처 |
| **고장난 악단** | 각 128~256 | 2~3 | 표정은 단순하지만 부서진 곳(금, 찌그러짐, 빠진 음판)은 정밀하게 |
| **어셔** | 128×384 | 걷기 2 | 손전등 원뿔은 3D 반투명 메시 (시야 표시) |
| **룰라** | 64×96 | 회전 4 | 눈은 태엽이 감겨 있을 때만 뜬다 |
| **여든여섯** | 64×128 ×86 | 1 | 반투명 실루엣. 각자 건반 번호 배지 |
| **지휘자** | (지오메트리) | — | 오르간 정면 파이프 88개가 3D. 스웰 셔터가 박자에 맞춰 여닫힌다 |

## A6. UI와 HUD

### A6.1 UI 스타일

- **90년대 에듀테인먼트 UI.** 입체 경사 버튼(윈도우 95 계열), 원색 테두리, 별 스티커.
- 글꼴은 한글 픽셀 폰트를 쓴다 (후보: *갈무리*, *Neo둥근모*. 둘 다 SIL OFL 라이선스로 알려져 있으며 적용 전에 원문을 다시 확인한다). 손글씨가 필요한 곳(연습일지, 아이 쪽지)은 별도의 크레용 비트맵.

### A6.2 HUD 배치

```
┌──────────────────────────────────────────────────────────┐
│                     [♩ 메트로놈  72]                       │  ← 박자 아이콘 + BPM
│                                                          │
│ (이명: 화면 가장자리의 흰 선)                                │
│                                                          │
│                          +                               │  ← 조준점 (작은 점)
│                                                          │
│                                                          │
│ [풀무 숨 ▮▮▮▮▯]                    [공명기: 초록 스트로보]   │
│ [가방: □ □ □ □]                    [● 녹음 4.0s]          │
└──────────────────────────────────────────────────────────┘
```

| 요소 | 형태 |
|------|------|
| 메트로놈 | 작은 진자 아이콘. 박자마다 좌우로 흔들린다 |
| 숨 | **아코디언 풀무** 아이콘이 접혔다 펴진다 |
| 이명 | 숫자 없이 화면 가장자리의 흰 선 |
| 공명기 | 초록 단색 CRT 원판. 목표 음과 맞으면 무늬가 멈춘다 |
| 가방 | 4칸. 소모품 아이콘은 32×32 |

### A6.3 메뉴 화면

- **일시정지 = 성적표.** 과목: 청음, 리듬, 음정 유지, 그리고 이번 챕터 기록 수집률.
- **저장 = 연습일지**에 날짜, 시간, 보면대 위치가 손글씨로 적힌다.
- **실패 = 성적표 맨 아래 칸에 크리처의 한 줄 평** (G12.2).

### A7.3 아이 그림 가이드

- 크레용 질감, 128×128. **아이의 시점과 비율**로 그린다 (어른은 거대하고, 손이 크고, 입이 없다).
- 반복 모티프: 손잡은 티코, 무서운 시계탑, 귀를 막은 아이, '음표 눈물', 빈 의자 하나에 동그라미.
