# [대설계 A] 아트 바이블

> 상위 문서: [00_INDEX](00_INDEX.md) · 이 문서의 트리: **A1 ~ A7**
> 원칙: **"투박하되 엄격하게."** 발디 시대의 조잡한 3D를 쓰지만, 모든 수치와 소품에는 규칙이 있다.

---

## A1. 스타일 정의

### A1.1 기준점

**2018년 인디 호러 『발디의 수학교실』 시절의 그래픽 문법**을 따른다.
- 단순한 박스형 공간 (격자 위의 방과 복도)
- 저해상도에 **보간 없이 픽셀이 그대로 보이는**(포인트 필터링) 텍스처
- **늘 카메라를 바라보는 2D 빌보드 캐릭터**
- 그림자 없는 평면 조명
- 90년대 에듀테인먼트 CD-ROM 같은 UI

### A1.2 '대충'과 '의도된 투박함'을 가르는 기준

| 대충 (금지) | 의도된 투박함 (목표) |
|------------|---------------------|
| 텍스처 해상도가 제각각 | 모든 텍스처가 **정해진 크기 단계**만 쓴다 (A2.2) |
| 색이 무작위 | **마스터 팔레트 64색** 안에서만 고른다 |
| 빈 방 | **한 방에 한 이야기** (A3.2) |
| 캐릭터가 배경에 묻힘 | 스프라이트 **1px 어두운 외곽선** 규칙 |
| 조명이 의미 없음 | 조명이 **박자와 동기화** (틱마다 3% 밝아짐) |
| 낡음이 균일 | 1996년의 '정지'와 2006년의 '부식'이 **두 층으로 나뉨** (A3.3) |

### A1.3 바디 호러의 시각 규칙 (이 게임 공포의 핵심)

> 저해상도는 약점이 아니라 무기다. **픽셀이 거칠수록 플레이어의 상상이 빈자리를 채운다.**

| # | 규칙 | 내용 |
|---|------|------|
| 1 | **흔적은 하나나 둘** | 살아 있는 악기 하나에 사람의 흔적은 **한두 개만** 둔다. 진짜 머리카락, f홀 너머의 눈, 펠트 속 손가락, 숨 쉬는 갈비뼈 모양 틀, 원통의 이. 세 개가 넘으면 괴물이 되고, 하나면 **사람**이 된다 |
| 2 | **피는 없다** | 피, 상처, 절단면, 시신은 그리지 않는다 (B6). 붉은색은 벨벳, 풀무 줄무늬, 립스틱처럼 **사물의 색**으로만 쓴다 |
| 3 | **움직임이 먼저** | 사람의 흔적은 정지 화면이 아니라 **작은 움직임**으로 드러낸다. 눈 깜빡임 1프레임, 손가락 꼼지락 2프레임, 풀무 들숨 3프레임 |
| 4 | **멀리, 어둡게, 짧게** | 흔적이 많은 존재(미완성품들)는 안개 속, 어둠 속, 2초 이하로만 보여 준다 |
| 5 | **귀여움을 지운다** | 공포는 귀여운 디자인 위에 **사람 하나를 얹을 때** 생긴다. 크리처의 기본형은 반드시 실제 장난감처럼 귀엽게 그리고, 그 위에 흔적을 더한다 |
| 6 | **소리가 그림보다 먼저** | 흔적을 보기 전에 소리로 먼저 알게 한다 (숨, 흐느낌, 허밍). 그림은 확인일 뿐이다 |

## A2. 기술 규격

### A2.1 렌더링

| 항목 | 규격 |
|------|------|
| 내부 해상도 | **640×360** 렌더 후 화면에 정수배 최근접 확대 (옵션: '원본 해상도') |
| 시야각 | 수직 60° |
| 텍스처 필터 | 최근접(포인트), 밉맵 없음 |
| 조명 | 실시간 그림자 없음. 방마다 **'방 색조'**(정점 색) + 거리 안개(구역별 색) |
| 캐릭터 그림자 | 발밑의 단순한 원형 그림자 하나 |
| 색 깊이 효과 | 안개 그라데이션에 **4×4 바이어 디더링**을 써서 16비트 시절의 색 띠 재현 |
| 금지 | 블룸, 모션블러, 피사계심도, 노멀맵 |
| 게임 속 TV 화면 | 그 화면에만 CRT 스캔라인과 색 번짐 셰이더 |
| 숨 쉬는 사물 | 살아 있는 악기 근처의 소품(악보, 커튼)이 그 악기의 숨 주기에 맞춰 1~2px 흔들린다 |

### A2.2 텍스처 크기 단계 (이 단계 밖의 크기는 쓰지 않는다)

| 단계 | 크기 | 용도 |
|------|------|------|
| S | 32×32 | 작은 소품, 아이콘 |
| M | **64×64** | 벽, 바닥, 천장 타일 (기본) |
| L | 128×128 | 포스터, 표지판, 문, 그림 |
| XL | 256×256 | 스트로보 원판, 졸업 게시판, 오르간 정면 같은 '간판' 오브젝트 |
| 스프라이트 | 높이 최대 512px | 캐릭터 |

- 텍스처 하나당 **최대 32색**, 게임 전체는 **마스터 팔레트 64색**('알레그레토 64'). 구역마다 그중 16~24색을 주로 쓴다.

### A2.3 지오메트리

| 항목 | 값 |
|------|----|
| 격자 단위 | 2.5m |
| 천장 높이 | 일반 3m · 연습실 **2.4m** (답답함) · 지하 공방 **2.2m** · 로비 9m · 발표회장 18m |
| 폴리곤 | 박스와 쐐기 위주. 곡면은 8각 이하로 근사 |
| 디테일 표현 | 지오메트리가 아니라 **텍스처로** 그린다 |

## A3. 디테일 규칙

### A3.1 디테일 3층 법칙 (모든 공간에 적용)

| 층 | 내용 | 예: 연습실 B-12 |
|----|------|----------------|
| **1. 실루엣** | 공간의 정체를 한눈에 알려 주는 형태 | 좁은 방, 첼로 하나, 보면대, 흡음 패널 |
| **2. 텍스처 서사** | 읽으면 이야기가 되는 표면 | 문의 연습 출석부(시간이 늘어남), 메트로놈이 **208**에 맞춰져 있음, 보면대에 붙은 엄마 사진 |
| **3. 상호작용** | 만지면 반응하는 것 | 첼로(허락받은 연주), 메트로놈(멈출 수 있다. 멈추면 그 방 차폐도 사라진다) |

### A3.2 '한 방에 한 이야기' 규칙

- 모든 방에는 **글 없이도 읽히는 작은 이야기가 하나 이상** 있어야 한다.
- 예시
  - 교무실: 걸이마다 직원 이름이 적힌 머그컵이 걸려 있고, 걸이 하나만 비어 있다. 이름표는 'T. 펠' (그는 실종자 명단에도 없다)
  - 레슨동 '도' 교실: 건반반 출석 그래프가 달마다 줄어든다. 마지막 칸은 '1'
  - 분실물 보관함: 장갑 한 짝, 아이 운동화 한 짝, 그리고 **귀마개가 유난히 많다**
  - 손 교정실: 가죽끈 하나가 아직 아이 손목 굵기로 묶여 있다
  - 양호실: '이빨 요정' 깡통 선반. 깡통마다 이름표와 숫자
  - 치수실: 키재기 자국 옆에 키 대신 **악기 사이즈**가 적혀 있다 (1/4, 1/2, 3/4, 4/4)
  - 보존실 구석: 어른 크기의 정장과 하이힐이 산처럼 쌓여 있다
  - 객석: 의자 팔걸이마다 진주 목걸이, 손목시계, 반지

### A3.3 시간의 두 층

| 층 | 의미 | 표현 |
|----|------|------|
| **1996 (정지)** | 12월 21일 밤에 멈춘 순간 | 펼쳐진 악보, 의자에 걸린 외투, 먹다 남은 간식, 켜진 채 멈춘 TV, '졸업 축하' 리본 |
| **2006 (부식)** | 그 뒤 10년 | 먼지 데칼, 벗겨진 포스터(알파 컷아웃), 물 얼룩, 깨진 창으로 들어와 쌓인 눈 |

## A5. 캐릭터 스프라이트 규격

### A5.1 공통

| 항목 | 규격 |
|------|------|
| 방향 | **단일 시점 빌보드** (Y축 고정. 항상 플레이어를 정면으로 본다) |
| 외곽선 | 1px, 팔레트의 가장 어두운 색 |
| 프레임 | 대기 2 · 걷기 2~4 · 특수 1~3 · **'흔적' 1~3** · **'얼굴 전환' 1** |
| 얼굴 전환 | 귀여운 얼굴에서 공포 얼굴로 **중간 프레임 없이 즉시** 바뀐다 (발디식 불쾌감) |
| 흔적 레이어 | 사람의 흔적(눈, 손가락, 숨)은 **별도 레이어**로 그려 따로 애니메이션한다. 접근성 옵션에서 실루엣으로 바꿀 수 있다 (G13) |
| 박자 동기 | 박자 묶임 크리처는 **틱마다 프레임이 넘어간다** |

### A5.2 캐릭터별 사양

## A6. UI와 HUD

### A6.1 UI 스타일

- **90년대 에듀테인먼트 UI.** 입체 경사 버튼(윈도우 95 계열), 원색 테두리, 별 스티커.
- 글꼴은 한글 픽셀 폰트를 쓴다 (후보: *갈무리*, *Neo둥근모*. 둘 다 SIL OFL 라이선스로 알려져 있으며 적용 전에 원문을 다시 확인한다). 손글씨가 필요한 곳(연습일지, 아이 쪽지)은 별도의 크레용 비트맵.

### A6.2 HUD 배치

```
┌──────────────────────────────────────────────────────────┐
│                     [♩ 메트로놈  72]                       │  ← 박자 아이콘 + BPM
│                                                          │
│ (이명: 화면 가장자리의 흰 선)                                │
│                                                          │
│                          +                               │  ← 조준점 (작은 점)
│                                                          │
│                                                          │
│ [풀무 숨 ▮▮▮▮▯]                    [공명기: 초록 스트로보]   │
│ [가방: □ □ □ □]                    [● 녹음 4.0s · 슬롯 A]  │
└──────────────────────────────────────────────────────────┘
```

| 요소 | 형태 |
|------|------|
| 메트로놈 | 작은 진자 아이콘. 박자마다 좌우로 흔들린다 |
| 숨 | **아코디언 풀무** 아이콘이 접혔다 펴진다 |
| 이명 | 숫자 없이 화면 가장자리의 흰 선 |
| 공명기 | 초록 단색 CRT 원판. 목표 음과 맞으면 무늬가 멈춘다. 녹음된 신호는 아이콘으로 표시 (소리굽쇠, 종, 손뼉, 자, 입술, 하트) |
| 가방 | 4칸. 소모품 아이콘은 32×32 |

### A6.3 메뉴 화면

- **일시정지 = 성적표.** 과목: 청음, 리듬, 음정 유지, 그리고 이번 챕터 기록 수집률.
- **저장 = 연습일지**에 날짜, 시간, 보면대 위치가 손글씨로 적힌다.
- **실패 = 성적표 맨 아래 칸에 크리처의 한 줄 평** (G12.2).

## A7. 소품 카탈로그와 게시물 문구

### A7.1 핵심 소품 (구역마다 반드시 배치)

| 소품 | 등장 | 의미 |
