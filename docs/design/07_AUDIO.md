# [대설계 S] 사운드 · 음악 바이블

> 상위 문서: [00_INDEX](00_INDEX.md) · 이 문서의 트리: **S1 ~ S10**
> 이 게임의 소리는 **몸의 소리**다. 건물은 심장이 뛰고 숨을 쉬며, 아이들은 저마다 다른 박동을 가졌다. 그리고 우나에게서는 아무 소리도 나지 않는다.

---

## S1. 원칙

| # | 원칙 | 의미 |
|---|------|------|
| 1 | **모든 소리는 실제 악기로 만든다** | 효과음도 실제 폴리에 **실제 악기 레이어**를 겹친다. 의료 기기 소리까지 악기로 연주한다 (S3) |
| 2 | **모든 소리는 건물의 심장 위에 있다** | 음악, 앰비언스, 크리처의 걸음이 하나의 박동(G2)에 묶인다. 박동이 멈추면 세계가 멈춘다 |
| 3 | **우나는 '빈 소리'로 들린다** | 우나에게서는 숨소리도, 심장 소리도 나지 않는다. 우나가 가까이 오면 대신 **주인공 자신의 심장 소리**가 들리기 시작한다. 대비로 비어 있음을 들려준다 |
| 4 | **침묵은 가장 큰 소리다** | 건물의 심장은 늘 뛴다. 그래서 그것이 멈추는 순간이 가장 무섭다 (S9) |
| 5 | **엄마의 목소리는 아껴 둔다** | 메인 테마의 자장가는 처음부터 들리지만, **엄마의 목소리로 부르는 원래 가사**는 진엔딩에서만 처음 온전하게 들린다 |

## S2. 악기 팔레트

| 출처 | 악기 | 음색 키워드 |
|------|------|------------|
| **건물 (잔여체)** | 큰북과 팀파니(심장), 콘트라베이스·콘트라바순의 공기 소리(숨), 튜바 다중음과 워터폰(배관), 어린이 합창의 입 다문 허밍(목소리) | 거대하고 느리고 따뜻하다 |
| **정상 시절의 병원** | 첼레스타, 오르골, 글로켄슈필, 장난감 피아노, 비브라폰 차임 | 다정하고 작다 |
| **설계하는 회사** | 프리페어드 피아노(현 사이에 볼트나 고무를 끼워 음색을 바꾸는 기법. 존 케이지가 발전시켰다), 현악기의 하모닉스, 크로탈레스 | 차갑고 정확하다 |
| **회진** | 약음한 마림바 저음, 펠트 피아노 | 너무 부드럽다 |
| **우나** | 없음. 그리고 그녀의 목소리 | 비어 있음 |
| **엄마 (린다)** | 사람의 허밍 | 메인 테마의 처음과 진엔딩에만 |
| **공포의 질감** | 유리 하모니카(1761년 벤저민 프랭클린이 발명한 실제 악기), 워터폰(호러 영화에서 자주 쓰이는 실제 악기), 활로 긋는 비브라폰 | 정체를 알 수 없는 긴 울림 |

## S3. 의료 기기는 악기로 연주한다

| 소리 | 악기 |
|------|------|
| 심전도 모니터 '삐' | 크로탈레스(작은 금속 원반 심벌) 아주 여리게 |
| 인공호흡기 | 하모니움 풀무 + 콘트라베이스 활의 공기 소리 |
| **원내 방송 차임 "회진 시간입니다"** | 비브라폰 3음 (E5 · C5 · G4) |
| 엘리베이터 도착 | 핸드벨 |
| 수액 떨어지는 소리 | 글로켄슈필 최고음, 아주 여리게 |
| 형광등 웅웅거림 | 활로 그은 크리스털 글라스 + 실제 60Hz 전원 험 (미국 전원 주파수) |
| 배관의 꾸르륵 | 튜바·콘트라바순 다중음, 워터폰 |
| **건물의 심장** | 큰북과 팀파니, 펠트 말렛. "쿵— 쿵" |
| 회진의 발소리 | 약음한 마림바 저음 |
| 클립보드와 볼펜 | 아주 여린 우드블록 + 실제 폴리 |
| 문 | 폴리 + 첼로 콜 레뇨(활대로 현 두드리기) |
| 잔여체의 목소리 | 어린이 합창 허밍 여러 겹, 일부는 거꾸로 재생 |

## S4. 메인 테마 「Whatever You Become (어떤 모습으로 와도)」

> 파피 플레이타임의 메뉴 음악처럼, **음악만 들어도 이 게임이 무엇인지 설명되는 곡**이 목표다.
> 구조 스케치 MIDI: `assets/audio/sketch/whatever_you_become_sketch.mid` (생성: `tools/audio/make_theme_sketch.py`).
> 이 파일은 General MIDI 음색으로 만든 **구조 확인용 스케치일 뿐 최종 음원이 아니다.**

### S4.1 핵심 아이디어: 자장가가 '시술'을 받는다

- 메인 테마는 **주제와 변주**다. 주제는 우나의 엄마가 부르던 자장가. 그리고 네 번의 변주가 회사의 네 계단을 차례로 따라간다.
- **같은 선율이 매번 다른 몸을 받는다.** 더 아름다워지고, 음이 빠지고, 흩어지고, 끝내 몸 없이 잔향만 남는다.

| 구간 | 회사의 계단 | 들리는 것 | 플레이어가 배우는 것 |
|------|-----------|-----------|-------------------|
| 도입 | — | 사람의 심장 박동 | 몸에 관한 게임이다 |
| **주제** | 치료 | **엄마의 허밍**과 오르골. 심장 박동. 마지막에 C로 돌아와 편안히 끝난다 | 엄마, 아이, 집 |
| **변주 1** | 개선 | 엄마의 목소리가 사라진다. 첼레스타와 현악과 하프로 **더 아름답게.** Cmaj7로 끝난다 (예쁘지만 집이 아니다) | 더 좋아졌는데 무언가를 잃었다 |
| **변주 2** | 설계 | **음 세 개 중 하나씩이 빠진다.** 넷째 마디에서 **심장 소리가 멈춘다.** G에서 끝나 해결되지 않는다 | 기능이 하나씩 지워진다. 심장이 뛰지 않는 아이가 있다 |
| **변주 3** | 인간 이후 | 음마다 **다른 악기, 다른 위치**에서 울린다. 마디 안의 순서가 거꾸로다. 심장이 아무 박에서나 뛴다 | 한 곳에 있지 않은 것. 뒤바뀌는 공간 |
| **변주 4** | 실험 90 | **선율이 없다.** 선율이 지나간 자리의 **잔향만** 남는다. 아주 느리고 거대한 심장, 콘트라베이스의 숨 | 몸이 없다. 건물이 숨 쉰다 |
| 끝 | — | 거대한 심장 | 다시 처음으로. 빠져나갈 수 없다 |

### S4.2 자장가 「Whatever You Become」 — 린다 피어스, 1970년대

- 다장조 5음 음계(도·레·미·솔·라), 6/8, 점4분음표 = 50. 8마디.

| 마디 | 가사 | 음 (길이) | 화음 |
|------|------|----------|------|
| 1 | 자 · 장 · 자 · 장 | E4♩ D4♪ E4♩ G4♪ | C |
| 2 | 우 · 리 · 아 · 가 | A4♩ G4♪ E4♩ D4♪ | Am |
| 3 | 봄 · 은 · 다 · 시 | E4♩ G4♪ A4♩ C5♪ | C |
| 4 | 올 · 거 · 야 | A4♩ G4♪ G4♩. | G |
| 5 | 어 · 떤 · 모 · 습 | C5♩ A4♪ G4♩ E4♪ | Am |
| 6 | 으 · 로 · 와 · 도 | G4♩ E4♪ D4♩ C4♪ | C |
| 7 | 엄 · 마 · 는 · 알 | D4♩ E4♪ G4♩ E4♪ | G |
| 8 | 아 · 볼 · 게 | D4♩ E4♪ C4♩. | C |

> 6/8 표기: ♩ = 8분음표 2개, ♪ = 8분음표 1개, ♩. = 8분음표 3개.

**한국어 가사 (게임판)**
```
자장자장 우리 아가
봄은 다시 올 거야
어떤 모습으로 와도
엄마는 알아볼게
```

**영어 원가사 (게임 속 린다의 노래)**
```
Hush now, my baby,
spring will come again.
Whatever you become,
Mama will know you.
```

**세 가지 버전 (게임 안에서 들리는 순서)**

| 버전 | 누가 | 가사 | 언제 |
|------|------|------|------|
| 우나의 기억 | 우나 | 첫 줄만. 나머지는 허밍 | Ch1~ |
| 루스의 버전 | 루스 (녹음, 루스의 회진) | 첫 줄 + 루스가 지어 붙인 가사 "꿈속에서 만나자 / 아침까지 여기 있을게" | Ch3~ |
| **원래 가사** | 엄마 (꿈의 방 조각 4개) | 위의 원래 가사 전체 | Ch5, 진엔딩 |

### S4.3 메인 테마 구조 — 44마디

| 구간 | 마디 | 악기 |
|------|------|------|
| 도입 | 1~2 | 팀파니 심장 박동 (마디당 두 번, 쿵-쿵) |
| 주제 「치료」 | 3~10 | 엄마의 허밍, 오르골(한 옥타브 위), 첼로 근음, 심장 |
| 변주1 「개선」 | 11~18 | 첼레스타, 현악(maj7·9화음), 하프 아르페지오, 여린 심장 |
| 변주2 「설계」 | 19~26 | 활로 긋는 비브라폰(세 음마다 하나 빠짐), 현악 빈 5도, 심장은 21마디까지만 |
| 변주3 「인간 이후」 | 27~34 | 피아노(왼쪽), 하프(오른쪽), 글로켄슈필(먼 왼쪽), 튜블러 벨(먼 오른쪽)이 음 하나씩 돌아가며. 마디 안 역순. 엇박의 심장 |
| 변주4 「실험 90」 | 35~42 | 잔향 패드(선율을 한 박 늦게, 아주 여리게, 잔향만), 큰북의 거대한 심장(마디당 한 번), 콘트라베이스의 숨 |
| 끝 | 43~44 | 큰북 심장, 숨 |

- **44마디, 약 1분 46초.** 끊김 없이 반복된다.
- 최종 음원 규칙: 변주 4는 실제로 **주제 녹음을 컨볼루션 리버브에 넣고 원음을 끈** 소리로 만든다. 잔향(殘響)은 '남은 소리'다. 잔여체가 '남은 몸'인 것처럼.

### S4.4 화음표

```

변주1     :  Cmaj9 Am9   Fmaj7 G6    Am11  C/E   Dm9   Cmaj7   (더 아름답지만 집이 아니다)
변주2     :  C5    A5    C5    G5    A5    C5    G5    G5      (3음이 빠진 빈 화음, G에서 멈춘다)
```

## S5. 챕터 크레딧 송

| 챕터 | 곡 | 형식 | 악기 | 설명 |
|------|----|------|------|------|
| Ch1 | 「부품은 바꿔도 (Swap a Part)」 | 2/4, 밝은 어린이 노래 | 장난감 피아노, 우쿨렐레, 글로켄슈필, 어린이 합창 | 호피 스와피의 노래. 정상 시절에는 정말 좋은 노래였다 |
| Ch2 | 「완벽한 얼굴 (Perfect Face)」 | 3/4 왈츠 | 현악 4중주, 하모닉스 | 아름답고 차갑다. 마지막 화음이 maj7에 멈춘다 |
| Ch3 | 「기능 목록 (Function List)」 | 7/8 오스티나토 | 프리페어드 피아노, 낭독 | 리듬에 맞춘 낭독. "잠, 필요 없음. 밥, 필요 없음. 아픔, 필요 없음…" |
| Ch4 | 「여기 그리고 저기 (Here and There)」 | 자유 | 공간 곳곳에 흩어진 앙상블 (헤드폰 입체음향) | 같은 선율이 사방에서 조금씩 어긋나게 들린다 |
| Ch5 | 「Whatever You Become」 | 자장가 | 엔딩마다 다르다 | 「귀가」: 엄마의 목소리로 원래 가사 / 「적출」: 첼레스타 하나가 점점 느려지다 멈춘다 / 「최종 형태」: 변주 4의 잔향만 |


## S6. 크리처 사운드 시그니처 — 청진기로 듣는 박동

> 청진기(G5)를 벽에 대면 그 너머 존재의 **심장 소리**가 들린다. 크리처마다 박동이 다르다. 플레이어는 소리만으로 벽 너머에 누가 있는지 알게 된다.

| 존재 | 접근음 (보이기 전에 들리는 소리) | 청진기 속 박동 | 잡을 때 |
|------|------------------------------|--------------|--------|
| **우나** | 맨발의 아주 작은 발소리 | **아무 소리도 없다** | — |
| 주인공 | 숨, 발소리 | 긴장하면 귀에 들릴 만큼 빨라진다 | — |
| 회진 | 약음한 마림바 발소리, 볼펜 딸깍 | 박동이 아니라 **액체가 흐르는 소리** | 클립보드에 적는 소리 → 하얗게 번짐 |
| 호피 스와피 | 벨크로 뜯기는 소리, 솜 속의 숨, 장난감 실로폰 | 인형탈 속에서 **아주 작고 빠른** 박동 | "새 친구! 부품 바꾸자!" |
| 나이트라이트 | 아주 느린 눈 깜빡임이 없는 정적, 그리고 비명(크로탈레스를 활로 긋기) | 110BPM. **한 번도 느려지지 않는다** (16년 동안 자지 않았다) | 비명 |
| 태그 | 웃음, 무언가 부러지는 소리 | 매우 빠르고 불규칙 | 태클 |
| 크레이들 | 여러 손바닥이 벽을 짚는 소리, 엉터리 자장가 | 50BPM. 느리고 깊다 | 자장가가 느려진다 |
| 탱글 | 세 목소리가 같은 말을 동시에 | **세 개의 박동이 완벽하게 같은 순간에** 뛴다 | 세 비명이 하나로 |
| 피카부 | 여러 방에서 동시에 "까꿍!" | 여러 벽에서 동시에 같은 박동 | 깔깔 웃음 |
| 노크노크 | 똑똑 | 문틀 속에서 박동 | 문이 닫히는 소리 |
| 레디오어낫 | 원내 방송의 목소리, 환기구의 숨 | **보일러실 펌프 속**에서 | "찾았다!" (그가 먼저 말하면 실패) |
| 잔여체 | 건물 전체의 심장, 배관의 꾸르륵, 수십 명의 허밍 | 어디에 대도 들린다 | — |

## S7. 적응형 음악 시스템

### S7.1 레이어

| 레이어 | 내용 | 켜지는 조건 |
|--------|------|------------|
| L0 심장 | 건물의 박동 | 항상 (심정지 때만 꺼진다) |
| L1 숨 | 콘트라베이스 공기 소리 | 조직이 짙을수록 커진다 |
| L2 구역 선율 | 자장가의 변주 단편 (구역 = 회사의 계단: Ch1은 주제, Ch2는 변주1…) | 탐색 상태 |
| L3 긴장 | 현 하모닉스, 유리 하모니카 | 근처 크리처가 '의심' 상태 |
| L4 추격 | 타악, 저음 오스티나토 | 크리처가 '추격' 상태 |
| L5 스팅어 | 발견, 침묵 예고, 회진 차임 | 이벤트 |

### S7.2 규칙

- **모든 전환은 다음 박동에서 일어난다** (박동 양자화).
- 음악은 미리 녹음한 스템이 아니라 **샘플 기반 시퀀서가 실시간으로 연주한다.** 그래서 건물의 심박이 빨라지면 음악도 음질 손상 없이 함께 빨라진다 ([08_PRODUCTION T2](08_PRODUCTION.md)).
- **챕터의 구역 선율 = 메인 테마의 해당 변주.** 플레이어는 메뉴에서 들은 곡의 변주를 챕터마다 '안에서' 듣게 된다.

## S9. 긴장감 설계 규칙

| # | 규칙 | 내용 |
|---|------|------|
| 1 | **침묵 예고** | 주요 크리처가 처음 나타나기 직전에 **2박 동안 건물의 심장까지 멈춘다.** 늘 들리던 소리가 사라지는 것이 가장 큰 경고다 |
| 2 | **사진 장면의 침묵** | Ch4 사진 장면에서는 장면 전체 동안 심장이 멎는다. 음악도 없다. 시리즈에서 가장 긴 침묵 |
| 3 | **소리 먼저, 모습 나중** | 모든 크리처는 보이기 전에 들린다 (공정성). 청진기로 미리 알 수 있다 |
| 4 | **하드 점프스케어 상한** | 큰 소리와 화면이 동시에 덮치는 연출은 15분에 1번 이하. **우나의 이상 징후는 절대 점프스케어로 쓰지 않는다** |
| 5 | **존재의 공포 우선** | 복도 끝에 아까는 없던 흰 가운. 빌보드는 늘 나를 바라본다 |
| 6 | **안전한 소리** | 무균실에서는 건물의 심장이 멀고 작다. 대신 형광등과 우나의 목소리만 들린다. 안전이 있어야 공포가 산다 |
| 7 | **반복 피로 방지** | 같은 스팅어를 연달아 쓰지 않는다. 스팅어마다 4가지 이상의 변형. **단, 회진 차임만은 언제나 같은 세 음이다** |

## S10. 녹음, 믹싱, 청력 안전

### S10.1 '진짜 악기' 확보 전략

| 순위 | 방법 | 내용 |
|------|------|------|
| 1 | **직접 녹음** | 오르골(종이띠 오르골에 자장가를 직접 펀칭할 수 있다), 장난감 피아노, 글로켄슈필, 우쿨렐레, 큰북·팀파니 대용(바닥에 놓은 큰 북이나 소파 쿠션을 펠트 말렛으로), 크리스털 글라스, 핸드벨. **엄마의 허밍은 실제 사람 목소리로** |
| 2 | **CC0 샘플 라이브러리** | 예: *VSCO 2 Community Edition*(CC0로 배포된 것으로 알려진 오케스트라 샘플), *Freesound*(파일마다 라이선스가 다르므로 CC0만 골라 쓴다). **적용 전에 라이선스 원문을 반드시 다시 확인한다** |
| 3 | **합성** | 이명, 기압 변화, 일부 저역 |

### S10.2 레트로 신호 체인

- 최종 출력은 48kHz로 하되 **'90년대 CD-ROM 소리'를 이펙트로 입힌다.** 22.05kHz 느낌의 대역 제한, 아주 약한 비트 감소.
- 받아쓰기 녹음기와 무전기, TV 소리에는 각각의 기기 대역(마이크로카세트의 좁은 대역, 무전기의 300Hz~3kHz)과 테이프 와우·플러터.
- 효과는 **은은하게.** '낡은 소리'이지 '나쁜 소리'가 아니다.

### S10.3 공간 (잔향 프리셋)

| 공간 | 잔향 시간 |
|------|----------|
| 병실 | 0.5초 |
| 무균실 | 0.3초 (스테인리스의 짧고 밝은 반사) |
| 냉동 보관실 | 0.8초 |
| 로비 | 2.6초 |
