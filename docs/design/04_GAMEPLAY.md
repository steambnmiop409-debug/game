## G1. 코어 루프

```
   ┌────────── 탐색 ──────────┐
   │  (박자에 맞춰 걷기)        │
   ▼                          │
  청취 ──▶ 단서·기록 획득 ──▶ 조율(퍼즐) ──▶ 길이 열린다
   │                                            │
   │ 위협 감지 (침묵 예고, 발소리, 맥놀이)          │
   ▼                                            │
 은신 / 진정 / 제압 / 도주 ─────────────────────────┘
```

- **분 단위 루프:** 듣고 → 박자에 맞춰 움직이고 → 소리 하나를 녹음하거나 조율해서 → 문 하나를 연다.
- **챕터 단위 루프:** 새 구역 → 새 공명기 기능 → 크리처의 규칙 학습 → 공명 기억 수집 → 보스 세트피스 → 진실 한 겹 공개.

## G2. 펜듈럼 (템포) 시스템 — 이 게임의 심장

### G2.1 원리

- 시계탑의 대 메트로놈 '펜듈럼'이 **틱 라인**(캠퍼스 방송 스피커망)으로 모든 방에 틱 소리를 보낸다.
- **게임 전체가 하나의 시계(Conductor Clock)를 공유한다.** 적의 걸음, 발소리 차폐, 음악, 조명 깜빡임, 포키즈의 점프가 모두 이 시계의 박자에 묶인다.

### G2.2 박자 은신 (Beat Masking)

| 항목 | 값 |
|------|----|
| 차폐 구간 | 틱 전후 **±90ms** |
| 차폐 구간 안에서 디딘 걸음의 소음 반경 | 1.5m (평소 6m) |
| 차폐 구간 밖에서 디딘 걸음 | 6m |
| 뛰기 | 차폐 여부와 관계없이 14m |
| 웅크려 걷기 | 3m, 차폐 시 0.5m |
| 발걸음 판정 | 플레이어가 한 걸음을 '디딘' 순간(걸음 주기의 접지 시점)을 기준으로 한다. 걷는 속도를 박자에 맞추는 **'박자 걷기' 보조 옵션**이 있다 (G13) |

- **표면 재질별 배율:** 카펫 ×0.6, 나무 ×1.0, 타일 ×1.3, 금속 ×1.6, **바닥 건반 ×2.5 (음이 난다)**.
- **스피커가 고장 난 방**에서는 틱이 없어 차폐도 없다. 레벨 디자인에서 '긴장 구간'으로 쓴다.

### G2.3 템포 변동

| 원인 | BPM 변화 |
|------|----------|
| 챕터 기본값 | Ch1 72 · Ch2 66 (연습동은 방마다 놓인 메트로놈이 박을 만든다) · Ch3 **없음** · Ch4 72→208 · Ch5 루바토(40~120 사이에서 흔들림) |
| 청음 수업 오답 | **+8 (영구, 챕터 안에서)** |
| 포키즈 경보 | +4 (16박 동안) |
| 템포 다이얼 (퍼즐 요소) | 구역별 BPM을 조정한다. 느리면 적이 느려지지만 차폐 기회가 드물어지고, 빠르면 차폐는 잦지만 적이 빨라진다 |
| 상한 | **208BPM** (실제 기계식 메트로놈의 일반적인 최고값) |

### G2.4 HUD 표현

- 화면 상단 가운데의 작은 메트로놈 아이콘이 박자에 맞춰 흔들린다. 옆에 현재 BPM이 연습일지 글씨체로 표시된다.
- 조명은 틱마다 **3% 밝아졌다 돌아온다** (잠재적 박자 신호. 꺼둘 수 있다).
- 난이도 'Presto'에서는 HUD 메트로놈이 사라진다. 귀로만 판단해야 한다.

## G3. 소음과 청각 AI

### G3.1 소음 전파

- 레벨은 **방 그래프**(방 = 노드, 문·통로 = 간선)로 나뉜다. 소음은 거리와 문 상태(열림 ×1.0, 닫힘 ×0.4)에 따라 감쇠한다.
- 각 크리처는 **청각 임계값**과 **관심 지점 목록**을 가진다. 소음이 임계를 넘으면 그 지점으로 이동한다.

### G3.2 크리처 상태 기계 (공통)

```
 배회 ──소음 감지──▶ 의심(그 지점 확인) ──시야/재감지──▶ 추격
  ▲                       │                              │
  │                       └─────── 놓침(8박) ──────────────┤
  └──────────────── 진정(공명) / 제압(맥놀이) ◀──────────────┘
```

| 상태 | 박자 묶임 크리처 (Ch1~2) | 무박자 크리처 (Ch3~) |
|------|------------------------|-------------------|
| 이동 방식 | 틱마다 한 칸(1.2m)씩 순간 이동하듯 걷는다 | 연속 이동. 매끄럽고 예측하기 어렵다 |
| 플레이어가 읽는 법 | 리듬 | 소리의 방향 (HRTF 입체음향) |

## G4. 숨과 이명

### G4.1 숨 (Breath, 스태미나)

| 항목 | 값 |
|------|----|
| 최대 | 100 |
| 뛰기 | −12/초 |
| 회복 | 걷기 +8/초, 멈춤 +15/초 |
| 숨 참기 (홀드) | −10/초. 그동안 내 소음이 **0** (숨을 곳에서 사용) |
| 25 미만 | **헐떡임**: 2초마다 반경 5m 소음. 벨로가 이것을 듣는다 |
| HUD | 왼쪽 아래 **작은 아코디언 풀무 아이콘**이 접혔다 펴진다 |

### G4.2 이명 (Tinnitus) — 위협 게이지

| 항목 | 값 |
|------|----|
| 범위 | 0~100. 100이 되면 **'조율됨'(게임오버)** |
| 증가 | 허밍 근원 근처 +2/초, 크리처의 비명이나 클러스터 +25, 싱어롱즈 12음 동시 발성 +25 |
| 감소 | 자연 −1/초, **귀 막기 −8/초**, 목캔디 −30 |
| **귀 막기 (Q 홀드)** | 이명이 빨리 내려가지만 **게임 소리 전체가 먹먹해진다** (저역통과 약 500Hz, −12dB). 다가오는 적의 소리를 듣기 어려워지는 대가 |
| 시각 표현 | 화면 가장자리에서 가는 흰 선이 안쪽으로 자란다. 텍스처의 미세한 떨림 |
| 청각 표현 | 이명 사인파. **청력 안전 규칙**에 따라 레벨과 주파수에 상한을 둔다 (S10.4) |
| 게임오버 '조율됨' | 화면이 하얗게 차오르고 순음 A4가 '정확히 440Hz로' 울린 뒤 뚝 끊긴다. 문구는 "당신은 완벽하게 조율되었습니다." |

## G5. 공명기 (The Resonator) — 플레이어의 유일한 '무기'

### G5.1 구성 (Ch1에서 직접 조립한다)

| 부품 | 획득 장소 | 기능 |
|------|----------|------|
| 소리굽쇠 No.49 (A4) | 소포 | 기준음. 두드리면 A440이 울린다 |
| 나팔 (축음기 혼) | 로비 | 지향성 증폭. 재생 소리가 조준한 방향으로 나간다 |
| 마이크로 릴 녹음기 | 로비 옆 AV실 | 녹음과 재생 |
| 스트로보 원판 | 레슨동 '라' 교실 | 화면. 목표 음과 맞으면 무늬가 멈춘다 (2차 조립) |

1인칭 시점에서는 오른손에 든 '나팔 + 작은 릴 + 초록 원판' 장치가 화면 오른쪽 아래에 2D 스프라이트로 보인다.

### G5.2 챕터별 업그레이드

| 챕터 | 기능 | 조작 | 설명 |
|------|------|------|------|
| Ch1 | **녹음 / 재생** | 좌클릭을 누르고 있으면 녹음(최대 4초), 우클릭으로 재생 | 녹음 슬롯 1개. 차임 잠금, 미끼 |
| Ch1 | **송출** | 방송 잭이나 라디오 근처에서 T | 녹음한 소리를 **다른 위치의 스피커로** 내보낸다 (원격 유인) |
| Ch2 | **음높이 다이얼** | 휠 | 거칠게 ±12반음, 미세하게(Shift+휠) ±50센트. 스트로보로 확인한다 |
| Ch3 | **역재생** | R | 거꾸로 부른 노래 속 숨은 메시지 복원, 레레의 공명 기억 복원 |
| Ch4 | **화음 쌓기** | 1·2·3 | 녹음 슬롯 3개를 동시에 재생해 3화음을 만든다 (화음 잠금) |
| Ch5 | **지속음** | 길게 홀드 | 음 하나를 숨이 닿는 한 계속 유지한다 (최종장) |

### G5.3 진정과 제압 (W2 규칙 3의 구현)

| 판정 | 조건 (크리처 고유음 기준) | 스트로보 | 효과 |
|------|------------------------|---------|------|
| **진정** | ±3센트 이내 | 멈춤 | 크리처가 20초간 공격하지 않는다. **공명 기억**과 함께 재생하면 영구히 진정된다 (G10) |
| **제압** | ±5~35센트 (맥놀이 구간) | 천천히 돈다 | 크리처가 3초간 경련하며 멈춘다. 그 뒤 20초간 **+50% 속도로 공격적**이 된다 |
| 무효 | 그 밖 | 빠르게 돈다 | 효과 없음. 소리가 나니 위치만 들킨다 |

> 설계 의도: 제압은 쉽고 빠르지만 대가가 있다. 진정은 이야기를 알아야 할 수 있다. **어느 쪽을 쓸지가 곧 플레이어의 '음률'(성향)이 된다.**

## G7. 룰라 오르골 나침반

| 항목 | 값 |
|------|----|
| 감기 | F를 길게. 8번 감으면 16박 동안 연주한다 |
| 방향 안내 | 목표를 바라볼수록 **음량과 밝기**가 커진다(장조). 등지면 작아진다 |
| 위험 | 연주 중 반경 10m 안의 크리처가 소리를 듣는다 |
| 감정 신호 | 장조 = 안전, 단조 = 위험이 가까움, 끊긴 스타카토 = 서둘러, 「똑딱 노래」 첫 소절 = 나 여기 있어 |
| 신뢰 (숨은 수치) | +: 그녀가 "감아 줘" 신호(빠르게 늘어지는 음)를 보낼 때 감아 준다, 그녀를 보호한다 / −: 미끼로 던진다(크리처 유인용으로 바닥에 두고 감기), 오래 방치한다 |

## G8. 청음 수업 — 발디 오마주 (Ch1 중심, Ch4에서 재등장)

### G8.1 진행

1. 교실 축음기에 **레슨 음반**(도·레·미·파·솔·라·시, 7장)을 올리면 TV가 켜지고 티코가 수업을 시작한다.
2. 문제 3개. 장난감 건반 책상(한 옥타브)과 `예 / 아니오` 버튼으로 답한다.
3. 정답이면 금별 스티커를 받고 다음으로 넘어간다. **오답이면 전체 BPM +8**, 그리고 티코가 깨어난다. 첫 오답 이후로 티코가 복도를 걷기 시작한다.
4. 음반 7장을 다 모아 레슨동 출구의 주크박스에 넣어야 나갈 수 있다 (P1).

### G8.2 문제 유형

| 유형 | 예시 | 보통 난이도의 공정성 규칙 |
|------|------|------------------------|
| 높낮이 | "두 번째 음이 더 높을까요?" | 간격은 최소 3반음 |
| 같다/다르다 | "두 음이 같을까요?" | 최소 1반음. 가끔 '같은 음, 다른 악기'라는 함정 |
| 리듬 세기 | "종이 몇 번 울렸나요?" | 최대 7번 |
| 따라 치기 | "이 세 음을 건반으로 쳐 보세요" | 도~솔 사이의 세 음 |
| **불가능한 문제** | **"시와 도 사이에 있는 음을 건반으로 쳐 보세요."** 질문 뒤에 실제로 **사분음**(반음의 절반)이 울린다 | 건반에는 그런 음이 없다. 무엇을 쳐도 오답이다. 화면 글자가 깨지고, 티코의 얼굴 프레임이 바뀐다 |

- **숨은 요소:** 진엔딩 후 '조율실'(뉴게임+)에서는 Ch2에서 얻는 공명기 **미세 다이얼**을 처음부터 쓸 수 있다. 이것으로 사분음을 맞히면 티코가 단 한 번 펠의 목소리로 말한다. "…거봐. 너는 들을 줄 알았어."

## G9. 퍼즐 유형 8가지 (모두 소리 기반)

| # | 퍼즐 | 원리 | 처음 등장 |
|---|------|------|----------|
| 1 | **핀 잠금** | 문에 달린 작은 핀블록과 현. 튜닝 해머로 현을 돌려 **소리굽쇠와의 맥놀이가 멈출 때까지** 맞춘다(스트로보가 멈추면 성공). **실제 조율사가 귀로 조율하는 방식**과 같다 | Ch1 |
| 2 | **소리 열쇠** | 특정 소리에만 열리는 문 (아이의 암호 문구, 종소리). 다른 곳에서 녹음해 와 재생한다 | Ch1 |
| 3 | **송출 유인** | 녹음한 소리를 먼 스피커로 보내 크리처를 그쪽으로 보낸다 | Ch1 |
| 4 | **음계 길** | 바닥 건반 복도. 다장조 음계 순서로만 밟아야 조용하다(음계 밖 음은 그랑데를 부른다) | Ch2 |
| 5 | **공명 유리** | 유리 진열장의 고유 진동수를 찾아 활과 다이얼로 맞추면 깨진다 (실제로 목소리로 와인잔을 깬 시연 사례가 있다) | Ch2 |
| 6 | **역재생** | 거꾸로 녹음된 노래를 뒤집어 금고 번호, 문 암호를 얻는다. 아이들이 어른 몰래 쓰던 '거꾸로 말하기 놀이' | Ch3 |
| 7 | **잔향 설계** | 잔향실에서는 소리가 8초 남는다. 레레가 3초 뒤 따라 한다. 이 지연을 계산해 적을 움직인다 | Ch3 |
| 8 | **화음 잠금** | 문에 3화음 표시가 있다 (예: `F · A · C`). 녹음 슬롯 3개로 화음을 쌓는다 | Ch4 |

## G10. 진정 대 제압: '음률' 시스템과 공명 기억

### G10.1 공명 기억 (Resonant Memory)

- 주요 크리처 5종(벨로, 그랑데, 허시, 레레, 티코)마다 **그 존재의 과거가 담긴 소리 하나**가 그들의 구역에 숨겨져 있다.
- 공명 기억을 **크리처의 고유음에 맞춰** 재생하면 영구 진정이 된다. 짧은 컷신과 함께 크리처가 '쉰다.'
- **세계관을 읽은 플레이어만 진정 루트를 갈 수 있다.** 기록 수집과 엔딩이 이렇게 연결된다.

### G10.2 음률 (Temperament) — 숨은 성향 수치

| 행동 | 순정(+) | 평균(−) |
|------|---------|---------|
| 주요 크리처 처리 | 진정 +2 | 제압 −2 |
| 일반 진정·제압 사용 | +0.2 | −0.2 |
| 룰라 신뢰 | 별도 수치 (G7) | |

- 수치는 **화면에 직접 나오지 않는다.** 대신 룰라의 선율 색깔(장조와 단조의 비율), 챕터 끝 크레딧 송의 편곡(순정 쪽이면 어쿠스틱, 평균 쪽이면 기계적인 편곡)으로 은근히 드러난다.

## G12. 저장, 실패, 난이도

### G12.1 저장: 보면대

- 체크포인트는 **보면대**다. 내 악보를 올려 두면 '연습일지'에 저장된다.
- 보면대는 대개 **틱이 크게 들리는 방**(안전 구역)에 둔다.

### G12.2 실패: 크리처별 '잡혔을 때'

- 모든 실패 연출은 **소리가 끊기며 암전**되는 것을 기본으로 한다 (B6). 크리처마다 마지막 소리가 다르다 (C4 각 항목).
- 실패 화면은 '성적표' 형태다. 맨 아래 칸에 크리처가 남긴 한 줄 평이 적힌다 (예: 티코 "수업 끝. 집에 가렴.").

### G12.3 난이도: 메트로놈 빠르기말

| 난이도 | BPM 배율 | 차폐 구간 | 이명 배율 | HUD 메트로놈 |
|--------|---------|----------|----------|-------------|
| **Largo** (쉬움) | ×0.8 | ±150ms | ×0.6 | 있음 + 박자 걷기 보조 |
| **Andante** (보통) | ×1.0 | ±90ms | ×1.0 | 있음 |
| **Presto** (어려움) | ×1.2 | ±60ms | ×1.3 | **없음 (귀로만)** |

## G13. 접근성 (소리가 핵심인 게임이기에 더 중요하다)

| 항목 | 내용 |
|------|------|
| 시각 박자 | 화면 가장자리의 박자 링, 진동(게임패드) |
| 소리 자막 | `[똑딱 — 박자]`, `[왼쪽 뒤: 아코디언 들숨]`처럼 **방향과 종류**를 함께 표시 |
| 음 맞추기 보조 | 스트로보 원판 외에 '높다/낮다' 화살표 옵션 |
| 박자 걷기 보조 | 이동 키를 누르고 있으면 걸음이 자동으로 박자에 맞춰진다 |
| 이명 소리 끄기 | 이명을 시각 효과로만 표현 |
| 깜빡임 감소 | 스트로보 무늬와 조명 깜빡임 약화 |
| 마이크 | **기본값은 꺼짐.** 최종장의 '내 목소리로 A 부르기'는 선택 사항이며 버튼 홀드로 대체할 수 있다 |
| 색 의존 금지 | 싱어롱즈의 색-음 대응은 보조 정보일 뿐이다. 퍼즐의 정답은 항상 소리 + 모양(번호)으로도 구분할 수 있다 |
