# [대설계 G] 게임플레이 시스템

> 상위 문서: [00_INDEX](00_INDEX.md) · 이 문서의 트리: **G1 ~ G13**
> **v0.4 기준.** 건물의 심장 박동에 맞춰 걷는 '박동 은신', 청진기로 건물을 진찰하기, 바뀌는 복도는 모두 뺐다.
> 이 게임의 공포는 **회사가 사람의 몸을 다시 썼다는 것**이다. 그래서 플레이의 중심도 하나다. **사람에게 무슨 일이 있었는지가 계속 풀려 나와야 한다.**
> 수치는 챕터 1 빌드(`src/`)에 들어간 값이다. 표시가 없는 값은 '노랑'(보통) 난이도 기준이다.

## G1. 코어 루프

```
   ┌──────────── 탐색 ────────────┐
   │  (병실, 차트, 테이프, 아이의 흔적) │
   ▼                              │
 판독 ──▶ 기록 하나가 풀린다 ──▶ 그걸로 길을 연다
   │ (재지시기로 몸에 남은 '지시'를 읽는다)     │
   │                                    │
   │ 위협 (회진, 호피 스와피)                 │
   ▼                                    │
 숨는다 / 우나의 손을 잡는다 / 진정 카드 / 도망 ─┘
```

- **분 단위 루프:** 방 하나에 들어간다 → 거기 있던 아이의 차트·물건·몸을 읽는다 → **"이 아이에게 무엇을 했는가"가 한 줄 늘어난다** → 그 한 줄이 다음 문의 열쇠가 된다.
- **챕터 단위 루프:** 회사의 다음 계단(치료 → 개선 → 설계 → 인간 이후 → 실험 90) → 재지시기의 새 카드 → 그 구역 아이들의 '원래 모습' 알아내기 → 우나의 이상 징후 하나 → 보스(개조된 아이) → 진실 한 겹.
- **판정 기준:** 새 방, 새 퍼즐, 새 크리처를 넣을 때마다 묻는다. **"이걸 겪고 나면 플레이어가 개조된 사람에 대해 하나를 더 알게 되는가?"** 아니면 넣지 않는다.

## G2. 재지시기 (SN-RI 3, Re-Instructor) ★

> 파피 플레이타임의 그랩팩 자리에 있는 장비. 그런데 이것은 **아이들을 고칠 때 쓰던 직원용 기기**다.
> 회사가 쓰던 도구로 회사가 한 일을 거꾸로 읽어 낸다.

### G2.1 기기

- 1980년대 회색 플라스틱 의료 기기. 손잡이, 초록 단색 LCD, 앞쪽 금속 노즐, 손잡이 옆 카드 슬롯.
- 로비 경비실의 충전 거치대에 꽂혀 있다 (Ch1 1-3). 화면: `SN-RI 3 / READY / RELAX x3`.
- 오른손에 든다. 왼손은 비어 있다 (우나의 손, 그리고 C-0으로 만든 왼팔을 보기 위해).

### G2.2 판독 (왼클릭 누르고 있기)

| 항목 | 값 |
|------|----|
| 조작 | 대상을 겨누고 왼클릭을 **1.3초** 누르고 있는다. 화면에 진행 막대, 한 줄씩 결과가 찍힌다 |
| 범위 | 대상마다 다르다 (기본 7m), 벽 너머는 읽지 못한다 |
| 결과 | 그 몸(또는 물건)에 남은 **DRI 지시 기록**: 날짜, 바뀐 항목, 지시문 "처음부터 이렇게 자란 ○○이었다.", 원료 |
| 기록 | 처음 읽은 대상은 저장된다. 판독 직후 우나나 주인공이 한마디 한다 |

**챕터 1 판독 대상 (구현)**

| 대상 | 결과 요약 | 풀리는 것 |
|------|----------|----------|
| 로비 경비실의 빈 생쥐 우리 | DRI-85-014, 발가락 5개 → 6개. "처음부터 이렇게 자란 발이었다." 대상 위치 알 수 없음 | 재지시가 무엇인지 (흉터 없이 몸이 바뀐다) |
| 로비의 호피 스와피 동상 | 판독 실패. 대상이 신호를 차단하고 있다 | 저 인형탈은 비어 있지 않다 |
| 빈 받침대 | 대상 없음. 잔류물: 분홍 아크릴 섬유 | 동상이 걸어갔다 |
| **우나** | **지시 기록 없음. 흉터 없음. 판정: 정상 인간** | 기계가 보기에 우나는 아무것도 바뀌지 않은 사람이다 (C2 반전의 첫 단서) |
| **회진** | 직원. 마지막 지시 판독 불가. **얼굴 항목: 삭제됨.** 맥박 없음 / 체액 흐름 있음 | 회진은 괴물이 아니라 직원이었다 |
| **호피 스와피 (추격 중)** | 인형탈(비생체), **내부 생체 반응 1. 대상 53.** 골격: 지시 "고정 해제" | 인형탈 안에 아이가 있다 (Ch3 오리가미) |
| **내 왼팔** | 지시 기록 1건 — 1994.07.12, 피부 재건. **원료: C-0 / 로트 0332** | 주인공의 몸도 이 회사가 다시 썼다 |
| 모양 공방 | 소아 발달 재지시 인터페이스. 부록 C-7 대기열. 누적 선택 기록 211건 | 아이들의 '놀이'가 동의 절차였다 |

## G3. 감지 AI

### G3.1 회진 (The Rounds)

- 회진은 **체온과 이물질**로 사람을 느낀다. 얼굴(눈)이 지워졌기 때문이다.
- 회진은 **일정한 박자로 걷는다.** 마림바 같은 딱딱한 발소리, 셋이 맞춰서. 박자가 빨라지면 위험하다는 뜻이다 (이 박자가 음악·발소리의 시계지만, 플레이어가 맞춰 걸을 필요는 없다).

| 플레이어 상태 | 열 (감지 배율) |
|--------------|--------------|
| 서서 걷기 | 1.0 |
| 뛰기 | 1.2 |
| 웅크리기 | 0.85 |
| 침대 밑·사물함에 숨기 | 0.22 |
| **우나의 손을 잡고 있기** | **0** (우나의 일부로 느낀다) |

| 난이도 | 감지 거리 |
|--------|----------|
| 초록 | 5.8m |
| 노랑 | 7.5m |
| 빨강 | 9m |

### G3.2 상태 기계 (공통)

```
 순찰 경로 ──감지──▶ 의심(그 지점 확인) ──재감지──▶ 추격
  ▲                      │                     │
  │                      └──── 놓침 ────────────┤
  ├──── 정지 (진정 카드 / 스크립트) ◀──────────────┤
  └──── 마주침의 끝 (C4 각 항목) ◀────────────────┘
```

### G3.3 누가 무엇으로 느끼나 (전 챕터)

| 존재 | 감각 | 피하는 법 | 마주침이 풀어 주는 것 |
|------|------|----------|-------------------|
| 회진 | 체온과 이물질 | 우나의 손, 숨기, 진정 카드 | 얼굴이 지워진 직원들 |
| 호피 스와피 | 소리와 시야 (인형탈의 눈구멍) | 좁은 곳, 진정 카드 | 인형탈 안의 대상 53 |
| 나이트라이트 | 시야 (눈꺼풀 제거) | 어둠 | 잠을 지운 아이 |
| 태그 | 움직임 | 규칙대로 놀아 주기 | 아픔을 지운 아이 |
| 크레이들 | 표면 진동 (여덟 개의 손바닥) | 카펫, 천천히 | 팔 개수 제한을 푼 아이 |
| 탱글 | 세 방향의 시야 (공유) | 진짜 이름 셋 | 신경을 나눠 쓰게 된 세쌍둥이 |
| 피카부 | 보는 사람이 없을 때 어디에나 있다 | 우나의 시선 | 한 곳에 있지 않아도 되게 된 아이 |
| 레디오어낫 | 감시 카메라 | 렌즈 가리기, 기관 찾기 | 몸이 건물 설비가 된 아이 |

## G4. 몸 상태 — 사람의 몸은 필요가 많다

> 체력 바는 없다. 대신 **사람의 몸이 필요로 하는 것들**이 있다. 우나에게는 하나도 필요 없는 것들이다.

### G4.1 숨 (달리기 체력, 구현)

- 달리면 5.5초에 바닥난다. 바닥나면 2.2초 동안 달릴 수 없고 헐떡인다.
- 우나는 달려도 숨이 차지 않는다. **숨소리가 없다.**

### G4.2 침식 (Encroachment) — 내 팔에 남은 지시

> 주인공의 왼팔은 C-0의 원료로 만든 피부다. 이 건물 안에서 그 피부가 **자란다.**

| 항목 | 값 |
|------|----|
| 표시 | 숫자 없음. **1인칭 화면의 왼팔**: 손목 쪽 이식 피부(털도 모공도 점도 없이 매끈하다)와 팔꿈치 쪽 원래 피부. **흉터는 없다** (A1.3). 털과 점이 자로 잰 듯한 선에서 끊길 뿐이다. 그리고 피부 아래에서 **매끈한 뿌리 무늬**가 팔꿈치 쪽으로 자란다 |
| 챕터 1 | 시작 0.1. 304호에서 자기 팔을 판독하면 0.35 |
| Ch2~ (계획) | 조직을 만지면 오르고, '거부 반응 유도제'로 내린다. 100이 되면 흡수 (실패, 「최종 형태」의 짧은 판) |
| 양면성 (Ch2~) | 침식이 높을수록 회진이 주인공을 '우리 쪽'으로 느낀다. **몸을 내줄수록 숨기 쉬워진다** |

### G4.3 체온·산소 (Ch2~ 계획)

- 냉동 보관실, 가스가 찬 방. **우나는 춥지도, 숨이 막히지도 않는다** (G6.3). 이 차이가 곧 '우나에게서 무엇을 지웠는가'를 보여 준다.

## G5. 기록이 풀린다 ★

> 이 게임은 '사람에게 무슨 짓을 했는가'를 조금씩 알아 가는 게임이다. 기록은 세 겹으로 풀린다.

### G5.1 세 겹

| 겹 | 매체 | 무엇이 풀리나 |
|----|------|-------------|
| **차트** | 병실마다 걸린 진료 차트 (클립보드) | 아이 한 명의 이름, 병, 처치. **연도 순으로 '치료'가 '개선'으로 바뀐다** |

## G6. 우나와 함께

### G6.1 손잡기 (구현)

| 항목 | 내용 |
|------|------|
| 조작 | 우나 가까이에서 **Q를 누르고 있는다** |
| 효과 | **회진이 주인공을 알아보지 못한다** (열 0. 주인공을 '우나의 일부'로 느낀다) |
| 대가 | 뛸 수 없다 (이동 속도 1.9m/s). 재지시기를 들어 올릴 수 없다. 다른 아이들(나이트라이트의 눈 등)에게는 그대로 보인다 |
| 이야기 | 처음 손을 잡았을 때 우나가 멈칫한다. "…손 따뜻한데 이상해요. 여기 같아요." (C2.5) |

### G6.2 따라오기

- 평소에는 플레이어 뒤 1.1m를 따라온다. 맨발 소리. 멀어지면(18m) 보이지 않는 곳에서 따라잡는다.
- 숨을 때 같이 숨는다 (Ch1 1-5: 침대 밑에서 옆으로 눕는다).

### G6.3 우나만 할 수 있는 일 (Ch2~)

| 위험 | 우나 | 다른 방법 | 풀리는 것 |
|------|------|----------|----------|
| 가스가 찬 방 | 숨이 필요 없다 | 환기 장치 재가동 | 실험 1-E: 저산소 내성 |
| 냉동실 깊은 곳 | 추위를 타지 않는다 | 보온포 여러 장, 먼 길 | 체온 조절 제거 |
| 물에 잠긴 수조 | 숨이 필요 없다 | 배수 밸브 찾기 | |
| 전기가 흐르는 바닥 | 죽지 않는다. **다만 아프다** | 차단기 찾기 | 통각은 남겨 두었다 |

- 늘 '다른 방법'이 있다. 더 멀고, 더 위험하고, 더 오래 걸린다. 무엇을 고를지가 G10 수치가 된다.

### G6.4 분리 사건 (Ch4)

- 우나가 정문이나 철조망 가까이 가면 잔여체가 우나를 데려간다. 우나는 **별관 B의 자기 방 침대**에서 눈을 뜬다.

### G6.5 대화

- 우나 가까이에서 E를 누르면 장소에 맞는 짧은 대화가 나온다. 엄마 이야기, 옛날 직원 이야기, 농담.

## G7. 마주침의 끝 — 이름을 찾아 준다

> 개조된 아이와의 마주침은 '쓰러뜨리기'로 끝나지 않는다. **그 아이가 누구였는지 알아내는 것**으로 끝난다.

| 단계 | 하는 일 | 쓰는 것 |
|------|--------|--------|
| 1. 피한다 | 감각의 규칙을 배워 살아남는다 | 숨기, 진정 카드, 우나 |
| 2. 읽는다 | 무엇을 지시받았는지 판독한다 | 재지시기 판독 |
| 3. 찾는다 | 차트·테이프·방에서 원래 이름과 바라던 것을 찾는다 | 기록 (G5) |
| 4. 돌려준다 | 이름을 부르거나, 원하던 것을 건넨다 | 원내 방송, 물건, 놀이 |

- 챕터 1의 호피 스와피는 3단계에서 끝난다 (인형탈 안에서 무언가가 접혀 빠져나간다). 이름은 챕터 3에서 돌려준다.
- 아무도 '고쳐지지' 않는다. 바뀐 몸은 되돌릴 수 없다 (W2 한계). 돌려줄 수 있는 것은 이름과 선택뿐이다.

## G8. 호피의 건강 시간 — 발디 오마주 (Ch1, 구현)

### G8.1 진행

1. 3층 소아 병동 병실 TV가 하나씩 켜진다. 「호피의 건강 시간」 퀴즈. 숫자 키로 답한다.
2. 맞히면 TV 앞에 **호피 스와피 인형 부품**(머리, 몸통, 왼팔, 오른팔, 왼다리, 오른다리)이 떨어진다. 6개.
3. **틀리면** 화면이 일그러지고, 놀이방 문 안쪽에서 무언가가 세 번 두드린다. 곧바로 회진이 순찰을 나오고, **회진의 걸음 박자가 빨라진다** (챕터 끝까지 유지). 9초 뒤 그 TV에서 다시 풀 수 있다. 평소 순찰은 80~110초마다 돈다.
4. 부품 6개를 놀이방의 모양 공방에 끼운다. **아무 자리에 아무 부품을 끼워도 된다.** "어떤 모양이든 좋은 모양이에요!"

### G8.2 문제 유형

| 유형 | 예시 | 정답 |
|------|------|------|
| 몸 상식 | "어른의 뼈는 몇 개일까요?" | 206개 |
| 몸 상식 | "심장은 하루에 몇 번쯤 뛸까요?" | 약 10만 번 |
| 짝 맞추기 | "호피의 오른팔은 어디에 붙여야 할까요?" | 어깨 (나중에 다시 보면 '어디든') |
| **풀 수 없는 문제** | **"사람에게 꼭 필요한 것은 무엇일까요? ① 잠 ② 밥 ③ 숨 ④ 몸"** | **무엇을 골라도 "틀렸어요!"** 정전 |

- 풀 수 없는 문제는 Ch1에서는 고장 난 화면처럼 보인다. Ch5에서 실험 90의 질문이었다는 것을 안다. 그리고 우나에게는 ①②③이 하나도 필요 없다.

## G10. 도구인가, 사람인가 — 숨은 성향 수치

> 회사는 우나의 몸을 '쓸모'로 보았다. 플레이어는 어떻게 볼 것인가.

| 수치 | 오르는 행동 |
|------|-----------|
| **도구** | 다른 방법이 있는데 우나를 위험 구역에 보낸다(+2) / 우나를 미끼로 쓴다(+3) / 진정 카드를 아이들에게 필요 이상으로 쓴다(+1) / 다친 우나를 지나쳐 서두른다(+1) |
| **사람** | 필요 없는 걸 알면서 물과 음식을 건넨다(+1) / 추운 방에서 보온포를 덮어 준다(+1) / 더 먼 길을 고른다(+2) / 우나의 이야기를 끝까지 듣는다(+0.5) / 크리처의 이름을 찾아 불러 준다(+2) |

- 수치는 **화면에 나오지 않는다.** 대신 우나가 달라진다. 사람 쪽이면 우나는 집 이야기를 점점 더 많이 하고, 건넨 물건을 주머니에 모아 둔다. 도구 쪽이면 우나는 "괜찮아요, 저 원래 이래요"라는 말만 한다.
- 엔딩 조건은 [P6](05_CHAPTERS.md)을 따른다.

## G12. 저장, 실패, 난이도

### G12.1 저장: 체크포인트 (구현)

- 장면이 바뀌는 지점마다 자동 저장된다 (출동, 정문, 로비, 3층, 우나, 퀴즈, 304호, 놀이방, 추격, 지하, 무균실).
- 저장되는 것: 체크포인트, 얻은 부품, 본 테이프, 판독 기록, 오답 수, 진행 표시, 진정 카드.
- 제목 화면의 '이어하기'로 마지막 체크포인트부터 다시 시작한다.

### G12.2 실패: 구급 기록지 (구현)

- 실패 화면은 **구급 활동 기록지(Patient Care Report)** 양식이다. '주증상' 칸에 원인이 적힌다.
- 모든 실패 연출은 **화면이 하얗게 번지며 소리가 멀어지는** 것을 기본으로 한다 (B6). 피는 없다.

### G12.3 난이도: 중증도 분류
