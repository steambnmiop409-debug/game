# [대설계 G] 게임플레이 시스템

## G1. 코어 루프

```
   ┌─────────── 탐색 ───────────┐
   │ (건물의 심장 박동에 맞춰 걷기) │
   ▼                            │
  진찰 ──▶ 기록·단서 ──▶ 처치(퍼즐) ──▶ 길이 열린다
   │ (청진기로 벽 너머를 듣는다)          │
   │                                  │
   │ 위협 (회진 차임, 비명, 바뀐 복도)     │
   ▼                                  │
 우나의 손을 잡는다 / 숨는다 / 도구 / 도주 ─┘
```

- **분 단위 루프:** 듣고 → 박동에 맞춰 움직이고 → 벽 너머를 진찰하고 → 문 하나를 연다.
- **챕터 단위 루프:** 새 구역(회사의 다음 계단) → 새 구급 장비 → 그 구역 아이의 규칙 배우기 → 우나의 이상 징후 하나 → 보스 → 진실 한 겹.

## G2. 박동 은신 — 건물의 심장

### G2.1 원리

- 지하 C-0의 심장이 뛴다. 그 박동이 **배관과 벽을 타고 건물 전체에 울린다.** "쿵— 쿵."
- 사람이 자기 맥박 소리를 신경 쓰지 않듯, **잔여체는 자기 심장 소리와 겹친 소리를 느끼지 못한다.**
- **게임 전체가 이 심장 하나를 시계로 쓴다.** 크리처의 걸음, 발소리 차폐, 음악, 조명 깜빡임이 모두 이 박동에 묶인다.

### G2.2 박동 은신

| 항목 | 값 |
|------|----|
| 차폐 구간 | 첫 박동음("쿵") 전후 **±100ms** |
| 차폐 구간 안에서 디딘 걸음 | 소음 반경 1.5m |
| 차폐 구간 밖에서 디딘 걸음 | 6m |
| 뛰기 | 14m (차폐 무관) |
| 웅크려 걷기 | 3m, 차폐 시 0.5m |
| 바닥 재질 배율 | 카펫 ×0.6, 리놀륨 ×1.0, 타일 ×1.3, 금속 ×1.6, **조직에 덮인 바닥 ×2.0** (건물이 직접 느낀다) |
| 보조 옵션 | '박동 걷기': 이동 키를 누르고 있으면 걸음이 자동으로 박동에 맞춰진다 (G13) |

### G2.3 심박 상태

| 상태 | BPM | 원인 | 효과 |
|------|-----|------|------|
| 안정 | 60 | 기본 | |
| 경계 | 90 | 회진이 주인공을 놓쳤다, 문을 부쉈다 | 크리처 이동 +25% |
| 흥분 | 120 | 나이트라이트의 비명, 회진이 주인공을 발견 | +50%, 회진 추가 출동 |
| 발작 | 160 | 보스전, 탈출 시도 | +80% |
| **심정지** | 0 | 심장실의 수동 제세동기(Ch3, Ch5), 특정 사건 | **8~16박 동안 박동이 멈춘다.** 회진이 그 자리에서 멈춘다(피가 돌지 않는다). 차폐도 없다. 끝나면 140으로 튀어 오른다 |

- 상승: 건강 퀴즈 오답 +15(Ch1에서는 챕터 끝까지 유지), 제세동기 사용 +10, 회진에게 발견 +20, 나이트라이트의 비명 +30.
- 하강: 10초마다 −5.

### G2.4 HUD

- 화면 위쪽 가운데의 **작은 초록 심전도 띠**가 건물의 박동을 그린다. 옆에 BPM 숫자.
- 조명은 박동마다 **3% 어두워졌다 돌아온다** (혈관이 수축하듯. 끌 수 있다).
- 난이도 '빨강'에서는 심전도 띠가 사라진다. 귀로만 판단해야 한다.

## G3. 감지 AI

### G3.1 소음 전파

- 레벨은 **방 그래프**(방 = 노드, 문·통로 = 간선)로 나뉜다. 소음은 거리와 문 상태(열림 ×1.0, 닫힘 ×0.4)에 따라 감쇠한다.
- 단, **방과 방의 연결은 바뀐다** (G7). 소음은 지금 이 순간의 연결을 따라 퍼진다.

### G3.2 누가 무엇으로 느끼나

| 존재 | 감각 | 피하는 법 |
|------|------|----------|
| 잔여체(건물) | 조직에 덮인 표면의 진동 | 박동 은신, 조직 없는 바닥 |
| 회진 | **체온과 이물질** | 우나의 손, 체온 낮추기, 무균실 |
| 나이트라이트 | 시야 | 어둠, 빛으로 눈 멀게 하기 |
| 크레이들 | 표면 진동 (여덟 개의 손바닥) | 카펫, 박동 은신 |
| 탱글 | 세 방향의 시야 (공유) | 세 자극 동시 과부하 |
| 피카부 | 보는 사람이 없을 때 어디에나 있다 | 우나의 시선 |
| 레디오어낫 | 감시 카메라 | 렌즈 가리기 |

### G3.3 상태 기계 (공통)

```
 배회/회진 경로 ──감지──▶ 의심(그 지점 확인) ──재감지──▶ 추격
  ▲                           │                        │
  │                           └──── 놓침(8박) ───────────┤
  ├──── 기절 (제세동기 4초 / 빛 / 과부하) ◀─────────────────┤
  └──── 마주침의 끝 (진정, C4 각 항목) ◀────────────────────┘
```

| 이동 방식 | 크리처 |
|----------|--------|
| **박동마다 한 걸음**씩 끊어 걷는다 | 호피 스와피, 회진 |
| 연속 이동 (매끄럽고 예측하기 어렵다) | 나이트라이트, 태그, 크레이들, 탱글 |
| 이동하지 않는다 (공간을 바꾼다) | 피카부, 노크노크, 레디오어낫, 잔여체 |

## G4. 몸 상태 — 사람의 몸은 필요가 많다

> 체력 바는 없다. 대신 **사람의 몸이 필요로 하는 것들**이 있다. 우나에게는 하나도 필요 없는 것들이다.

### G4.1 체온

| 항목 | 값 |
|------|----|
| 정상 | 37.0°C |
| 냉동실 | −0.5°C/10초 |
| 우나의 손을 잡고 있을 때 | −0.1°C/10초 (그녀의 손은 늘 차갑다) |
| 35°C 미만 | 떨림: 3초마다 작은 소음, 조준이 흔들린다 |
| 33°C 미만 | 이동 속도 −40% |
| 31°C 미만 | 쓰러진다 (실패) |
| 회복 | 보온포 +2°C, 난방기 앞 |
| **양면성** | 체온이 낮을수록 회진이 주인공을 느끼는 거리가 줄어든다 (37°C 8m → 34°C 4m). **차가워질수록 숨기 쉽지만 위험해진다** |

### G4.2 산소

| 항목 | 값 |
|------|----|
| 최대 | 100 |
| 가스가 찬 방 | −5/초 |
| 숨 참기 (숨을 때) | −10/초, 그동안 내 소음 0 |
| 산소마스크 (Ch3) | 휴대용 산소통 60초 |
| 25 미만 | 시야가 좁아진다. 헐떡임 (2초마다 반경 5m 소음) |

### G4.3 침식 (Encroachment) — 주 위협 게이지

> 주인공의 왼팔은 C-0의 원료로 만든 피부다. 건물 안에서 그 피부가 **자란다.**

| 항목 | 값 |
|------|----|
| 범위 | 0~100. 100이 되면 **흡수** (실패. 「최종 형태」 엔딩과 같은 연출의 짧은 판) |
| 증가 | 조직을 만짐 +2/초, 조직이 짙은 구역에 머묾 +0.5/초, 피카부가 만짐 +10, **회진에게 잡힘 +40** |
| 감소 | **거부 반응 유도제** −30 (부작용: 20초 동안 시야가 흐리고 메스껍다), 자외선 등으로 자기 팔 지지기 −10 (10초 동안 뛸 수 없다) |
| 효과 (양면성) | 30 이상: 회진이 주인공을 느끼는 거리 −25% / 60 이상: −50%, 건물의 꿈이 눈앞에 스친다 / 80 이상: 건물이 주인공에게 말을 건다. **몸을 내줄수록 숨기 쉬워진다** |
| 표시 | 숫자 없음. **1인칭 화면의 왼팔**에 매끈한 무늬가 손목에서 팔꿈치로, 손가락 끝으로 번진다 |
| 근거 | 실제 이식 의학의 '거부 반응' (W1.3). 여기서는 반대로, 몸이 이식된 조직을 거부하게 만들어야 산다 |

## G5. 구급 가방 — 건물을 진찰한다

### G5.1 장비

| 장비 | 획득 | 쓰임 |
|------|------|------|
| **청진기** | 처음부터 | 벽이나 문에 대면 **그 너머를 듣는다.** 크리처마다 다른 심장 박동, 회진의 발소리, 조직 문의 '맥 짚는 자리'. 그리고 우나의 가슴 (Ch1 마지막) |
| **펜라이트** | 처음부터 | 손전등. 나이트라이트의 눈을 멀게 한다. 동공 반응을 본다 (Ch2) |
| **휴대용 제세동기** | Ch1 끝 | 패들 충전 3회 (벽 콘센트에서 60초 충전). 조직 문의 맥 자리를 지져 수축시켜 연다. 회진 4초 기절. 꺼진 기계 재가동. 사용할 때마다 건물 심박 +10. **두 손이 필요하다** |
| **자외선 살균등** | Ch2 | 배터리 100. 조직 덩굴을 태워 길을 낸다. 비춘 자리 반경 3m는 30초 동안 **바뀌지 않는다** (임시 앵커). 회진이 물러난다. 자기 왼팔에 비추면 침식 −10 |
| 거부 반응 유도제 | 소모품 | 침식 −30 |
| 보온포 | 소모품 | 체온 +2°C |
| **산소마스크와 산소통** | Ch3 | 가스 구역 60초 |
| **관제실 출입 카드** | Ch3 | CCTV로 지금의 실제 구조를 본다 (G7) |
| **청진 증폭기** | Ch4 | 청진기를 원내 방송 배선에 연결해 **멀리 있는 방의 소리**를 듣는다 |
| 무전기 | 처음부터 | 처음엔 마커스의 목소리. 나중엔 그의 목소리를 흉내 내는 무언가 |

### G5.2 가방 칸

- 소모품은 **4칸**이다. 장비는 칸을 차지하지 않는다.
- 우나에게 물이나 음식을 건네면 그 칸이 빈다. 우나는 먹지 않고 **주머니에 넣어 둔다** (G10).

## G6. 우나와 함께

### G6.1 손잡기

| 항목 | 내용 |
|------|------|
| 조작 | 우나 가까이에서 왼손 버튼을 누르고 있는다 |
| 효과 | **회진이 주인공을 알아보지 못한다** (주인공을 '우나의 일부'로 느낀다). 잔여체의 바닥 진동 감지 −50% |
| 대가 | 뛸 수 없다, 사다리를 오를 수 없다, **두 손 장비(제세동기)를 쓸 수 없다**, 체온이 천천히 떨어진다. 다른 아이들(나이트라이트의 눈 등)에게는 그대로 보인다 |
| 이야기 | 처음 손을 잡았을 때 우나가 멈칫한다. "…손 따뜻한데 이상해요. 여기 같아요." (C2.5) |

### G6.2 시선 고정

| 항목 | 내용 |
|------|------|
| 조작 | 우나에게 방향을 가리키며 "여기 지켜봐" |
| 효과 | 우나가 보고 있는 시야 안의 공간은 **바뀌지 않는다** (W2 규칙 5). 우나는 눈을 깜빡이지 않는다 |
| 한계 | 한 번에 한 곳. 그동안 우나는 따라오지 않는다. **90초 넘게 혼자 두면** 잔여체가 우나를 '불러들인다'. 우나가 사라지고 분리 사건이 시작된다 (G6.4) |

### G6.3 우나만 할 수 있는 일

| 위험 | 우나 | 다른 방법 |
|------|------|----------|
| 가스가 찬 방 | 숨이 필요 없다 | 산소마스크(Ch3), 환기 장치 재가동 |
| 냉동실 깊은 곳 | 추위를 타지 않는다 | 보온포 여러 장, 난방기 우회 |
| 물에 잠긴 수조 | 숨이 필요 없다 | 배수 밸브 찾기 |
| 전기가 흐르는 바닥 | 죽지 않는다. **다만 아프다** | 차단기 찾기 (회진 구역을 지나야 한다) |

- 늘 '다른 방법'이 있다. 더 멀고, 더 위험하고, 더 오래 걸린다. 무엇을 고를지가 G10 수치가 된다.

### G6.4 분리 사건

- 시선 고정을 너무 오래 하거나, 우나가 정문이나 철조망 가까이 가면, 잔여체가 우나를 데려간다.
- 우나는 **별관 B의 자기 방 침대**에서 눈을 뜬다 (Ch4 전에는 플레이어가 이 방을 모른다). 그때까지 주인공은 혼자다.
- 우나가 지나간 자리에는 분필 그림(작은 화살표와 웃는 얼굴)이 남는다. "나 여기로 갔어요."

### G6.5 대화

- 우나 가까이에서 말 걸기 버튼을 누르면 장소에 맞는 짧은 대화가 나온다. 엄마 이야기, 옛날 직원 이야기, 농담.
- 드물게 주인공의 선택지 대사가 나온다 (예: "너 여기 들어온 지 얼마나 됐어?").

## G7. 변하는 건물

### G7.1 규칙

| 규칙 | 내용 |
|------|------|
| **아무도 보지 않는 곳이 바뀐다** | 주인공의 시야에도, 우나의 시야에도 없는 방과 복도는 건물의 박동에 맞춰 연결이 바뀔 수 있다 |
| 보고 있는 곳은 그대로 | 주인공의 시야, 우나의 시선 고정, 자외선 임시 앵커 |
| **무균실은 절대 바뀌지 않는다** | 조직이 없다. 길을 잃었을 때의 기준점이자 저장 지점 |
| 비상구는 다른 층의 비상구로 열린다 | 비상구끼리의 연결은 챕터마다 정해진 순열이다. 외우면 지름길이 된다 |
| 창밖 풍경이 바뀐다 | **기억의 창**: 창밖에 남의 집 부엌, 학교 운동장, 눈 내리는 뒷마당이 보인다. 잔여체의 꿈이다 |
| 나가도 돌아온다 | 정문을 나가 19번 군도를 따라가면 다시 정문 앞이다. 산을 넘으면 철조망이 나온다 |

### G7.2 길 찾기 도구

- **CCTV 관제실 (Ch3):** 지금 이 순간의 실제 구조를 보여 주는 유일한 지도. 모니터를 보는 동안에는 화면에 비친 곳도 '보고 있는 곳'이다.
- **분필:** 벽에 표시를 남긴다. 표시는 남지만, 표시가 있는 벽이 다른 곳으로 옮겨 갈 수 있다.
- **우나의 기억:** "여기 원래 화장실이었는데"처럼 우나는 바뀌기 전의 구조를 안다. 맞을 때도 있고, 22년 사이에 바뀐 곳은 틀린다.

## G8. 호피의 건강 시간 — 발디 오마주 (Ch1 중심)

### G8.1 진행

1. 소아 병동 곳곳에 **호피 스와피 인형 부품 6개**가 흩어져 있다 (머리, 몸통, 왼팔, 오른팔, 왼다리, 오른다리).
2. 부품이 있는 병실마다 TV가 켜지고 「호피의 건강 시간」 퀴즈가 시작된다. 문제 3개. 맞히면 부품을 얻는다.
3. **틀리면 건물의 심박 +15** (챕터 끝까지 유지), 그리고 놀이방의 호피 스와피 인형탈이 깨어난다.
4. 부품 6개를 놀이방 문의 인형 틀에 끼우면 문이 열린다. **아무 자리에 아무 부품을 끼워도 열린다.** 문 위 표어: "어떤 모양이든 좋은 모양이에요!"

### G8.2 문제 유형

| 유형 | 예시 | 정답 |
|------|------|------|
| 몸 상식 | "어른의 뼈는 몇 개일까요?" | 206개 |
| 몸 상식 | "심장은 하루에 몇 번쯤 뛸까요? ① 1천 번 ② 10만 번 ③ 1억 번" | ② (약 10만 번) |
| 숫자 세기 | "호피가 박수를 몇 번 쳤을까요?" | 화면을 보고 센다 |
| 짝 맞추기 | "호피의 오른팔은 어디에 붙여야 할까요?" | 정상 시절 화면에서는 어깨, Ch1 뒤 다시 보면 '어디든' |
| **풀 수 없는 문제** | **"사람에게 꼭 필요한 것은 무엇일까요? ① 잠 ② 밥 ③ 숨 ④ 몸"** | **무엇을 골라도 "틀렸어요!"** 화면이 일그러진다 |

- 풀 수 없는 문제는 Ch1에서는 고장 난 화면처럼 보인다. Ch5에서 실험 90의 질문이었다는 것을 알게 된다. 그리고 우나에게는 ①②③이 하나도 필요 없다.

## G10. 도구인가, 사람인가 — 숨은 성향 수치

> 회사는 우나의 몸을 '쓸모'로 보았다. 플레이어는 어떻게 볼 것인가.

| 수치 | 오르는 행동 |
|------|-----------|
| **도구** | 다른 방법이 있는데 우나를 위험 구역에 보낸다(+2) / 우나를 미끼로 쓴다(+3) / 시선 고정으로 오래 혼자 둔다(+1) / 다친 우나를 지나쳐 서두른다(+1) |
| **사람** | 필요 없는 걸 알면서 물과 음식을 건넨다(+1) / 추운 방에서 보온포를 덮어 준다(+1) / 더 먼 길을 고른다(+2) / 우나의 이야기를 끝까지 듣는다(+0.5) / 꿈의 방에서 우나의 기억 조각을 찾는다(+2) |

- 수치는 **화면에 나오지 않는다.** 대신 우나가 달라진다. 사람 쪽이면 우나는 집 이야기를 점점 더 많이 하고, 건넨 물건을 주머니에 모아 둔다. 도구 쪽이면 우나는 집 이야기를 그만둔다. 그리고 "괜찮아요, 저 원래 이래요"라는 말만 한다.
- 엔딩 조건은 [P6](05_CHAPTERS.md)을 따른다.

## G12. 저장, 실패, 난이도

### G12.1 저장: 병상

- 저장 지점은 **무균실의 병상**이다. 누우면 화면이 어두워진다.
- 깨어나면 우나가 침대 옆 의자에 앉아 있다. **밤새 같은 자세로.** "잘 잤어요?"

### G12.2 실패: 구급 기록지

- 실패 화면은 **구급 활동 기록지(Patient Care Report)** 양식이다. '주증상' 칸에 원인이 적힌다. "저체온", "질식", "흡수".
- 모든 실패 연출은 **화면이 하얗게 번지며 소리가 멀어지는** 것을 기본으로 한다 (B6).

### G12.3 난이도: 중증도 분류

> 구급대원의 '중증도 분류(트리아지)' 색으로 난이도를 고른다.

| 난이도 | 심박 배율 | 차폐 구간 | 침식 배율 | 심전도 HUD |
|--------|---------|----------|----------|-----------|
| **초록** (쉬움) | ×0.8 | ±150ms | ×0.6 | 있음 + 박동 걷기 보조 |
| **노랑** (보통) | ×1.0 | ±100ms | ×1.0 | 있음 |
| **빨강** (어려움) | ×1.2 | ±60ms | ×1.3 | **없음 (귀로만)** |
