## G1. 코어 루프

```
   ┌────────── 탐색 ──────────┐
   │  (박자에 맞춰 걷기)        │
   ▼                          │
  청취 ──▶ 기록·신호·기억의 소리 획득 ──▶ 조율(퍼즐) ──▶ 길이 열린다
   │                                                   │
   │ 위협 감지 (침묵 예고, 숨소리, 박자 밖의 소리)            │
   ▼                                                   │
 은신 / 신호로 멈추기 / 진정 / 도주 ─────────────────────────┘
```

- **분 단위 루프:** 듣고 → 박자에 맞춰 움직이고 → 소리 하나를 녹음하거나 조율해서 → 문 하나를 연다.
- **챕터 단위 루프:** 새 구역 → 새 공명기 기능 → 크리처가 '어떤 아이였는지' 알아내기 → 기억의 소리 찾기 → 보스 세트피스 → 진실 한 겹 공개.

## G2. 펜듈럼 (템포) 시스템

### G2.1 원리

- 시계탑의 대 메트로놈 '펜듈럼'은 **캠퍼스 전체의 길들이기 장치**다. **틱 라인**(방송 스피커망)으로 모든 방에 틱 소리를 보낸다.
- 아이들은 이 박자에 맞춰서만 움직이도록 체벌로 길들여졌다. 박자 밖의 소리는 '실수'이고, 실수를 찾아내도록 배웠다 (W2 규칙 3).
- **게임 전체가 하나의 시계(Conductor Clock)를 공유한다.** 적의 걸음, 발소리 차폐, 음악, 조명 깜빡임, 포키즈의 점프가 모두 이 시계의 박자에 묶인다.

### G2.2 박자 은신 (Beat Masking)

| 항목 | 값 |
|------|----|
| 차폐 구간 | 틱 전후 **±90ms** |
| 차폐 구간 안에서 디딘 걸음의 소음 반경 | 1.5m (평소 6m) — 아이들에게는 '정답'이라 들리지 않는다 |
| 차폐 구간 밖에서 디딘 걸음 | 6m — '실수' |
| 뛰기 | 차폐 여부와 관계없이 14m |
| 웅크려 걷기 | 3m, 차폐 시 0.5m |
| 발걸음 판정 | 걸음 주기의 접지 시점 기준. 걷는 속도를 박자에 맞추는 **'박자 걷기' 보조 옵션**이 있다 (G13) |

- **표면 재질별 배율:** 카펫 ×0.6, 나무 ×1.0, 타일 ×1.3, 금속 ×1.6, **바닥 건반 ×2.5 (음이 난다)**.
- **스피커가 고장 난 방**에는 틱이 없어 차폐도 없다. 레벨 디자인에서 '긴장 구간'으로 쓴다.

### G2.3 템포 변동

| 원인 | BPM 변화 |
|------|----------|
| 챕터 기본값 | Ch1 72 · Ch2 66 (연습동은 방마다 놓인 메트로놈이 박을 만든다. **가장 가까운 메트로놈의 박**이 차폐 기준) · Ch3 **없음** (지하는 방송망과 분리) · Ch4 72→208 · Ch5 **후원자들의 박수**와 프리마의 루바토 |
| 청음 수업 오답 | **+8 (영구, 챕터 안에서)** |
| 포키즈 경보 | +4 (16박 동안) |
| 템포 다이얼 (퍼즐 요소) | 구역별 BPM 조정. 느리면 적이 느려지지만 차폐 기회가 드물어지고, 빠르면 차폐는 잦지만 적이 빨라진다 |
| 상한 | **208BPM** (실제 기계식 메트로놈의 일반적인 최고값) |

### G2.4 HUD 표현

- 화면 상단 가운데 작은 메트로놈 아이콘이 박자에 맞춰 흔들린다. 옆에 현재 BPM이 연습일지 글씨체로 표시된다.
- 조명은 틱마다 **3% 밝아졌다 돌아온다** (잠재적 박자 신호, 끌 수 있다).
- 난이도 'Presto'에서는 HUD 메트로놈이 사라진다. 귀로만 판단해야 한다.

## G3. 소음과 청각 AI

### G3.1 소음 전파

- 레벨은 **방 그래프**(방 = 노드, 문·통로 = 간선)로 나뉜다. 소음은 거리와 문 상태(열림 ×1.0, 닫힘 ×0.4)에 따라 감쇠한다.
- 각 크리처는 **청각 임계값**과 **관심 지점 목록**을 가진다. 소음이 임계를 넘으면 그 지점으로 이동한다.

### G3.2 크리처 상태 기계 (공통)

```
 배회 ──소음 감지──▶ 의심(그 지점 확인) ──시야/재감지──▶ 추격
  ▲                       │                              │
  │                       └─────── 놓침(8박) ──────────────┤
  ├──────── 신호 반응 (멈춤 / 제자리로 / 움츠림 / 잠듦) ◀──────┤
  └──────────────── 진정 (기억의 소리, 자장가) ◀───────────────┘
```

| 상태 | 박자 묶임 크리처 (Ch1~2, Ch4 정지 전) | 무박자 크리처 (Ch3, Ch4 정지 후~) |
|------|------------------------------------|----------------------------------|
| 이동 방식 | 틱마다 한 칸(1.2m)씩 끊어 걷는다 | 연속 이동. 매끄럽고 예측하기 어렵다 |
| 플레이어가 읽는 법 | 리듬 | 소리의 방향 (HRTF 입체음향) |

## G4. 숨과 이명

### G4.1 숨 (Breath, 스태미나)

| 항목 | 값 |
|------|----|
| 최대 | 100 |
| 뛰기 | −12/초 |
| 회복 | 걷기 +8/초, 멈춤 +15/초 |
| 숨 참기 (홀드) | −10/초. 그동안 내 소음이 **0** |
| 25 미만 | **헐떡임**: 2초마다 반경 5m 소음. 벨로가 이것을 듣는다 |
| HUD | 왼쪽 아래 **작은 아코디언 풀무 아이콘**이 접혔다 펴진다 |

### G4.2 이명 (Tinnitus) — 위협 게이지

| 항목 | 값 |
|------|----|
| 범위 | 0~100. 100이 되면 게임오버 |
| 증가 | 허밍이 큰 곳 +2/초, 크리처의 비명 +25, 싱어롱즈 12음 클러스터 +25, 미완성품이 매달림 +5/초, 후원자 금관의 비명 +15 |
| 감소 | 자연 −1/초, **귀 막기 −8/초**, 목캔디 −30 |
| **귀 막기 (Q 홀드)** | 이명이 빨리 내려가지만 **게임 소리 전체가 먹먹해진다** (저역통과 약 500Hz, −12dB). 다가오는 적의 소리를 듣기 어려워지는 대가 |
| 시각 표현 | 화면 가장자리에서 가는 흰 선이 안쪽으로 자란다 |
| 청각 표현 | 이명 사인파. **청력 안전 규칙**에 따라 레벨과 주파수에 상한을 둔다 (S10.4) |
| 게임오버 | 화면이 하얗게 차오르고 아이들의 허밍이 귀 안을 가득 채운다. 문구는 "당신도 이제 들립니다." |

## G5. 공명기 (The Resonator) — 녹음하고, 되돌려 쓴다

### G5.1 구성 (Ch1에서 직접 조립한다)

| 부품 | 획득 장소 | 기능 |
|------|----------|------|
| 소리굽쇠 No.49 (A4) | 소포 | 기준음. 그리고 **학교의 '멈추고 들어라' 신호** |
| 나팔 (축음기 혼) | 로비 옆 AV실 | 지향성 증폭. 재생 소리가 조준한 방향으로 나간다 |
| 마이크로 릴 녹음기 | 로비 옆 AV실 | 녹음과 재생 |
| 스트로보 원판 | 레슨동 '라' 교실 | 화면. 목표 음과 맞으면 무늬가 멈춘다 (2차 조립) |

1인칭 시점에서는 오른손에 든 '나팔 + 작은 릴 + 초록 원판' 장치가 화면 오른쪽 아래에 2D 스프라이트로 보인다.

### G5.2 챕터별 업그레이드

| 챕터 | 기능 | 조작 | 설명 |
|------|------|------|------|
| Ch1 | **녹음 / 재생** | 좌클릭을 누르고 있으면 녹음(최대 4초), 우클릭으로 재생 | 녹음 슬롯 1개 |
| Ch1 | **송출** | 방송 잭이나 라디오 근처에서 T | 녹음한 소리를 **다른 위치의 스피커로** 내보낸다 (원격 유인) |
| Ch2 | **음높이 다이얼** | 휠 | 거칠게 ±12반음, 미세하게(Shift+휠) ±50센트. **기억의 소리는 그 아이의 음높이에 맞춰야 닿는다** |
| Ch3 | **역재생** | R | 아이들이 거꾸로 부른 노래와 메시지를 복원한다 |
| Ch4 | **겹쳐 쌓기** | 1·2·3 | 녹음 슬롯 3개를 동시에 재생 (화음 잠금, 여러 신호 동시 송출) |
| Ch5 | **지속음** | 길게 홀드 | 음 하나를 숨이 닿는 한 계속 유지한다 (최종장) |

### G5.3 신호표 (W2 규칙 2의 구현)

> 아이들을 길들인 신호는 지금도 그들의 몸을 움직인다. 플레이어는 그 신호를 녹음해 되돌려 쓸 수 있다.
> **효과가 강한 신호일수록 '선생님' 수치가 오른다** (G10). 그 신호들은 원래 체벌이었기 때문이다.

| 신호 | 학교에서의 뜻 | 획득 | 효과 | 선생님 수치 |
|------|-------------|------|------|-----------|
| **소리굽쇠 A** | "멈추고 들어라" (모든 수업의 시작) | 처음부터 | 반경 8m 안의 크리처가 **4박 정지**. 같은 크리처에 연달아 3번 쓰면 익숙해져 무시한다 | 0 (조율사의 도구) |
| **수업 종** | "수업 끝, 제자리로" | Ch1 교무실 방송실에서 녹음 | 크리처가 **자기 자리**(진열대, 요람, 양호실)로 돌아간다. 유인과 통로 열기 | 0 |
| **박수 두 번** | "노래 시작" | Ch2 합창실 | 노래하는 크리처가 **그 자리에서 노래를 시작한다** (위치 고정, 소음 미끼) | +0.5 |
| **자 소리 '탁!'** | "틀렸다. 손 내밀어." | Ch2 살롱 (그랑데의 자) | 크리처가 움츠러들며 **3초 정지.** 그 뒤 20초 동안 겁에 질려 +50% 속도로 날뛴다 | +1 |
| **"쉬이— 금방 끝나"** | 마취 직전 | Ch3 양호실 테이프 | 크리처를 **8초 재운다** | +2 |
| **해로우의 목소리** | 창립자 | Ch4 해로우 집무실 테이프 | 졸업생들까지 얼어붙는 가장 강한 신호 (**12초**) | +3 |
| **기억의 소리** | (학교 바깥의 소리: 엄마의 편지, 웃음, 동화) | 주요 크리처마다 하나 | 그 아이의 음높이에 맞춰 재생하면 **영구 진정** | 친구 +2 |
| **자장가** | — | 곳곳 (오르골, 테이프) | 일반 크리처 20초 진정 | 친구 +0.2 |

## G7. 룰라 오르골 나침반

| 항목 | 값 |
|------|----|
| 감기 | F를 길게. 8번 감으면 16박 동안 연주한다 |
| 방향 안내 | 가야 할 쪽을 바라볼수록 **음량과 밝기**가 커진다(장조). 등지면 작아진다 |
| 위험 | 연주 중 반경 10m 안의 크리처가 소리를 듣는다 |

| 신뢰 (숨은 수치) | +: "감아 줘" 신호에 바로 감아 준다, 그녀를 위험에서 지킨다 / −: 미끼로 쓴다(바닥에 두고 감아서 크리처를 유인), 오래 방치한다 |

## G8. 청음 수업 — 발디 오마주 (Ch1 중심, Ch4에서 재등장)

### G8.1 진행

1. 교실 축음기에 **레슨 음반**(도·레·미·파·솔·라·시, 7장)을 올리면 TV가 켜지고 티코가 수업을 시작한다. 수업은 지금도 매일 같은 시간에 아이들을 위해 돌아가고 있다.
2. 문제 3개. 장난감 건반 책상(한 옥타브)과 `예 / 아니오` 버튼으로 답한다.
3. 정답이면 금별 스티커를 받는다. **오답이면 전체 BPM +8**, 그리고 티코가 깨어난다. 첫 오답 이후로 티코가 복도를 걷기 시작한다.
4. 음반 7장을 다 모아 레슨동 출구의 주크박스에 넣어야 나갈 수 있다 (P1).

### G8.2 문제 유형

| 유형 | 예시 | 보통 난이도의 공정성 규칙 |
|------|------|------------------------|
| 높낮이 | "두 번째 음이 더 높을까요?" | 간격은 최소 3반음 |
| 같다/다르다 | "두 음이 같을까요?" | 최소 1반음. 가끔 '같은 음, 다른 악기'라는 함정 |
| 리듬 세기 | "종이 몇 번 울렸나요?" | 최대 7번 |
| 따라 치기 | "이 세 음을 건반으로 쳐 보세요" | 도~솔 사이의 세 음 |
| **불가능한 문제** | **"시와 도 사이에 있는 음을 건반으로 쳐 보세요."** 질문 뒤에 실제로 **사분음**(반음의 절반)이 울린다 | 건반에는 그런 음이 없다. 무엇을 쳐도 오답이다. 화면 글자가 깨지고, 티코의 얼굴 프레임이 바뀐다 |

- **숨은 요소:** 진엔딩 후에는 공명기 **미세 다이얼**을 처음부터 쓸 수 있다. 이것으로 사분음을 맞히면 티코가 단 한 번 펠의 목소리로 말한다. "…거봐. 너는 들을 줄 알았어."

## G9. 퍼즐 유형 8가지 (모두 소리 기반)

| # | 퍼즐 | 원리 | 처음 등장 |
|---|------|------|----------|
| 1 | **핀 잠금** | 학교의 문은 작은 핀블록과 현으로 잠겨 있다(기계식, 살아 있지 않다). 튜닝 해머로 현을 돌려 **소리굽쇠와의 맥놀이(와와와 떨림)가 멈출 때까지** 맞춘다. **실제 조율사가 귀로 조율하는 방식**과 같다 | Ch1 |
| 2 | **소리 열쇠** | 특정 소리에만 열리는 문 (교사의 암호 문구, 종소리). 테이프에서 녹음해 와 재생한다 | Ch1 |
| 3 | **송출 유인** | 녹음한 신호를 먼 스피커로 보내 크리처를 그쪽으로 보낸다 (예: 먼 교실 스피커로 수업 종 → 크리처가 그쪽 자리로) | Ch1 |
| 4 | **음계 길** | 바닥 건반 복도. 다장조 음계 순서로만 밟아야 조용하다 | Ch2 |
| 5 | **허락받은 연주** | 퍼즐에 살아 있는 악기의 음이 필요하다. **억지로 연주하면**(활로 세게 긋기, 건반 내려치기) 바로 음을 얻지만 아이가 비명을 지르고 선생님 수치가 오른다. **먼저 진정시키고 부탁하면** 아이가 스스로 그 음을 내 준다 (W2 규칙 4) | Ch2 |
| 6 | **역재생** | 거꾸로 녹음된 노래를 뒤집어 금고 번호, 문 암호, 그리고 **아이들의 비밀 노래 조각**을 얻는다. 아이들이 어른 몰래 쓰던 '거꾸로 말하기 놀이' | Ch3 |
| 7 | **신호 연쇄** | 여러 신호를 순서대로 쓴다. 예: 수업 종으로 미완성품들을 요람으로 돌려보내고 → 그 사이 소리굽쇠로 허시를 멈추고 → 통과 | Ch3 |
| 8 | **화음 잠금** | 문에 3화음 표시가 있다 (예: `F · A · C`). 녹음 슬롯 3개로 화음을 쌓는다. 고장난 악단에게 음을 부탁할 수도 있다 | Ch4 |

## G10. 선생님인가, 친구인가 — 숨은 성향 수치

### G10.1 기억의 소리

- 주요 크리처 5종(벨로, 싱어롱즈, 그랑데, 허시, 티코)마다 **학교 바깥의 소리 하나**가 그들의 구역에 숨겨져 있다. 엄마의 녹음 편지, 방송 NG의 웃음, 어린 시절의 레슨, 동화 낭독, 콘테스트의 웃음.
- 기억의 소리를 **그 아이의 음높이에 맞춰** 재생하면 영구히 진정된다. 짧은 컷신과 함께 그들이 잠시 아이로 돌아간다.
- **이야기를 읽은 플레이어만 진정 루트를 갈 수 있다.** 기록 수집과 엔딩이 이렇게 연결된다.

### G10.2 두 수치

| 수치 | 오르는 행동 | 의미 |
|------|-----------|------|
| **선생님** | 자 소리, "쉿", 해로우의 목소리를 쓴다 / 살아 있는 악기를 억지로 연주한다 / 주요 크리처를 제압한다(+2) | 아이들은 당신을 **또 하나의 어른**으로 기억한다 |
| **친구** | 기억의 소리로 진정시킨다(+2) / 자장가 / 허락받은 연주 / 룰라를 지킨다 | 아이들은 당신을 **49번, 반 친구**로 기억한다 |

- 수치는 **화면에 직접 나오지 않는다.** 대신 아이들의 반응이 바뀐다. 친구 쪽이면 크리처가 가끔 길을 비켜 주거나 경고음을 내 주고, 선생님 쪽이면 마주치자마자 움츠러들거나 더 공격적으로 쫓아온다. 챕터 끝 크레딧 송의 편곡도 달라진다.
- 엔딩 조건은 [P6](05_CHAPTERS.md#p6-엔딩-3종--이름은-실제-종지에서-따왔다)를 따른다.

## G12. 저장, 실패, 난이도

### G12.1 저장: 보면대

- 체크포인트는 **보면대**다. 내 악보를 올려 두면 '연습일지'에 저장된다.
- 보면대는 대개 **틱이 크게 들리는 방**(안전 구역)에 둔다.

### G12.2 실패: 크리처별 '잡혔을 때'

- 모든 실패 연출은 **소리가 끊기며 암전**되는 것을 기본으로 한다 (B6). 크리처마다 마지막 소리가 다르다 (C4 각 항목).
- 실패 화면은 '성적표' 형태다. 맨 아래 칸에 크리처가 남긴 한 줄 평이 적힌다 (예: 티코 "수업 끝. 집에 가렴.", 허시 "금방 끝났지?").

### G12.3 난이도: 메트로놈 빠르기말

| 난이도 | BPM 배율 | 차폐 구간 | 이명 배율 | HUD 메트로놈 |

## G13. 접근성

| 항목 | 내용 |
|------|------|
| 시각 박자 | 화면 가장자리의 박자 링, 진동(게임패드) |
| 소리 자막 | `[똑딱 — 박자]`, `[왼쪽 뒤: 아코디언 들숨]`처럼 **방향과 종류**를 함께 표시 |
| 음 맞추기 보조 | 스트로보 원판 외에 '높다/낮다' 화살표 옵션 |
| 박자 걷기 보조 | 이동 키를 누르고 있으면 걸음이 자동으로 박자에 맞춰진다 |
| 이명 소리 끄기 | 이명을 시각 효과로만 표현 |
| 깜빡임 감소 | 스트로보 무늬와 조명 깜빡임 약화 |
| 바디 호러 강도 | '흔적 표시 줄이기' 옵션: 사람의 흔적을 실루엣으로 대체한다 |
| 마이크 | **기본값은 꺼짐.** 최종장의 '내 목소리로 부르기'는 선택 사항이며 버튼 홀드로 대체할 수 있다 |
| 색 의존 금지 | 싱어롱즈의 색-음 대응은 보조 정보일 뿐이다. 퍼즐의 정답은 항상 소리 + 모양(번호)으로도 구분할 수 있다 |
